# 工程记录

[English](README.md) | 中文

本目录保存跨软件包或跨部署适用的工程审查和验证记录。它与产品文档分开，也与每个 release 的上游记录（见 [`upgrades/`](../upgrades/README.zh.md)）分开。

| 记录 | 范围 |
| --- | --- |
| [`BENCHMARK.md`](BENCHMARK.md) | 性能基线和可重复的测量说明。 |
| [`CODE-QUALITY-REVIEW-2026-09-08.md`](CODE-QUALITY-REVIEW-2026-09-08.md) | 仓库级质量审查发现和后续证据。 |
| [`PLUGIN_SECURITY_PLAN.md`](PLUGIN_SECURITY_PLAN.md) | 插件安全审查和实施计划。 |

当新记录的主题跨越多个软件包或部署目标时，将其放在这里。软件包专属契约放在软件包 README，事故放在 [`docs/postmortem/`](../docs/postmortem/README.zh.md)，上游 release 的取舍记录放在 [`upgrades/`](../upgrades/README.zh.md)。
