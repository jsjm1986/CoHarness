把 AI 团队，管成一个团队

CoHarness 是面向中小团队的全插件化协作平台：管理员在一个管理中心里管住用户、项目、模型与成本；成员在同一个工作台里与智能体共享真实的工作——持久会话、跨会话记忆、文档、审批与委派。

核心 · 管理中心

一个 /admin，管住团队的全部 AI 资产

Gateway 自带完整管理端：从账号与实例生命周期，到模型治理、用量成本、审计与部署——中小团队不需要再拼一套运维后台。

  • 用户与实例账号、角色、登录状态与每位用户独立的 Harness 运行时实例——启动、停止、重启一手掌控。

  • 用量与成本按用户/项目的 Token 用量、成本估算、额度告警与配额配置——账本不存 API 密钥与对话内容。
  • 审计与运维审计记录、部署状态、终端、SSH、Webhook、桌面与归档——运维面在同一个管理端里。

运行机制

运行时怎么分：成员有独立个人运行时，项目有共享运行时

Gateway 管理两类实例：每位用户一个个人运行时承载个人空间，每个项目一个共享运行时承载协作——两种实例都按需拉起、空闲回收。

  • 一成员一个个人运行时每位用户分配独立的 dsh web 进程、专属端口与独立 home 目录（进程的 cwd 与 $HOME）——个人空间的会话、记忆、文档落在成员自己的目录下；目录授权还投影进成员可读写的所属项目目录（ro/rw 按成员表）。
  • 一项目一个共享运行时项目运行时以项目目录本身为 cwd 与 home，启动时挂载协作套件与项目作用域记忆——成员在同一个共享环境里接力：会话、项目记忆与文档属于项目，而不是成员各自的副本。
  • 按需拉起，空闲自动回收两类实例都带 starting / ready / stopping / stopped 生命周期：空闲自动停止、有操作时拉起；手动停止不会被隐式拉起；steward 维护空间常驻。
  • 三档权限预设 + 路径级授权运行时挂载 read-only / workspace-write / danger-full-access 预设；会话按 cwd 精确授权并过滤参与者可读范围，会话可见性可选项目共享或创建者私有；项目路径不允许与任何用户目录重叠。
  • 平台后端可替换开发环境本机 spawn；Linux 生产用 systemd 用户单元 + 独立系统账号（成员 harness-<user>、项目独立运行时账号）+ TemporaryFileSystem 隔离——普通项目运行时只看得见自己的项目目录。

协作理念

协作的单位是共享的工作，不是共享的对话链接

项目承载持续的智能体环境、成员贡献、委派关系、待决决策与可恢复的进度——浏览器关闭、单个智能体停止，工作依然在那里。

插件装配，而非固定流程

模型、工具、角色、上下文、权限、委派路径与工作流都通过插件、profile、bundle 组合，适配团队自己的工作方式。

有边界与责任的委派

主智能体可把部分工作委派给专家子智能体——有明确关系、范围与责任；子任务不静默继承全部能力与权限。

人类判断是一等工作

审批授权受控操作，提问补充业务判断；一个有效参与者认领待决项，结果写入共同历史，不产生竞争结果。

沉淀可复用的实践

验证过的委派模式、评审步骤、上下文来源或工具策略，可固化为团队的下一个插件、技能、profile、bundle 或工作流。

能力矩阵

覆盖人机协作的完整链路

以下均为当前代码库中已实现的能力。

Agent 运行时

Cordis 插件运行时 + 事件溯源会话：持久恢复/分叉、模型请求、审批、提问、计划、目标、待办、任务、工作流、压缩与遥测。

工具与执行

工作区文件工具、图片读取、Shell 与持久终端、LSP、网页搜索/抓取、技能、结构化附件、沙箱与目录策略。

跨会话记忆

个人 / 工作区 / 项目三级作用域：画像、指引、背景、资源四类条目随会话注入有界清单，支持搜索与修订。

会话历史检索

模型可搜索、追踪、精读有权限的既有会话，并生成接续交接摘要——过去的工作成为可用的上下文。

文档管理

命名用户文档：上传下载、附加到会话、作用域感知浏览、跨作用域复制、快照谱系与操作历史。

子智能体团队

持久的子智能体会话、明确的委托关系、可恢复可继续的协作伙伴，报告选择性回流主任务。

自动化任务

定时与触发器驱动的自动化：任务计划、目标管理与后台执行，工作离开浏览器也能继续。

Web 界面

响应式浏览器应用：会话与实时历史、模型选择、命令与 @ 建议、附件、权限、目标、任务、设置、中英双语与主题。

MCP 与扩展生态

MCP 客户端接入外部工具服务，Claude Code / Codex hook 桥接既有工作流，插件目录与 bundle 持续扩展能力面。

安全与凭证

凭证引用让密钥不进日志；沙箱策略、目录授权、审批与权限预设，把"能做什么"钉在每次执行上。

多入口接入

Headless、JSON-RPC、ACP 自动化协议、TypeScript / Python SDK、SSH 远程执行目标、Webhook 出站集成。

语音与附件

语音输入转写、图片读取与结构化附件、用户文档附加到会话——输入面不只有键盘。

快速开始

两条路：本机个人用，或 Gateway 团队用

个人 / 单机

无需 Gateway 与 PostgreSQL，浏览器工作区 + 本地会话存储。

git clone https://github.com/jsjm1986/CoHarness.git
cd CoHarness && pnpm install && pnpm run build
pnpm dsh --profile web
→ 打开浏览器进入工作台，在 设置 → 模型 里配置 DeepSeek 或其他提供方密钥，选择工作区目录即可开始。

团队 / Gateway

认证的项目边界：账号、个人空间、共享项目、模型治理、配额与审计。

# 见部署手册
gateway/deploy/README.md
# PostgreSQL + release 目录 + launchd/systemd
release-control.sh activate <release-dir>
→ 生产部署按评估过的自托管责任对待；Linux systemd 提供更强隔离，macOS 适用于可信团队。
开源

站在 DeepSeek Harness 之上，独立演进

CoHarness 是独立衍生项目，不是上游换皮版。底层插件与运行时契约以 DeepSeek Harness / Cordis 为参照，自研并维护 Gateway、协作、管理、文档、部署与 Android 能力；与上游按行为选择性同步。

⚠ 预发布阶段：公开 API、配置、数据库结构与部署流程可能变化；暴露服务前请先阅读 SAFETY.md 与部署 runbook。
  • 全插件架构：一切都是插件，能力以 Service Definition / Provider / Consumer 接缝组合
  • 事件溯源会话：持久、可恢复、可分叉，会话数据遵循不可变代际规则
  • 中英双语文档与界面，VitePress 文档站随仓库投影
  • TypeScript / Python SDK、JSON-RPC、ACP 自动化接入
  • Android（Capacitor）壳可访问已部署的 Gateway
  • 数据主权：全部数据在自有基础设施上——BYOK 模型路由、账本不存密钥与对话内容
