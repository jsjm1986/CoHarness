# 浏览器环境与文档位置

[English](README.md) | 中文

<a id="summary"></a>
## 概述

工作台和 Admin 遵循浏览器入口的[部署模式](../../deployment-topology/README.zh.md)。单电脑入口沿用现有布局，不显示电脑标签。多电脑主入口提供统一个人浏览与轻量电脑标识，直接访问接入电脑仍只使用本机。新标签页可独立操作另一台电脑或 Runtime。

## 身份与权限

| 资源 | 身份与权限范围 |
| --- | --- |
| 账号 | 组织账号；现有角色和模型预算统一管理 |
| 个人 Runtime | 分配 UUID；会话、插件状态和进程代次独立 |
| 个人文档 | 账号与电脑；同一账号在同一电脑上的 Runtime 共用 |
| 项目 | 固定一台电脑；项目成员权限与电脑使用权限均需满足 |
| 能力资格 | 现有授权对象与选定电脑；会话确认另行保留 |
| 真实桌面 | 电脑与实际桌面；不同电脑可以并行操作 |

电脑卡片显示当前电脑和具体 Runtime。可选环境列表只包含获准使用的分配，并按有界分页加载。显示名称不参与身份判断。浏览器会话键包含分配 UUID，因此不同个人 Runtime 中相同的会话编号仍能区分。明确的 Runtime 地址优先于旧空间 Cookie。当前选择、工作区预留和工作台展示按标签页保留各自的存储归属；现有会话文件保持原格式。

<a id="user-navigation"></a>
## 用户端导航

个人／项目空间选择器、会话和工作区保留现有行为。电脑卡片提供其他已授权环境，并支持在新标签页打开当前环境。切换不会更新其他标签页的 Runtime 选择。后续请求、套接字、私有链接和启动资源均绑定已选分配。插件模块 URL 的原始查询字节在路由中保持完整。

文档管理使用统一入口，分别浏览各电脑上的位置。标题标明存储电脑，详情卡片同时显示当前对话所在电脑。浏览另一位置不会切换对话。全部可访问文档总览查询已授权的数据库元数据；打开具体位置时才请求该处文件。混合位置的列表行带有电脑卡片，已限定位置的列表只在标题标识一次。

复制预览固定来源、目标电脑和空间，只读取选中文件的元数据。提交时重新检查双方权限，并通过现有可续传上传协议流式传输经校验的快照。副本获得独立文档身份，保留来源关系。读取和复制文档不会启动 Runtime。访问个人文档要求该电脑上已保留账号主目录；电脑使用授权本身不会创建存储。撤销权限后隐藏该电脑的元数据，并拒绝其内容访问和后续写入。位置不可用时仅报告该位置的故障，不会改选其他电脑上的同名文件。

将副本附加到对话时，Gateway 在打开源文件前重新核验具体的对话、Runtime 和电脑。若复制后未能记录活动，已完成的副本仍可使用。再次复制前请先刷新历史记录。

<a id="admin-navigation"></a>
## Admin 导航

Admin 电脑卡片在切换电脑时保留当前页面。用户详情列出电脑使用授权、跨电脑的 Runtime 分配和生效配额。组织默认值位于部署页，用户覆盖值位于用户详情。分配重试沿用同一请求编号。生命周期确认框标明电脑、Runtime UUID 和展示的进程代次。插件、终端和 Webhook 执行选择器明确选择具体 Runtime；插件配置和终端清理直到完成仍使用同一身份。项目配置快捷入口打开项目所属环境。

现有六类资格控制作用于选定的管理电脑。账号角色、成员关系和组织设置保留原有统一含义。管理员可以管理其他账号的分配而不借用该账号的个人执行权限；打开用户工作台时仍需满足管理员自身的电脑使用权限。

账号选项、账号编辑、密码重置、组织模型、用量和预算请求由中心处理。选择不可用电脑不会将这些共享操作转发到该电脑。实例列表字段、电脑资料、项目与本地资源仍绑定所选电脑。

手机端 Runtime 管理使用现有条目列表，全部生命周期操作可直接使用；Runtime 配额由独立折叠区提供。写入失败或结果未确认时，保留已显示的授权与配额字段，刷新权威状态后再写入。生命周期操作的失败原因保留在确认框内。刷新元数据不会重放变更操作。

工作台与 Admin 链接在登录和必须设置密码后保留原有本地目标。账号表单携带 `returnTo`；Gateway 只接受本地工作台及 Admin 界面地址，拒绝外部目标和 API 路由。

电脑配置并验证本地内容卷后，首次打开空的个人文档目录会保留其文件系统身份。迁移现有账号目录时，在所属电脑请求 `GET /admin/api/documents/personal/{userId}/migration?dshNode={nodeId}`，核对文件数、历史记录数及阻止原因。向同一地址发送 POST，提交原根 UUID、两项摘要、检查限额和电脑 UUID。文件日志变更、转移记录归属不清、电脑使用权撤销或文件不匹配都会阻止发布。文件保留原位，原目录索引继续冻结保存。

<a id="browser-api"></a>
## 浏览器 API

`GET /account/api/document-locations` 返回有界的 `items` 页和 `nextCursor`，不会启动 Runtime 或读取文件。`GET /account/api/documents/overview` 返回跨电脑的已授权元数据。浏览器复制、预览、提交、重试及目录操作使用 `/account/api/documents/transfer/...`。文件操作继续使用现有 `/api/documents/scope` 和可续传上传路由，并明确携带 `scope` 与 `dshNode`。这些浏览器操作直接认证账号，不签发执行主体。Runtime 回调保留现有凭证和执行参与检查。
