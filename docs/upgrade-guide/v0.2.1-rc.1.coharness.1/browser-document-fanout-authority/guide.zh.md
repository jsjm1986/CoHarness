# 浏览器文档多目标复制授权

[English](guide.md) | 中文

## 变更

浏览器向多个项目目标复制时，发起账号必须持续具备有效的组织管理员身份。每次源文件读取、上传请求及后续目标都会重新检查该角色。账号降权后，即使保留项目写成员资格，剩余请求仍会以 `DOCUMENT_TRANSFER_MULTI_TARGET_FORBIDDEN` 停止。已完成文件保留为快照；未完成上传沿用正常到期清理。

## 迁移

1. 多目标操作进行期间，保持管理员成员身份有效。授权被撤销后，重试前先查看各目标的结果。
2. 拥有源读取与目标写入权限的成员，仍可一次向一个目标复制。
3. 无需修改配置或迁移存储数据。参见[文档工作台决策](../../../../.agents/notes/implemented/feature/2026-08-24-cross-scope-document-workbench.zh.md)。
