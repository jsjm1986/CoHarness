# 升级完成通知准入

[English](guide.md) | 中文

## 变更

设备注册和删除要求认证账户当前有效的企业与成员资格。完成通知还要求当前继承的会话访问权限和设备归属。已撤销资格的收件人跳过。个人根会话和子会话只对所有者开放，并要求精确 Runtime 分配与来源电脑使用授权；另一台获准电脑不能替代该授权。缺失或已移除的 Runtime 分配跳过。

未过期 pending 与 sent 投递记录会抑制再次发送。failed 与过期 pending 记录可以重试。尝试结算与无效注册删除会保留后继尝试和转属后的设备。FCM 初始化可在凭据修复后恢复。提供方工作释放数据库连接，并具有有限期限。

未配置的提供方会记录失败并保留注册。后续回调带有提供方配置时，可以重试同一完成事件，不会虚构成功记录。

## 迁移

1. 升级完整 Gateway 构建。设备 API 字段和数据库 schema 无需迁移。确认来源电脑使用权限撤销后，即使另一台电脑仍获准，个人会话也停止通知；整个账户的设备注册仍可使用。
2. 可设置正数 `HGW_PUSH_DELIVERY_TIMEOUT_MS`（默认 `30000`）和 `HGW_PUSH_DELIVERY_LEASE_MS`（默认 `120000`）。租期必须大于超时；无效值会令启动失败。
3. 考虑响应丢失前远端已经接受的情况：后续重试可能重复通知。failed 与过期记录需要再次触发回调；不增加后台 worker。见[投递归属](../../../../.agents/notes/implemented/bug-fix/2026-10-29-push-delivery-authority.zh.md)。
