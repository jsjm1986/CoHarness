# SDK 子级保留父级执行权限

[English](guide.md) | 中文

## 变更

发起 Agent 安装执行权限服务时，SDK 委派必须安装父级控制，也覆盖没有资源准入和模型访问策略的组合。每次子级模型请求在适配器派发前，经过捕获的父级中间件和实时授权。此前这种组合启动独立子级，跳过了这些检查。

## 迁移

1. 重新构建匹配的 SDK 提供方和受管子级入口。
2. 提供父级常规 LLM 运行时，以及支持私有引导的 CLI。子级没有确认引导时拒绝启动。
3. 受管委派保持执行权限服务处于安装状态。通过 [SDK 提供方参考](../../../../packages/subagent/subagent-dsh-sdk/README.zh.md)配置父级控制限额。
