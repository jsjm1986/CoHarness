# 升级账号用量读取

[English](guide.md) | 中文

## 变更

`GET /account/api/usage` 在准备好所选账号或项目的汇总后重新核验浏览器会话。注销、过期、要求改密以及账号或组织资格撤回时返回403，不包含用量或额度数据。

项目汇总还要求当前项目成员资格、挂载、精确电脑权限及 Steward 资格。所有权转移或管理员降级后，只要普通成员资格仍然有效，就可继续读取。个人汇总的发布要求当前账号资格；初始 Runtime 选择保留既有授权规则。被拒绝的项目读取不会切换为个人计费数据。

显式 `month` 必须使用四位年份的 `YYYY-MM`，月份从01到12。空值或无效值返回400及 `invalid-month`。

## 迁移

部署完整 Gateway 构建。数据库结构、计费总数和请求字段保持不变。

自定义协作适配器需要提供 `projectReadAuthorities(userId, projectId?)`，不执行电脑元数据 I/O。返回所选项目的当前权限；组织目录提供所选电脑时，保持对应的 `nodeId`。提供方缺失返回501；读取失败返回503，不包含已准备的数据或数据库诊断。个人汇总不要求协作适配器。

收到403后刷新账号或项目访问资格。验证只读成员可以读取项目汇总、准备期间被移除的账号收不到汇总，且个人总数始终归属该账号。参见 [Gateway 规则](../../../../gateway/README.zh.md)。
