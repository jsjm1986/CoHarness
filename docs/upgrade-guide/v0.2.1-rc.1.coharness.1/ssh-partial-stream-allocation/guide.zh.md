# SSH 启动失败等待每次流分配结束

[English](guide.md) | 中文

## 变化

普通进程启动期间一路流失败时，`done`、成功的范围观察和提供方销毁会等待其他流分配尝试及已分配套接字关闭。仅有远端终止确认，不能释放本地启动清理仍活跃的分配。原启动错误与独立的范围观察失败继续通过各自路径报告。

## 迁移

重新构建 Host SSH 子进程提供方及其匹配分发包。不改变辅助程序协议字段、已安装辅助程序摘要、设置或存储数据。取消的范围观察仍然有界；未完成的观察保留不确定占用，直到后续确认。参见[提供方参考](../../../../packages/ssh/subprocess-ssh/README.zh.md)。
