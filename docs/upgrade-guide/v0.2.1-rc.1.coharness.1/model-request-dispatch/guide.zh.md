# 在请求派发前保留模型授权

[English](guide.md) | 中文

## 变更

`LlmAdapter.stream()` 和 `PreparedAdapterCall.stream()` 接收可选的 `dispatchRequest` 回调。运行时调用会传入它，在异步凭据、附件和请求扩展准备完成后重新检查保留的授权。DeepSeek 和 pi-ai 实现这些检查；准备期间被撤权的请求会在提供方派发前失败。不携带回调的直接适配器执行保留其独立行为。

## 迁移

1. 更新外部适配器和预备调用包装器，接收并转发第二个参数。在异步准备完成后用它包装每次提供方请求；提供方重试时重复检查。
2. 将回调拒绝保留为原始结构化失败，不要转为传输恢复、图片回退或成功完成。
3. 使用凭据解析屏障验证：在返回凭据前撤销访问，确认适配器不发送提供方请求，并释放资源许可。
