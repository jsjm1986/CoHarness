# 会话写入在等待后复核当前权限

[English](guide.md) | 中文

## 变更

项目会话物化和带参与者归属的消息持久化，会在数据库锁等待后复核当前组织成员资格与项目权限。移除成员、撤销管理员角色或降为只读期间暂停的请求，会以 HTTP 403 被拒绝。此前请求可能沿用旧权限提交，或返回内部错误。维护空间的交互应答抢占及持久化，也会在等待后要求当前管理员角色及启用资格。

浏览器子会话目录、提示和中断请求也保留最初授权的协作提供方。撤下会以 `collaboration-forbidden`、原因 `gateway-unavailable` 拒绝等待中的读取及 inbox 接受前的投递；重新加载的提供方只授权新请求。已接受的消息继续独立执行。

## 迁移

1. 通过既有[部署流程](../../../../gateway/README.zh.md)部署 Gateway。已有会话保留格式和数据。
2. 自定义持久化客户端需将 HTTP 403 作为权限拒绝处理，重试前刷新空间权限。未提交的批次仍不存在；搜索、贡献和事件行一起回滚。
3. 确认当前写入成员可以持久化消息，再确认已移除或只读账户无法新增事件。参见[协作决策](../../../../.agents/notes/implemented/feature/2026-08-15-project-collaborative-conversations.zh.md)。
