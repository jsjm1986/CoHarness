# 升级模型发现重定向

[English](guide.md) | 中文

## 变更

pi-ai 和 Gateway 的模型发现仅跟随配置地址内的同源重定向。主机、协议或端口变化会在下一次请求前返回 `DISCOVERY_FAILED`；URL 内凭据也会被拒绝。这保护了 Fetch 过去会跨源转发的 Anthropic API 密钥和部署鉴权请求头。同源路径跳转继续可用，并保留有界的跳转次数和调用方取消。

此规则适用于组织及项目模型设置中的已保存凭据和草稿凭据。它不改变模型生成请求的传输行为。

## 迁移

1. 核对预期的最终 Provider 端点。在 `settings.yaml` 或 Gateway 模型设置中直接填写其 `baseURL`，保留部署路径；为其配置凭据前先确认目标地址。
2. 重新执行模型发现。同源跳转返回目录；跨源跳转返回发现错误，且不会访问其目标地址。如果部署无法在配置的源地址提供发现接口，请手动填写模型信息。

无需迁移已保存数据，也不新增配置字段。参见 [LLM 服务](../../../../packages/llm/llm/README.zh.md)。
