# 升级 SSH 目标管理

[English](guide.md) | 中文

## 变更

SSH 目标读取、注册、连接配置变更、启停／移除和管理端共享，在数据库事务内保留当前活跃管理员资格。失去管理员资格的账号不能沿用先前的 HTTP 检查继续执行，即使该账号拥有项目。拒绝的操作返回403，不修改目标或共享。

项目自助 SSH 目录和共享要求活跃组织与账号，以及当前管理员身份或活跃项目所有权。目标 revision 校验、凭据引用保留及清除的含义不变。

## 迁移

1. 升级完整 Gateway 构建。这项权限校验不改变数据库迁移和浏览器请求字段。
2. 收到403后，刷新当前账号角色与组织状态。项目所有者使用项目自助入口，目标管理仍要求管理员身份。
3. 同时验证当前管理员、项目所有者，以及撤权前已排队的请求。参见 [Gateway SSH 规则](../../../../gateway/README.zh.md)。
