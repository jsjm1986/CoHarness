# 升级工作台电脑权限

[English](guide.md) | 中文

## 变化

账户工作台目录中的每条个人根会话，都要求该 Session 精确 Runtime 分配所属电脑的当前使用权限。另一台电脑的授权不能暴露其标题、工作目录或其他元数据。个人 Runtime 无法列出 Session、工作台返回数据库中的账户元数据时，也执行同样的检查。

撤销一台电脑的权限会隐藏其个人根会话，并保留其他电脑上已授权的根会话。其他账号及项目对话规则保留既有可见性。未知或已退役的 Runtime 分配不能建立当前电脑权限。个人列表不可用时仍标记结果不完整，因此缺失不能证明 Session 已删除。

「全部空间」搜索本标签页已载入且有权访问的个人及项目对话。选择具体的个人 Runtime 或项目可以继续分页搜索。账号 Runtime 目录支持用 `projectId` 精确查找尚未出现在已载入分页中的项目。新窗格使用所选 Runtime 确认的创建回执和工作区，单独打开已有对话时重新验证访问权限。

## 迁移

1. 一起升级完整 Gateway 和 Runtime 包。应用 PostgreSQL 迁移 `104_personal_conversation_catalog.sql`，它添加可空的个人对话元数据，不改变 Session 代际、文件或 Runtime 身份。已运行的个人 Runtime 在重启后发布摘要，已停止的 Runtime 在明确启动时发布。读取选择器不会启动它们。
2. 确认两台已授权电脑的个人根会话均可见，撤销一台电脑后，验证其标题和工作目录消失，另一台电脑仍可使用。
3. 在个人 Runtime 不可用时重复验证，并检查独立账号的目录仍保持隔离。参见 [Gateway 参考](../../../../gateway/README.zh.md)。
