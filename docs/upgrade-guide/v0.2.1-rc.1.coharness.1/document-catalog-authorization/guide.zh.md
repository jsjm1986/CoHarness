# 文档目录访问要求当前权限

[English](guide.md) | 中文

## 变更

文档同步、移入回收站、永久清理及所有权转移会拒绝数据库等待期间已撤销的权限。管理员生命周期操作同样拒绝已停用或降级的管理员；批量 HTTP 响应保留逐文档失败结果。此前，这些事务可能使用等待前读取的权限提交。

Steward 元数据、历史及成员修改同时要求当前管理员成员身份与已启用的 Steward 资格。用户文档总览的列表、总数及统计排除不可访问的 Steward 文档和已归档项目；管理员检查保留企业范围的审计元数据。此前成员总览可能暴露这些条目。

批量目录移除在权限修订更新之前锁定初始活跃行，并保留等待期间提交的登记。并发生命周期写入可以与批量操作一同完成；此前的取锁顺序可能因数据库死锁返回 HTTP 503。

## 迁移

1. 按[部署流程](../../../../gateway/README.zh.md)部署 Gateway。无需迁移数据库结构或文档文件。
2. 自定义目录客户端必须将 HTTP 403 视为权限拒绝，并检查每一项管理员批量结果。重试前刷新当前访问权限。数据库拒绝会回滚目录变更与历史；目录回调之前已完成的文件系统操作仍可能需要对账。
3. 通过 Steward 管理页面，仅向当前管理员授予 Steward 资格。确认符合资格时访问成功，撤权或降级后不能读取 Steward 元数据或修改其目录。详见[文档生命周期决策](../../../../.agents/notes/implemented/architecture/2026-08-27-document-index-pagination-and-trash-lifecycle.zh.md)。
