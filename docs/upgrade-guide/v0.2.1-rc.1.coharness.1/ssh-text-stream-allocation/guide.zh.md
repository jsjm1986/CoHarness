# 开始消费 SSH 文本流后再分配远端名额

[English](guide.md) | 中文

## 变更

`SshFileSystem.streamText()` 返回的可迭代对象在第一次拉取时预留远端迭代器。关闭、向其抛出错误或取消尚未读取的可迭代对象，都不会占用辅助程序的文本流名额。此前丢弃未读取的可迭代对象可能留下远端预留，最终导致其他读取被拒绝。

流准入和文件错误在迭代期间报告。辅助程序协议、容量上限、版本检查和文本内容保持兼容。

## 迁移

1. 重新构建 SSH 文件系统实现。本次变更不要求升级辅助程序协议。
2. 在 `for await` 循环或迭代器拉取处捕获错误，包括第一次拉取。仅等待 `streamText()` 不会预留或验证远端读取。
3. 提前停止时继续关闭已开始的迭代器；`for await` 在 break 时会执行此清理。
