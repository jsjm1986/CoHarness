# 升级远程桌面管理

[English](guide.md) | 中文

## 变更

Gateway 端点、授权及审计操作保留当前活跃组织管理员。角色、账号、成员身份或组织被撤销前已排队的请求返回403，不修改文件。新授权记录该保留账号的当前用户名。

Gateway 与 VNC 运行时授权写入共用本地写锁，每次变更前重读已提交行。插入和级别变更保留其他写入者的撤销及授权。端点与授权缓存识别保留修改时间的替换文件。状态文件读取错误返回503，不会覆盖已有数据进行初始化。数据库权限连接丢失会在 rename 尝试前取消文件发布。

## 迁移

1. 一起升级 Gateway 和 VNC 运行时提供方。文件格式与浏览器请求字段不变。
2. 外部授权写入者必须使用同一把本地 `grants.jsonl` 写锁及原子替换。不支持不同主机或 PID 命名空间共享路径；每份状态目录由其所属节点管理。
3. 收到403后刷新账号当前资格。收到503后修复状态文件或数据库故障，重试前先读取当前状态：已发起的 rename 即使遇到失败响应仍可能提交。
4. 验证当前管理员、已撤权管理员拒绝，以及独立写入者之间的撤销保留。参见[提供方规则](../../../../packages/remote-desktop/remote-desktop-vnc/README.zh.md)与 [Gateway 管理](../../../../gateway/README.zh.md)。
