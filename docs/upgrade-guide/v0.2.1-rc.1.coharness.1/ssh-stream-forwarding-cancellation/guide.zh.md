# SSH 流取消确认转发清理

[English](guide.md) | 中文

## 变化

OpenSSH 完成转发后取消流，即使客户端套接字尚未创建，也会移除预留。转发取消或本地套接字路径移除失败时，连接会失效，并等待原生传输的退出观察。分配与清理的独立失败仍然可见；原生清理未获确认时保留私有目录。

## 迁移

重新构建 Host SSH 包及其匹配的分发产物。此 Host 修复不改变辅助程序协议字段或摘要。连接失效后不能继续使用，也不要重放结果不明的远端操作。参见 [SSH 参考](../../../../packages/ssh/ssh/README.zh.md)。
