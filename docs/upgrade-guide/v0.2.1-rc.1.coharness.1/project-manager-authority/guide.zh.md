# 升级项目管理权限

[English](guide.md) | 中文

## 变更

项目名称、主题、Provider 及凭据变更在数据库事务内授权认证参与者。浏览器早先检查之后发生的所有权或账户变更，不能授权新的写入。已经保留权限的数据库变更会在冲突的角色变更提交前完成。模型发现以同样权限检查凭据准备，并在 HTTP 目录探测前释放事务。

管理员成员覆盖操作也会在写入事务中重新检查当前有效的管理员角色。早先 HTTP 检查之后发生的降权或账户停用，不能授权这些覆盖操作，即使该账户拥有项目。管理员权限拒绝返回403、保留项目数据并记录失败尝试。

## 迁移

升级完整的 Gateway 构建，包含 PostgreSQL 权限帮助模块。数据库 schema、项目数据及浏览器请求字段保持不变。自定义服务消费方应向管理变更、成员覆盖及发现准备传入认证账户 id；省略该参数仅供受信任的内部维护使用。浏览器提供的参与者 id 不能代替认证。

收到403后重新打开项目设置，以刷新当前所有权及能力。验证当前所有者可以更新项目，旧所有者不能修改数据或凭据。参见 [Gateway 管理规则](../../../../gateway/README.zh.md)。
