# 升级项目管理权限

[English](guide.md) | 中文

## 变更

项目名称、主题、Provider 及凭据变更在数据库事务内授权认证参与者。浏览器早先检查之后发生的所有权或账户变更，不能授权新的写入。已经保留权限的数据库变更会在冲突的角色变更提交前完成。模型发现以同样权限检查凭据准备，并在 HTTP 目录探测前释放事务。

管理员成员覆盖操作也会在写入事务中重新检查当前有效的管理员角色。早先 HTTP 检查之后发生的降权或账户停用，不能授权这些覆盖操作，即使该账户拥有项目。管理员权限拒绝返回403、保留项目数据并记录失败尝试。

项目模型读取在准备完成后重新检查当前账户、成员资格、项目及目标电脑访问权限。强制改密和维护空间资格撤销也会拒绝返回数据。仍保留成员资格的旧所有者收到只读设置和凭据状态；发现结果要求当前管理权限。已发出的目录请求可以完成，但撤权后不会返回其元数据。

共享管理[改密资格](../user-administration-authority/guide.zh.md)也在权限等待后适用；重试排队的管理操作前须完成要求的改密。

项目目录、详情、配置与项目邀请在准备完成后重新检查当前浏览器资格。已撤权目录条目会消失，其他已撤权读取返回403。所有者、主题与能力采用当前权限。项目邀请列表在管理权失效后不再返回其他账号的邀请；仍有资格的成员保留本人收发邀请的历史。项目电脑变化后需要重新读取；Steward 空间返回 `members: false`。

账号邀请历史与待处理数量重新核验浏览器会话有效性，包括注销、过期和要求改密。项目或电脑权限失效后，账号保留本人的收发历史。其他账号之间的邀请要求当前管理权限及自定义项目读取提供方；提供方失败时不返回数据。

## 迁移

升级完整的 Gateway 构建，包含 PostgreSQL 权限帮助模块。数据库 schema、项目数据及浏览器请求字段保持不变。自定义服务消费方应向管理变更、成员覆盖及发现准备传入认证账户 id；省略该参数仅供受信任的内部维护使用。浏览器提供的参与者 id 不能代替认证。

自定义项目模型服务实现还需提供 `authorizeProjectModelRead(projectId, actorUserId)`。它依据当前账户及目标电脑权限返回读取者的管理标记或拒绝读取，且不异步加载节点元数据。Gateway 在每次读取数据准备完成后调用该方法；缺少此能力的实现返回501。

自定义协作适配器提供 `projectReadAuthorities(userId, projectId?)`，不执行电脑 I/O，返回当前所有者、主题与管理标志。初始与最终项目视图应一致地保留 `nodeId`。省略项目 id 时选择当前目录，提供时选择单个项目。缺少提供方时返回501，查询失败时返回503，不携带已准备的元数据。已有 Runtime 授权方法保留原有行为。

收到403后重新打开项目设置，以刷新当前所有权及能力。验证当前所有者可以更新项目，旧所有者不能修改数据或凭据。参见 [Gateway 管理规则](../../../../gateway/README.zh.md)。
