# 跟随当前语音偏好存储

[English](guide.md) | 中文

## 变化

语音偏好跟随当前挂载的 Settings 提供方。撤回提供方后恢复组合默认值，并在替代提供方就绪前拒绝保存。替换后读取新提供方自己的持久值，后续保存写入其文件。就绪状态观察者会收到这些变化，语音识别无需重启。

## 迁移

重新构建语音服务。替换 Settings Loader 条目后，等待其启动完成再保存偏好。若保存报告提供方变化，原文件可能已经写入；保留已提交数据，等待当前提供方就绪后重试。现有 `speech-to-text` 命名空间字段与存储文件无需迁移，不需要更改 Session 格式或数据库版本。
