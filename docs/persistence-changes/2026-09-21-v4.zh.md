<a id="compatibility"></a>
## 兼容性

写入器推进到 Session 格式版本 4。物理 header 移除 `draft` 与 `seedLength` 并要求 `isSeeded`；独立的 `assistant/chunk` 行被移除，助手 token 流以 `stream` 记录内嵌于 `assistant/message` 与 `assistant/attempt`；`tool/code-dispatch` 与 `tool/code-dispatch-start` 由 PTC 派发事件取代；消息内容块联合类型以及 `system/message`、`request/header`、`turn/end`、`session/end-seed` 负载已修订。V3 读取方无法消费 V4 日志；[V3 到 V4 迁移库](../../packages/session/session-format-v3-to-v4)负责读取 V3 输入。

<a id="verification"></a>
## 验证

V3 到 V4 迁移库在 V3 声明的 fixture 上携带转换器 spec，覆盖流内嵌、header 收窄与内容联合改写。`pnpm run verify-persistence-formats` 在当前检出处验证 V0 至 V3 全部历史格式以及当前 V4 目录。
