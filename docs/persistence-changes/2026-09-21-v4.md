<a id="compatibility"></a>
## Compatibility

The writer advances to Session format version 4. The physical header drops `draft` and `seedLength` and requires `isSeeded`; the standalone `assistant/chunk` row is removed and assistant token streams live embedded as `stream` records on `assistant/message` and `assistant/attempt`; `tool/code-dispatch` and `tool/code-dispatch-start` are superseded by the PTC dispatch events; message content-block unions and the `system/message`, `request/header`, `turn/end`, and `session/end-seed` payloads are revised. V3 readers cannot consume V4 logs; the [V3-to-V4 migration library](../../packages/session/session-format-v3-to-v4) owns reading V3 inputs.

<a id="verification"></a>
## Verification

The V3-to-V4 migration library carries converter specs over V3-declared fixtures, including stream embedding, header narrowing, and content-union rewriting. `pnpm run verify-persistence-formats` validates every historical format V0 through V3 plus the current V4 inventory against this checkout.
