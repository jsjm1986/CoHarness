# 上游发布说明逐条对账 — 截至 dsh-v0.2.1-alpha.4

## 范围与方法

- 输入：GitHub Releases 上 28 个发布（`dsh-v0.1.0-rc.7` → `dsh-v0.2.1-alpha.4`）的中文/英文发布说明，共 729 条；rc 发布说明为周期累计汇总，按文本相似度去重后 558 条独立条目（重复条目继承原条目判定并注明「同 …」）。
- 证据：完整上游历史（非浅克隆）中每个发布区间的 1,224 个 PR 合并提交；对每个 PR 计算「新增且在 alpha.4 仍存活的产品源码行」在本地树中的存在比例（同路径优先，长行允许跨文件命中；排除测试、夹具、生成物与注释散文行），并单列用户可见文案行的存在比例。
- 本地比较基线：栈顶 `01cfc99db9d`（`origin/master` `015f4cd6478` + 未合并 PR #286/#287/#288/#291/#292）。
- 每条判定在机械证据之上人工复核：按关键词与作者匹配 PR、对存疑条目做定点源码探测，并与 `upgrades/alignment/` 既有审计裁决（rc.1 业主决定、alpha.2 审计的有意分歧与观望项）交叉核对。标注「需核实」的条目只有源码证据，未做运行时验收。

## 判定口径

| 代码 | 含义 |
|---|---|
| N | 缺失 |
| P | 部分 |
| R | 替换面未跟进 |
| ? | 未定位 |
| S | 已被取代 |
| L | 有意分歧/本地替代 |
| X | 不适用 |
| Y | 已有 |

价值：高 = 正确性/可靠性且影响生产；中 = 用户可感知或平台能力；低 = 打磨、边缘场景或开发者面。
