# @deepseek-ai/dsh-archive-gateway

[English](README.md) | 中文

把 Gateway 启动的运行时中的 Workspace 归档快照同步到 Gateway 归档索引。提供方发送带版本的会话 ID 快照、根会话谱系、会话头、原 Workspace 位置、消息数量以及标题/正文搜索投影；Gateway 下发的命令在下一次成功同步时应用。

提供方还注册仅限 loopback 的 `/api/internal/archive/read` 路由。Gateway 签发的归档能力可以按需读取个人根会话及其子会话；该路由不接受浏览器来源请求或非管理员断言。

这是仅供运行时使用的集成。独立启动的本地 DSH 不加载该提供方，继续使用本地归档注册表。

## 模型体验

没有影响。该提供方只读取和同步已经记录的会话状态，不增加提示词、工具或模型请求字段。

#### KV Cache 影响

没有影响。它不组装模型请求，也不改变可复用前缀。

## 已知限制与延期工作

- 只有使用 Gateway 凭据启动的运行时才会同步；独立的本地组合继续使用原有归档行为。
- 所属运行时不可用或持久化日志损坏时，个人正文无法读取；Gateway 会保留归档索引行并报告正文不可用。
