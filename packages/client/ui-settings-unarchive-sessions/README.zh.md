# @deepseek-ai/dsh-client-ui-settings-unarchive-sessions

[English](README.md) | 中文

Web 设置中的**已归档会话**页面：从 Workspace 导航中隐藏的会话在此恢复。浏览器插件注册一个 id 为 `archived-sessions` 的本地化 `settings.section` 贡献，排在最末；设置外壳拥有导航入口与分区框架。页面按归档时间倒序列出每个已归档会话及其所属 Workspace 与最后活动时间，每行提供一个“取消归档”操作；搜索框可按会话标题或 Workspace 名称过滤。

行数据由注册表全局归档集合与已加载的会话摘要连接得出，因此归档集合中会话记录已不存在的条目没有对应行，也没有操作。页面先等待会话列表就绪再渲染行；归档为空、归档条目全部无法恢复、查询无匹配分别给出三种不同提示。每次恢复都走 `ctx.workspaces.unarchiveSession`，其回传的归档集合会更新所有按它过滤的界面，因此会话同时重新出现在侧栏与搜索中。调用被拒绝时记录为控制台诊断，行保持原位可重试。注册使用 `ctx.slots.inject()`，因此能跟随分区 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 概述

**已归档会话**设置页用于恢复在所有分组界面中被隐藏的会话。它按归档时间倒序列出归档集合，展示每个会话所属的 Workspace（或“未分组”）与最后活动时间，支持按标题或 Workspace 搜索，并通过共享的 Workspace 命令逐行恢复。恢复后，会话回到其记录的 Workspace 位置；若不属于任何 Workspace，则回到未分组会话中。

## 不变量

**运行不变量：** 不发布伴生包。本页面注册一个本地化的 `settings.section` 贡献及其 locale 命名空间；不发出 Cordis 事件，也不拥有跨插件的可变关系。

## Model Experience

无——本包是浏览器侧 UI 插件层，不注册任何面向模型的内容。

#### KV Cache 影响

无；本包既不组装也不发送 provider 请求。

## 已知限制与后续工作

- **没有已加载摘要的已归档会话无法恢复** —— 页面通过归档集合与会话列表的连接得出行，列表未携带的成员没有对应行和“取消归档”操作，尽管归档集合仍持有它；当集合中全部成员都处于该状态时，页面报告为“不可恢复”而非“空”。
- **页面只列出会话；不提供会话删除** —— 归档可通过本页面撤销，而删除会话记录是另一项独立能力。
