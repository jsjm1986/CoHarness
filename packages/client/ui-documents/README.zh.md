# @deepseek-ai/dsh-client-ui-documents

CoHarness Web UI 的工作区文档管理器。整理、预览、上传、移动、下载、删除，并将已存储文档加入对话输入框。

[English](README.md) | 中文

## 安装

本包是 `@deepseek-ai/dsh-client-ui-documents` 功能包的一部分，由 web-app profile 自动加载。

## 使用方法

插件在侧边栏底部（工作区切换按钮旁）添加一个**文档**按钮。窄栏只显示图标和工具提示；展开侧边栏时图标旁显示「文档」。点击后打开当前工作区（个人或项目）的管理弹窗。

对话框在桌面端是全高工作台，在手机端是紧凑的全屏工作台。桌面端保留作用域侧栏和行内操作；紧凑布局使用当前作用域按钮、底部作用域选择层，以及承载筛选和次要操作的“更多”层。每个操作层只有一个标题行和一个滚动区域，管理器中的文档列表仍是主页面唯一的滚动区域。上传是紧凑工具栏的主操作，视觉上使用短标签但保留完整无障碍名称；上传和桌面拖放都会进入当前文件夹。说明行写出个人或项目可见性以及筛选后的文档数量。复制流程使用元数据计划、目标文件夹选择器和逐文件重试。

选择其他个人或可写项目作用域时，管理器和当前对话保持不变。Gateway 作用域 broker 会为所选作用域重新检查浏览、预览、下载、上传、文件夹、移动、回收、恢复和永久清理权限；只读项目仍可浏览和预览，但会禁用写操作。从非当前作用域加入对话时，会先把快照复制到当前对话作用域再附加。全部作用域汇总视图会先要求选择上传目标，不会在没有目标时直接上传。

文档元数据读取遇到运行时启动中的临时响应时，会按服务端的 `Retry-After` 延迟重试，之后才显示本地化的作用域不可用提示。上传和复制写操作不会自动重放。

作用域和文件夹读取期间会保留最后一次已提交的行，直到新结果可用。持续挂载的管理器保留按作用域隔离的有界元数据缓存：30 秒内获取的条目会直接显示且不再发起列表请求；五分钟内的旧条目会直接显示并在后台重新校验；更早的条目会被移除。显式刷新和文档变更会使列表缓存失效；重新校验失败时仍保留可见行并显示可重试错误。该缓存只存在于当前页面内存中，不保存文档字节，也不会跨浏览器刷新保留。

选中一个或多个文档后选择“复制到其他作用域”，即可把快照复制到可写项目或个人文档。管理器只展示安全的作用域名称；Gateway 负责授权与流式传输，目标冲突不会覆盖已有文件，并逐个返回结果。复制到当前对话作用域的目标文档可以作为不拥有文件的草稿附加到当前 composer；复制到其他作用域的文件会留在那里，之后可从该作用域选择使用。

composer 中的文档控件会打开同一个管理器，因此从输入栏发起的复制会通过管理器附加命令回到当前草稿。

管理器可以把已授权的其他个人／项目源以安全元数据行展示。选择作用域时会继续使用当前管理器弹窗，不会打开第二个浏览器或模态窗口。预览、下载、上传、移动、回收、恢复、永久清理、文件夹和加入对话操作由所选作用域权限决定；从非当前作用域加入对话会先复制快照到当前对话作用域。全部作用域视图不会暴露文件字节或主机路径，每行都可以复制到可写目标，并选择或创建目标文件夹。

文件夹行可打开文件夹，并提供重命名和删除；删除需要确认，而且只允许空文件夹。文档行显示复选框、省略后的名称、大小、日期和一个“更多”入口。紧凑操作层会根据作用域权限展示加入对话 / 预览 / 移动 / 下载 / 删除。加入对话直接引用已存储文档，不会重复上传。移动可作用于一个文档或当前所选文档，目标包含根目录和全部文件夹。紧凑多选使用避开安全区的批量操作条和操作层；所有紧凑控件保持 44px 触控热区，长名称不会与操作重叠。

文档按名称和类型（图片、PDF、文本、其他）筛选，按日期、名称或大小排序，每页 20 行；仅按日期排序时分组。复选框可跨页选择；批量移动和删除都逐个 id 请求。管理器的“回收站”视图列出可恢复文档，按不冲突名称恢复，并在确认后永久清理；过期日期由提供方保留策略决定。预览支持图片、PDF 和文本文件（文本上限 256 KiB）；其他类型提示下载。当网关 `GET /account/api/context` 返回项目空间时，标题使用项目名，说明行写明成员共享，删除确认附加全员影响说明；协作路由缺失时保持个人空间标题。

桌面端和移动端使用同一套可续传上传协议。小文件使用一个分片；更大的文件拆成 8 MiB 分片，并校验每个分片及最终文件的 SHA-256。网络中断不会丢弃已经完成的分片；运行时保留会话期间，重新选择同一文件即可继续。浏览器只保存不透明的会话元数据，不保存文档字节。

## 范围隔离

文档按运行时范围隔离存储：

- **个人空间**：`$HOME/documents/`
- **项目空间**：`<项目目录>/documents/`

文件夹是真实目录，模型可通过常规文件系统工具查看。后端 API（`/api/documents`）由 `@deepseek-ai/dsh-host-userdoc-http` 和 `@deepseek-ai/dsh-userdoc-local` 提供；旧 `uploads` 的迁移规则见本地后端 [README](../../attachment/userdoc-local/README.zh.md)。

## 模型体验

### 文档管理器

#### 模型可见内容

浏览器在侧边栏底部显示文档按钮。打开后通过 `/api/documents` 展示当前工作区的文档文件夹，提供面包屑导航、文件夹管理、名称与类型筛选、排序、每页 20 行、加入对话、预览、移动、下载、回收、恢复、永久清理、多选和当前文件夹上传。选择其他已授权作用域后管理器保持打开，并通过 Gateway 按该作用域权限执行相同的元数据与生命周期操作；从非当前作用域加入对话时会先复制快照到当前对话作用域。加入对话在当前会话接受后把已有文档 id 放入输入框，并关闭管理器。默认上传策略不限制单个文档大小；消息数量和消息总大小仍由部署策略保护。

#### Token 影响

管理器是纯客户端界面；它不向会话上下文或模型请求增加任何 token。上传的文档仅在用户将其附加到消息时进入模型转录。

#### KV 缓存影响

管理器读写的是与对话附件相同的持久 `/api/documents` 存储，因此已上传的文档无需重新上传即可跨会话使用。短期浏览器元数据缓存只影响列表显示，不影响模型 KV 缓存。

## 已知限制与待办

- 预览仅支持图片、PDF 和基于文本的文件；其他媒体类型显示下载替代提示。
- 文本预览上限为 256 KiB；更大的文本文件需要下载查看。
- 删除文档不会重写会话历史，因此之前引用该文档的消息在删除后无法再取回其内容。
- 跨作用域复制是快照而不是实时同步；在两个作用域均已授权时支持项目到项目复制。
- 当前文件夹和全部作用域列表在提供方支持时使用有界服务端分页与不透明游标；旧提供方仍可通过浏览器本地分页使用。管理器持续挂载期间会保留已加载页面。
- 移入回收站的文档只在提供方保留窗口内可恢复；永久清理不可撤销，活动文档仍会一直保留到删除。
- 只能删除空文件夹；界面不递归删除目录树。
