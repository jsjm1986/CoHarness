# @deepseek-ai/dsh-client-ui-documents

CoHarness Web UI 的工作区文档管理器。整理、预览、上传、移动、下载、删除，并将已存储文档加入对话输入框。

[English](README.md) | 中文

## 安装

本包是 `@deepseek-ai/dsh-client-ui-documents` 功能包的一部分，由 web-app profile 自动加载。

## 使用方法

插件在侧边栏底部（工作区切换按钮旁）添加一个**文档**按钮。窄栏只显示图标和工具提示；展开侧边栏时图标旁显示「文档」。点击后打开当前工作区（个人或项目）的管理弹窗。

对话框在桌面端是全高工作台，在小屏幕上自适应为面板。作用域侧栏可以在个人文档、每个已加入项目和仅显示元数据的“全部授权范围”之间切换，覆盖层保留后面的会话上下文。面包屑显示当前文件夹。工具栏包含名称搜索、类型和排序下拉框、新建文件夹、上传、刷新和当前作用域历史；上传和桌面拖放都会进入当前文件夹。说明行写出个人或项目可见性以及筛选后的文档数量。复制流程使用元数据计划、目标文件夹选择器和逐文件重试。

选中一个或多个文档后选择“复制到其他作用域”，即可把快照复制到可写项目或个人文档。管理器只展示安全的作用域名称；Gateway 负责授权与流式传输，目标冲突不会覆盖已有文件，并逐个返回结果。复制成功的目标文档可以作为不拥有文件的草稿附加到当前 composer。

composer 中的文档控件会打开同一个管理器，因此从输入栏发起的复制会通过管理器附加命令回到当前草稿。

管理器可以把已授权的其他个人／项目源以只含元数据的行展示。选择作用域时会继续使用当前管理器弹窗，并明确标记为只读视图，不会打开第二个浏览器或模态窗口。其他作用域的行只允许选择和复制，预览、下载、移动和删除始终绑定当前运行时存储。全部作用域视图不会暴露文件字节或主机路径，每行都可以复制到可写目标，并选择或创建目标文件夹。

文件夹行可打开文件夹，并提供重命名和删除；删除需要确认，而且只允许空文件夹。文档行显示复选框、省略后的名称、大小，以及加入对话 / 预览 / 移动 / 下载 / 删除。加入对话直接引用已存储文档，不会重复上传。移动可作用于一个文档或当前所选文档，目标包含根目录和全部文件夹。紧凑布局把文档操作换到名称下方，避免 44px 触控热区与长名称重叠；320px 工具栏使用明确的搜索／筛选／操作轨道，使刷新按钮与主要操作保持对齐。

文档按名称和类型（图片、PDF、文本、其他）筛选，按日期、名称或大小排序，每页 20 行；仅按日期排序时分组。复选框可跨页选择；批量移动和删除都逐个 id 请求。预览支持图片、PDF 和文本文件（文本上限 256 KiB）；其他类型提示下载。当网关 `GET /account/api/context` 返回项目空间时，标题使用项目名，说明行写明成员共享，删除确认附加全员影响说明；协作路由缺失时保持个人空间标题。

## 范围隔离

文档按运行时范围隔离存储：

- **个人空间**：`$HOME/documents/`
- **项目空间**：`<项目目录>/documents/`

文件夹是真实目录，模型可通过常规文件系统工具查看。后端 API（`/api/documents`）由 `@deepseek-ai/dsh-host-userdoc-http` 和 `@deepseek-ai/dsh-userdoc-local` 提供；旧 `uploads` 的迁移规则见本地后端 [README](../../attachment/userdoc-local/README.zh.md)。

## 模型体验

### 文档管理器

#### 模型可见内容

浏览器在侧边栏底部显示文档按钮。打开后通过 `/api/documents` 展示当前工作区的文档文件夹，提供面包屑导航、文件夹管理、名称与类型筛选、排序、每页 20 行、加入对话、预览、移动、下载、删除、多选和当前文件夹上传。加入对话在当前会话接受后把已有文档 id 放入输入框，并关闭管理器。默认上传策略不限制单个文档大小；消息数量和消息总大小仍由部署策略保护。

#### Token 影响

管理器是纯客户端界面；它不向会话上下文或模型请求增加任何 token。上传的文档仅在用户将其附加到消息时进入模型转录。

#### KV 缓存影响

管理器读写的是与对话附件相同的 `/api/documents` 存储，因此不存在独立缓存，已上传的文档无需重新上传即可跨会话使用。

## 已知限制与待办

- 预览仅支持图片、PDF 和基于文本的文件；其他媒体类型显示下载替代提示。
- 文本预览上限为 256 KiB；更大的文本文件需要下载查看。
- 删除文档不会重写会话历史，因此之前引用该文档的消息在删除后无法再取回其内容。
- 跨作用域复制是快照而不是实时同步；在两个作用域均已授权时支持项目到项目复制。
- 列表没有服务端分页；每次完整返回当前文件夹，文档由浏览器分页。
- 只能删除空文件夹；界面不递归删除目录树。
