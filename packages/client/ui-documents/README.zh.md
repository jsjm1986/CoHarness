# @deepseek-ai/dsh-client-ui-documents

CoHarness Web UI 的工作区文档管理器。浏览、预览、上传、删除对话输入框中上传的文档。

[English](README.md) | 中文

## 安装

本包是 `@deepseek-ai/dsh-client-ui-documents` 功能包的一部分，由 web-app profile 自动加载。

## 使用方法

插件在侧边栏底部（工作区切换按钮旁）添加一个**文档**按钮。窄栏只显示图标和工具提示；展开侧边栏时图标旁显示「文档」。点击后打开当前工作区（个人或项目）的管理弹窗。

视口宽度至少 768px 时弹窗为 560px 卡片；更窄时为全宽底部抽屉（Modal 挂在 `document.body`，看不到外壳的 `data-viewport`，因此用 `(max-width: 767px)` 与 `(pointer: coarse)` 分支）。限额显示在标题下方。工具栏包含名称搜索、选完即传的上传按钮，以及刷新图标。紧凑视口下搜索独占一行，上传按钮在其下拉满。精细指针可在桌面把文件拖进列表；粗指针不显示拖放层。

每行显示文件图标、可省略的名称、大小，以及预览 / 下载 / 删除。紧凑视口和粗指针隐藏操作文字、把热区放大到 44px，读屏名称仍带文件名。预览支持图片、PDF 和文本文件（文本上限 256 KiB）；其他类型提示下载。当网关 `GET /account/api/context` 返回项目空间时，标题使用项目名，删除确认附加全员影响说明；协作路由缺失时保持个人空间标题。

## 范围隔离

文档按运行时范围隔离存储：

- **个人空间**：`$HOME/uploads/<YYYY-MM-DD>/<filename>`
- **项目空间**：`<项目目录>/uploads/<YYYY-MM-DD>/<filename>`

后端 API（`/api/documents`）由 `@deepseek-ai/dsh-host-userdoc-http` 和 `@deepseek-ai/dsh-userdoc-local` 提供。

## 模型体验

### 文档管理器

#### 模型可见内容

浏览器在侧边栏底部显示文档按钮。打开后在当前对话上方弹出弹窗，通过 `/api/documents` 接口列出当前工作区（个人或项目运行时）上传的所有文档，按上传日期分组，每行提供预览、下载和删除操作，并带有上传控件和名称筛选。

#### Token 影响

管理器是纯客户端界面；它不向会话上下文或模型请求增加任何 token。上传的文档仅在用户将其附加到消息时进入模型转录。

#### KV 缓存影响

管理器读写的是与对话附件相同的 `/api/documents` 存储，因此不存在独立缓存，已上传的文档无需重新上传即可跨会话使用。

## 已知限制与待办

- 预览仅支持图片、PDF 和基于文本的文件；其他媒体类型显示下载替代提示。
- 文本预览上限为 256 KiB；更大的文本文件需要下载查看。
- 删除文档不会重写会话历史，因此之前引用该文档的消息在删除后无法再取回其内容。
- 文档管理器作用于当前运行时工作区；在个人与项目工作区之间切换时，仅显示对应工作区的上传内容。
- 管理器不提供多选、可排序表格、文件夹树或类型筛选。
