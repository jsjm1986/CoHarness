# @deepseek-ai/dsh-client-ui-memory

[English](README.md) | 中文

记忆浏览插件的浏览器侧：通过 `sidebarRightTabs` 注册的右侧栏 `memory` 标签页类型，从指南入口打开，按更新日分组的时间线列出持久记忆条目。标签页读取 `memory/*` Remote API（`ctx.remote.memory`）：`memory/scopes` 返回 runtime 提供的作用域——个人 runtime 中是个人作用域加上有条目的工作区作用域，项目 runtime 中是共享的项目作用域——并附带实时条目数与按调用者判定的 `writable` 标志；`memory/list` 返回所选作用域的全部条目。首次加载目录时，标签页优先选中 `directory` 与当前会话 `cwd` 相同的工作区作用域，使面板落在 Agent 写入的上下文上；之后的手动选择在目录刷新间保留。服务从 `memory` 设置段返回 `enabled`，因此标签页能解释为何所有 `writable` 标志都被拉低，而已存条目仍可查看。

条目按本地更新日分组（最新在前），展示条目的时刻、写入来源、成员 id、类型徽标，展开后可见更新时间、修订号前缀与完整 Markdown 正文。条目通过可由键盘操作的按钮展开，并向辅助技术提供展开状态。客户端搜索按 key、摘要与正文过滤；搜索和编辑控件具有程序化标签，键与摘要的提示关联为描述。紧凑与粗指针布局保留 44px 操作热区和至少 16px 输入文字。条目操作与错误信息使用在展开卡片上清晰可读的主文字色；彩色下划线区分普通与破坏性操作。类型徽标在明暗主题下均使用主文字色，并保留分类底色。原生选择框随文字增大，并保留系统选择器。可编辑的类型与正文字段沿用 Input 控件的清晰边框，禁用字段保留较淡的边界。窄面板将作用域选择框放在搜索和操作上方，保证查询文字可读。较矮的面板将选择框和搜索保留在同一行，并收紧时间线间距，让首条记忆可见且保留查询输入框的最小宽度。列表保留足以显示完整条目的高度，额外的工具栏或提示内容随外层面板滚动。较矮的停靠面板将工具栏、编辑器和页脚合为同一滚动区；紧凑的反馈间距保留空搜索结果的可见性，停用说明位于控件之前。正文字段适应面板可用高度且保留草稿。归因于 agent 写入的条目通过 `uiWorkspace.openSession` 链接到来源对话，并沿用 Schedule 页面的会话/工作区列表成员判定。仅当所选作用域报告 `writable` 时才渲染创建、编辑和删除控件；编辑器以条目 `revision` 为编辑与删除做并发保护，并发修改表现为 `memory_stale`。删除被拒绝或失败时保留条目与编辑草稿，播报错误并允许用户重试；写入期间禁用重复操作。时间线删除在操作换行时将删除与取消放在同一组。取消会将焦点还给条目展开按钮；取消或切换展开状态会清除本次确认和失败提示。转发的 `memory/changed` 事件与每次成功的写入都会重读目录与当前作用域；无订阅的标签页不持有任何 Remote 订阅。

一张 `plugins.item` 卡片通过 `ctx.settingsScope` 绑定 `memory` 设置命名空间，提供该段唯一的开关 `enabled`；关闭后 agent 不再看到作用域且一切写入被拒绝，已存条目仍可读取。变更等待期间显示并播报“保存中…”；写入被拒绝时保留已保存的设置，并播报原位重试提示。

`/client` 导出插件主体（`apply`/`inject`）、source 工厂与快照类型、卡片控制器以及注入面。

## 概述

Web GUI 新增右侧栏记忆标签页：成员可在个人与项目空间中浏览、搜索并在服务报告可写时编辑持久记忆；插件页新增一张可整体关闭该功能的卡片。

记忆页签按所属对话固定 Runtime，用于作用域发现、读取、写入和来源对话跳转。配置卡片保留当前文档的启动设置所有者，其他电脑的事件不能改变页签目标。

<a id="invariants"></a>
## Invariants

**运行时不变量：** 不发布伴随检查。条目、可写性与 enabled 标志归 Host 的 `memory` 服务所有，经 Remote 读取镜像；插件不持有业务状态。

<a id="model-experience"></a>
## Model Experience

无——本包是记忆服务之上的浏览器表面，不向模型请求注入任何内容；面向 agent 的目录与工具随记忆服务自身交付。

#### KV Cache 影响

无——插件不执行任何模型可见的操作。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- **客户端搜索**——页面只在已列出作用域的条目内本地过滤；跨全部作用域的 Remote `memory/search` 延后。
- **无分页**——作用域一次性渲染全部条目，由服务的每作用域条目上限兜底。
- **编辑器为单条目**——无批量编辑、导入或导出界面。
