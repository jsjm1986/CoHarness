# @deepseek-ai/dsh-client-ui-collaboration

[English](README.md) | 中文

Web 客户端的 Gateway 协作 UI。一个插件通过已有 Client slot 与会话创建 waterfall 事件，负责账户上下文 HTTP 状态、个人/项目 scope 选择器、根对话待用可见性、对话共享菜单，以及只读项目 composer 策略。

切换空间时，页面同时检查各输入框和打开对话期间暂存的文字。所属节点尚未确认写入或标签页保有离线文字时，离开前会提示。

Workbench 的共享、只读输入区选择及创建资格按窗格或请求的 runtime 判定，与页面当前空间独立。浏览器共享请求携带原始 Session ID、显式项目 ID 和该 Session 的 Runtime 分配身份；未限定身份的独立运行历史保留当前标签页 URL 选择的 Runtime。Gateway 在读取或修改可见性前核验项目与 Runtime。个人窗格不会继承项目窗格的只读状态或共享控件。

环境发现从账号验证后开始。待完成的读取和保留的分页归属于该账号和连接；账号变化或连接失效时会丢弃它们。统一空间入口追加目录分页，刷新时从首页重新读取，无需连接每台电脑。按账号隔离的浏览器偏好只保存收藏 Runtime ID 和最多八条最近使用记录；名称来自已授权目录，偏好不会选择其他标签页的环境。尚未加载分页中的已保存 ID 通过同一授权目录查询分批解析，每批最多 32 个；撤销授权的 ID 不产生快捷入口。空间行区分电脑和 Runtime 的可用状态，已停止的 Runtime 在进入时启动。切换失败保留原页面并说明可执行的恢复方式。推入式选择页将焦点移到返回按钮，只使被覆盖的侧栏区域不可交互，不会锁住主工作区焦点。

空间选择器会立即列出有权访问的项目编号。选择电脑后，每次最多读取该电脑上 32 个项目的名称。已打开的项目只读取自己的名称。权限失效后隐藏名称和本地路径。

设置与插件管理页独立于当前对话显示其已验证的启动电脑。主入口可以在新标签页打开现有环境选择器，保留当前文档的未保存配置。单电脑模式隐藏这些电脑控件，接入电脑的直接入口不提供跨电脑操作。

电脑名称作为空间和对话标题旁的次要信息，不再单独构成卡片。紧凑顶部栏跟随选中对话实际执行的 Runtime；没有对话时说明所选空间的 Runtime。会话位置未知时不借用其他 Runtime 的电脑名称。桌面对话标题和工作台各面板保留自己的执行电脑归属；编号与权限放在管理界面。当前环境的新标签页操作位于统一空间菜单。

工作区尚未创建第一条对话时，展开侧栏的桌面主区显示已验证空间的电脑。收起侧栏与手机顶栏只保留一处可见标识。

## 概述

使用 `dsh-client-ui-collaboration` 获得 Web 客户端的 Gateway 协作 UI：账户上下文选择器、分阶段的根会话可见性、会话共享菜单与只读项目创作区策略。一个插件经既有 Client 槽位与会话创建瀑布事件贡献这些能力，共享项目会话无需独立账户界面即可工作。

## 用户界面约定

- `sidebar.footer.action` 展示唯一个人空间入口以及带固定电脑归属的项目空间、可访问成员身份、`ro`/`rw` 模式，以及下一条根对话的 `project` 或 `private` 可见性。导航前由 `/account/api/scope` 准备选定的具体 Runtime；各项目保留其绑定电脑。
- 创建项目时选择已授权电脑。邀请候选人具有项目电脑的使用权限，发出和接受邀请时重新核验该权限。 邀请弹窗始终读取当前用户跨项目收到的邀请。仅项目管理者读取所选项目的已发邀请和可邀请用户目录。单独一项读取失败时保留成功读取的待接收邀请；接受邀请保留当前查看的项目和 Runtime。
- 每位项目成员都可以从 scope 菜单打开**项目设置**。面板展示项目 owner 和按能力划分的所有权；owner 或组织管理员可以进入项目运行时、预设、主题和 Provider 控制，普通成员会看到只读原因说明。服务器目录、挂载、生命周期和删除仍在 `/admin` 中处理；管理员项目页只链接回这个带项目作用域的面板，不复制逻辑设置。
- 空间入口按收藏、最近使用、唯一个人入口和项目分组，每个空间只展示一次。个人电脑在工作区浏览器内部组织。搜索匹配空间、电脑和 Runtime 身份。管理操作位于导航之后；768px 以下使用共享手机 Sheet，搜索、清除和空间行保留触控尺寸。
- `shell.mobile.header.context` 在紧凑顶栏展示选中对话的电脑。设置页标题标识其固定配置电脑。在新标签页打开选中对话环境时，原标签页中尚未完成的设置会保留。`conversation.session.header.titleMeta` 独立于页面选择，展示所渲染 Session 的电脑。
- `sidebar.settings.action` 会在 Gateway 账户上下文 ready 后，在 Settings 触发器右侧显示紧凑的「退出」操作。它提交原生 `POST /logout` 表单，由 Gateway 负责令牌撤销、审计记录、Cookie 清理以及跳转到 `/login`。展开行使用门和箭头图标配合短文字，完整名称仍保留在无障碍标签中，悬停或聚焦时才显示危险色；轨道与触控布局仍保留既有的触控尺寸。
- `conversation.session.header.actions` 用一个紧凑入口显示可见性和参与者数量。菜单会加载从根继承的访问权限、创建者、参与者列表和参与次数；创建者或组织管理员可以请求更改可见性，`visibility-locked` 响应也会继续显示在其中。
- 高优先级 `conversation.composer` 注册为 `ro` 项目成员替换整个 composer，覆盖普通输入、审批和问答控件。`sessions/prepare-create` 也会在 RPC 分发前拒绝创建根会话。
- 新建 `rw` 项目会话流程会通过 `sessions/prepare-create` 传递待用可见性。复用空白候选项前，`sessions/confirm-blank-reuse` 会通过 Gateway 重新校验其根可见性，并且只接受完全匹配的候选项；不匹配时会用准备后的可见性创建新根会话。HTTP 响应会先在浏览器信任边界通过 16 MiB 的流式字节上限解码，再发布任何状态。
- 所有注册都是 effect，并会在卸载时完整清理。个人窗格保留普通 Web UI。账号变化及成员资格移除会清除对应的缓存会话详情。

账户上下文还会把当前 scope 的项目身份——公开 id、显示名与管理能力——以及当前账户选择 Full 和 Auto 的资格发布到现有运行时 UI 策略。刷新时撤销当前权限资格；请求失败可保留展示上下文，但不授予操作权限。浏览器身份约束拥有文档生命周期时，签名事件流续连保留私有草稿和布局使用的已确认账号。账号、凭据或 Runtime 身份变化仍通过该约束销毁文档。连接重置会取消并丢弃上一代上下文请求。消费者将该账户值与自身连接的部署信息结合，遵循[权限 UI 规则](../ui-permission-presets/README.zh.md)。

上下文加载只合并非强制调用；变更后的强制刷新会取代并取消旧的上下文读取，陈旧请求的成功或失败都不会发布。请求 slot 在延迟传输执行或通知订阅者之前赋值。对话详情的强制刷新仍保留合并后的尾随读取语义。

<a id="model-experience"></a>
## 模型体验

经由宿主协作消费方间接产生影响；浏览器 UI 所选状态的授权与参与者归属由该消费方负责。

#### KV Cache 影响

无直接失效；消费方负责请求前缀的任何变化。

## 已知限制与延期工作 <a id="known-limitations-and-deferred-work"></a>

- **切换 scope 时整页刷新** — 各 Runtime 保留自己的 Host 连接和任务。可恢复文字草稿通过标签页独立的浏览器存储保留。图片、附件、正在提交或尚未保存的输入会让原标签页继续挂载，并提供在新标签页打开已准备空间的操作。目标准备沿用已有进度层；导航不会取消原空间任务。
- **仅支持 Gateway 传输** — `/account/api/context` 缺失或失败时会隐藏协作控件，并保留普通个人 Web UI。
- **浏览器暂存创建可见性** — 页面加载后，下一条对话的选择默认恢复为项目公开；它不是账户偏好设置。
