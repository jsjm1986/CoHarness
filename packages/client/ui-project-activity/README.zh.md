# @deepseek-ai/dsh-client-ui-project-activity

[English](README.md) | 中文

在项目会话里打开「项目动态」，可以回看成员消息、回答和进展。有可读的 AI 纪要时打开「进展」。没有可读纪要时打开「时间」。「时间」「会话」和「成员」对同一批动态分组。即使成员的动态在更早的页面，当前项目成员也会出现在筛选器里。选择成员后，从该成员的第一页开始读取。

标签跟随当前会话所属的 Runtime。未限定 Runtime 的独立会话使用页面项目策略。即使另一浏览器标签修改空间 cookie，动态分页、纪要读取和生成请求也会保留所属 Runtime。带署名的条目打开来源会话，有日志锚点时定位到对应事件。Gateway 对每次请求检查权限。视图状态归所属会话。Host 半保持惰性。

会话标记使用共享主题调色板来区分会话；颜色不表示任务状态。

工具栏在侧栏内换行。触控目标的两个方向均保留至少 44 CSS 像素，时间戳与梳理状态使用可读的次级文字令牌。指针悬停反馈仅在支持悬停的设备上生效。

`/client` 导出插件体（`apply`/`inject`）、Feed 线路类型、store 工厂与状态类型、注入面类型。

## 概述

在右侧栏查看项目动态并打开来源。AI 纪要展示当前进展和每周的决定、完成事项、进行中工作与卡点。项目没有可读纪要时，从时间流开始。

<a id="invariants"></a>
## 不变量

**运行时不变量：** 不发布伴随件。Feed 由 Gateway 路由从持久会话数据派生；插件只持有一个视图状态 store。

分组使用会话和成员 ID，改名仍保留同一个分组。更改成员筛选后从该成员的最新一页开始读取。被替代的请求即使完成解码，也不能发布结果。

日期分组和会话近期时间使用查看者的本地日历。昨天指前一个日历日期，夏令时切换时也遵循这一规则。面板可见期间会查询梳理状态。查询到期或无法确认状态时，可用「刷新状态」再次查询 Gateway。临时读取失败会保留上次收到的纪要。

<a id="model-experience"></a>
## 模型体验

无，因为本包是成员消息与已选回答的浏览器端只读投影，不向模型请求添加任何内容。

#### KV Cache 影响

无——插件不执行任何模型可见操作。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延后工作

- **仅人类行**——Feed 只列成员消息与已选回答；自动任务、Webhook 回合、权限模式切换与审批执行日志按设计排除。审批行面向另一种阅读问题，继续延后。
- **纪要依赖 Postgres 部署与模型路由**——未挂载进展服务时（非 Postgres 部署、功能开关关闭、或无托管模型凭据），进展档位渲染「暂不可用」页；原始 Feed 仍可用。
- **无已读位置**——按成员的「上次看到这里」标记延后；没有未读态或通知面。
- **补链前的回答无锚点**——`call_id` 持久化（迁移 056）之前认领的回答不渲染提问原文，也不跳转到结果帧。
