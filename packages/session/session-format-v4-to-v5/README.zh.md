# @deepseek-ai/dsh-session-format-v4-to-v5

[English](README.md) | 中文

## 概述

纯相邻 V4 → V5 Session 迁移。它保留本 fork 的 V4 编码器已输出的可选布尔 `draft`，并推进标头版本。所有事件、序号、载荷、surface 操作和继承边界保持原值。V5 写入器将该标头字段纳入已确认的物理格式。

## 使用本包

生成的第一方 Session 格式目录通过 `dsh.sessionFormatMigration` 元数据导入此迁移。持久化提供方使用既有 V4 codec 读取 V4，读取时在内存中重建 V5，显式以写权限打开时才发布独立的 V5 代次。分类和仅读标头不会改写存储。既有 V4 代次的字节、inode 和修改时间保持不变；旧代次的存在不允许从损坏的 V5 回退。

省略 `draft`、包含 `draft: false` 或包含 `draft: true` 的 V4 标头均可读取。V4 编码器已输出该字段，但已接受的 JSONL 类型声明和读取白名单遗漏了它。[V4 历史参考](../../../docs/persistence-changes/historical-formats/v4.zh.md)保留这一不一致；此迁移不改写已接受记录。非布尔草稿值、未知标头字段和未来版本均被拒绝。

## 实现

V5 codec 将事件物理编码与校验委托给既有 V4 codec。迁移逐事件原样转发，并观察继承切点标记，不收集另一份完整产物。仅读标头的迁移只改变 `version`；完整产物校验在 V5 版本标记下应用 V4 事件规则。

不发布运行时不变式伴生插件：该纯库没有可供比对的注册或独立可变状态。直接转换测试和 JSONL 提供方的不可变代次测试验证其 codec 与迁移行为。

## 模型体验

### 历史恢复

#### 模型可见内容

既有事件内容保持不变，包括每条已记录的模型输入与输出。可选的 `draft` 标头字段不进入模型请求。

#### Token 影响

迁移不增加模型可见文本或模型请求。

#### KV Cache 影响

迁移保留历史请求内容，不改变提示词前缀。

## 已知限制与后续工作

- V5 是 CoHarness 的格式后继，上游 V3 构建无法消费它。
- 本包不发布文件，不修复旧代次，也不从历史消息推断缺失的执行权威。
