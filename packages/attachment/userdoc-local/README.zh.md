# @deepseek-ai/dsh-userdoc-local

[English](README.md) | 中文

`userDocs` 的本地后端：把文档存成一个配置根目录下的普通文件，默认根目录为 `<home>/documents`。默认部署会在第一次存储操作时迁移同级 `<home>/uploads`：如果 `documents` 不存在就直接替换；如果已存在则合并，绝不覆盖已有文件，冲突项使用与上传相同的 ` (2)` 后缀。自定义根目录只有显式配置 `legacyUploadRoot` 时才迁移旧目录。

写入分两步。`resolveTarget` 验证目标目录并净化不受信任的客户端文件名——手动剥除两种分隔符、移除控制字符、按字节截断到 255、拒绝纯点名称——再挑选第一个空闲叶名，冲突时在扩展名之前加 ` (2)` 后缀，超过一千次冲突则以 `DOCUMENT_NAME_EXHAUSTED` 失败。`save` 写入以 `O_CREAT | O_EXCL` 打开的同级 `.part` 文件，边接收边计数，fsync 后通过排他硬链接发布，因此绝不替换已占用目标。默认配置不限制单个文档的字节数；显式设置 `maxFileBytes` 仍会执行有限的部署策略。任何失败路径都会删除部分文件。

读取接受 store 作用域内的 `docId`——即以正斜杠表示的根相对路径——而不接受调用方持有的 `UserDocRef.path` 副本。每次读取都会重新推导路径，并同时证明词法路径和真实路径都位于根目录内，因此目录遍历和指向根外的目录符号链接都会被拒绝。`list` 递归返回所有普通文档；`listDirectory` 返回直接子文件夹与文件；`listDirectoryPage` 与 `listTrashPage` 提供有界筛选分页；`listDirectories` 枚举移动目标。创建和重命名文件夹只接受一个净化后的叶名，删除要求目标为空且不是根目录，`move` 绝不替换已有目标。`openRead` 流式下载，`remove` 将文件本已不存在视为成功。`trash`、`restore` 与 `purge` 通过私有清单和隐藏文件移动文档，`trashRetentionDays`（默认 30 天）控制自动过期；恢复时会重建已被删除的原目录，名称仍遵循普通的不覆盖目标策略。

相同的在途列表请求会共享一次文件系统扫描；单个调用方的取消只影响自己，只有最后一个等待方离开时才会停止底层扫描。

`mediaType` 由存储文件的扩展名推导。文本、Markdown、CSV、JSON、YAML、XML、常见源代码、图片、PDF 和 Office 扩展名会得到对应的展示类型；无法识别的扩展名记为 `application/octet-stream`。它只是展示用的元数据：这里既不解析内容，也不拒绝未知格式。

## 可续传上传

本地后端实现 Web 客户端使用的 `resumable-v1` 上传会话。它一次只接收一个请求大小的分片，使用 SHA-256 校验每个分片，把私有 manifest 和部分文件保存到 `.upload-sessions/v1/`，并在完整 SHA-256 校验通过后才发布最终文件。会话可在运行时重启后继续，并按配置的默认 24 小时保留；过期会话会自动清理。默认分片大小为 8 MiB，低于公网 Cloudflare 请求体限制；所有上传安全参数都可以通过后端配置调整。

`uploadManifestMaxBytes` 限制每次读取的 manifest 大小（默认 256 KiB）。`uploadMaxConcurrent` 同时限制过期会话清理和最终化 worker 数量；存储停止或取消上传时，排队中的最终化任务会被取消。`uploadCleanupIntervalMs` 限制为 Node 的最大计时器延迟（`2,147,483,647` 毫秒），无效间隔不会被钳制成高频的一毫秒循环。

## 模型体验

该包通过主机的提示装配消费方间接影响模型：消费方把已存储的引用转换为内联文本，或转换为一个由 agent 用常规工具读取的路径。

#### KV 缓存影响

无；该包既不组装也不发送提供方请求。

## 已知限制与待完成工作

- **没有业务存储配额** — 默认不限制单个文档或用户总字节数，但后端仍通过可配置的最低剩余空间、并发会话数和未完成会话清理保护主机。
- **已完成文档的保留策略是显式的** — 活动文档会一直存在到删除；移入回收站的文档只在 `trashRetentionDays` 内可恢复，之后由提供方清理。包括完成状态元数据在内的会话记录是临时的，按配置的上传保留期清理。
- **`list` 每次调用都遍历整棵目录树** — 没有索引，因此存有数千个文件的根目录每次列举都要付一次完整扫描的代价。
- **只能删除空文件夹** — 删除目录树前必须先移动或删除其中内容；本包不提供递归删除操作。
