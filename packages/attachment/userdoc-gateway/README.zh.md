# @deepseek-ai/dsh-userdoc-gateway

[English](README.md) | 中文

## 概述

`userdoc-gateway` 通过已认证的 Gateway 传输提供 `ctx.userDocs`。文档引用保留所配置公开根目录下的普通绝对路径，文件系统和 shell 工具可以直接编辑文件。服务端持有上传会话、存储限额与元数据；运行时不会收到私有存储路径。

## 身份与传输

每项操作在等待传输前捕获当前执行身份。已捕获的执行只发送会话和作用域引用，绝不转发后来浏览器请求的身份断言。执行之外的操作必须具有仍然有效的交互请求身份。受限用途均被拒绝，只有 `document-admin` 可以执行移入回收站、恢复和永久删除。服务端必须独立校验每个引用和所有参与者的当前权限。上传所有者参数只是对已认证所有者的断言，不能选择其他所有者或根目录。

私有 POST 端点 `/internal/runtime/documents/store` 传输有长度前缀且大小受限的 JSON 信封，随后传输原始文件字节。上传和读取以流方式进行，文件字节不计入元数据预算。目录和回收站分页在服务端计算。严格解析器拒绝未知操作、字段和错误码；返回路径必须与运行时独立配置的根目录一致。

请求准入名额一直保留到响应消费结束或 `openRead` 明确移交流。卸载会拒绝新调用、中止已接收的 RPC，并等待其清理结束。已经移交的读取流由消费方持有。取消失败会保留原因、关闭后续准入，并使卸载失败。`read` 在全部字节处理结束前始终由提供方持有。

<a id="configuration"></a>
## 配置

| 键 | 默认值 | 含义 |
|---|---|---|
| `documentRoot` | `~/documents` | 展开主目录后独立预期的公开根目录绝对路径 |
| `maxMetadataBytes` | `4194304` | 编码信封的字节上限，不含四字节前缀和文件字节 |
| `requestTimeoutMs` | `60000` | 元数据操作完成或流式读取移交前的期限 |
| `maxPendingRequests` | `64` | 消费结束或移交前最多接收的请求数 |

`/server` 导出的服务端适配器要求在读取请求前完成运行时认证，并提供生命周期信号，以及从后端选择到响应发送结束全程有效的授权持有方。其 `finish` 回调在确认成功前完成所需的目录索引或持久投递副作用。适配器本身不认证运行时令牌。拒绝响应发送结束后，适配器会关闭未完成的请求，不等待发送方传输到 EOF。后端错误和响应源清理错误分别保留。管理型 Gateway 为内容读取、一次性保存和分片请求体订阅账号、项目及捕获参与者的实时撤权，并保持订阅直到输入取消与源／响应清理结束；已交付的字节无法收回。缺少访问监控器时拒绝装配后端，监控不可用时不接受新请求并取消活动传输。

<a id="model-experience"></a>
## 模型体验

### 文档引用

#### 模型所见

现有文档消费方呈现各个文件的绝对 `path` 和服务端限额。提供方不增加工具或提示词节。

#### Token 影响

无直接影响；各个消费工具或提示词节持有其呈现内容。

#### KV Cache 影响

无；提供方不增加模型可见的请求前缀。

## 已知限制与待完成工作

<a id="known-limitations-and-deferred-work"></a>

- 托管 Web 运行时在插件挂载前，根据不可变的继承 Gateway 凭据通道标记选择此提供方。它们等待 `gatewayRuntime` 和 `executionAuthority`，不会激活本地存储。独立组合使用本地提供方，项目和用户环境文件不能选择托管存储。生产进程隔离依赖 Linux 运行时账号和部署挂载策略。local 启动器部署共享宿主机账号，不能证明用户或项目间的进程隔离。
