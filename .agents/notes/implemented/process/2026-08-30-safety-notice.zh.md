# Agent Note: Publish an explicit pre-release safety notice

Status: implemented

[English](2026-08-30-safety-notice.md) | 中文

## 问题

CoHarness 可以执行模型生成的代码、加载插件、访问部署开放的宿主资源，并可选发起网络请求。仓库已有分组件的安全防护说明，但缺少一个面向运维人员的根目录提示，集中说明发布前风险和部署姿态。

## 决策

仓库根目录发布 `SAFETY.md` 和 `SAFETY.zh.md`，作为面向运维人员的安全权威入口。文档说明项目尚未审计且处于发布前阶段，列出沙箱和授权的限制，要求最小权限与经过测试的备份，并规定 WebFetch、插件 metadata 和 Session-log upload 在端点、脱敏、限流、审计和回滚控制获批前保持显式关闭。该提示不取代 Gateway 认证、TLS、沙箱或部署方审查。

## 考虑过的替代方案

**只依赖各包的安全文档。** 不采用：运维人员在启用部署前需要一个清晰的统一入口。

**声称现有沙箱足以保证不可信执行安全。** 不采用：部署开放的资源、被攻陷的插件以及 macOS 隔离限制仍然是实质风险。

**默认启用上游新增的出网功能。** 不采用：metadata 和 Session-log 字段可能把项目或会话信息泄露到本地进程之外。

## 影响

新部署拥有明确的安全警告和高风险可选功能检查清单。该文档是提示，不能强制基础设施控制，也不能替代安全审计。
