# Agent Note: 复用验证工作而不降低 PR 验收要求

Status: implemented

[English](2026-09-22-pr-verification-throughput.md) | 中文

## 问题

局部包修改常常附带 README 和 Agent Note。把三者都归为运行时输入，会将有限范围的变更扩大成全量 CI。浏览器场景还在功能 golden 中重复无关的会话界面，因此普通界面文案变更需要刷新多份无关预期。独立的 provider、内核和包工作流可能失败，却不影响必需的 PR 汇总。

## 决策

[范围选择](../../../../scripts/ci-pr-scope.ts)保留全部变化路径，仅从运行时分类中排除已识别的无影响说明文档。模型输入、配置、共享运行时包和未知输入仍采用保守策略。仅浏览器场景或 golden 变化时，选择全部已登记的所属场景和公共冒烟集；生产组件变化仍选择其业务分组。缺失入口在执行前失败。[分层决策](../testing/2026-09-11-web-verification-tiering.zh.md)继续负责分组和冒烟库存。

选择器比较冻结的已提交基线与候选，默认执行去重并集。报告区分旧、新和实际执行的选择。显式的候选策略试验不等于获准上线：切换默认值需要经过审查的提交，包含两批代表性实际验证、全部缩减依据，且没有未解释的漏选或扩张。冻结基线仅用于本次迁移，并随该切换退役。

[本地预检](../../../../scripts/pr-preflight.ts)报告未提交与已提交范围、公开检查、生成物工作、双语配对和缺失引用。默认只读。`--check` 执行登记的机械检查，不执行产品库存；`--fix-generated` 仅调用登记的确定性生成器。两者均不确认译文语义或刷新预期输出。报告始终明确产品检查未执行；没有完整输入和环境身份的证据不可复用。

[Web fixture 准入](../../../../scripts/verify-web-fixtures.ts)在独立浏览器车道构建前解析选中的已录制 Session。运行时创建的 fixture（测试前置数据）仍由所属场景负责。本地完整检查图让 typed lint 等待生成的声明。独立检查继续报告各自的失败。

[必需结果验证器](../../../../scripts/verify-pr-results.ts)消费与 CI 生产方相同、绑定提交的计划。选中的包、内核、原生 Windows 和 provider 证明通过已有 job 与可复用工作流纳入汇总。必需结果缺失、失败、取消或跳过均拒绝验收。必需的 provider 运行保留可信 PR 限制，环境不可用时失败；不能以回放或密钥存在性检查代替真实调用。独立的手动与主线工作流保留各自职责。

首期必需的真实 provider 验收范围为 DeepSeek。Azure OpenAI 与 Anthropic 明确不在支持的验收范围内；涉及它们的变更在报告中保留未验证状态。上游手动测试入口仍可使用；将其纳入必需验收需要显式修改范围策略并配置可用凭据。

主线发布打包负责 PR job 消费的 pnpm 缓存命名空间，主线浏览器巡检负责 Chromium 的命名空间。安装仍校验锁文件。[覆盖率耗时](../../../../scripts/coverage-partitions.ts)仅为调度权重，不是验收结果：它绑定工具链、配置、平台、资源类别和有效期；数据损坏或不兼容时使用冷启动权重。PR 保存的权重帮助同一 PR 的后续运行；不为填充权重而额外增加主线覆盖率 job。分片以真实测试库存为准，每个测试只运行一次。

[产物 manifest（元数据清单）](../../../../scripts/build-artifacts.ts)绑定干净候选、环境、profile、输入摘要和完整输出库存。消费者拒绝缺失、多余、陈旧或损坏的输出。没有达标测量时，共享构建拓扑保持禁用。[成本比较器](../../../../scripts/compare-ci-cost.ts)最多接受三组可比样本；仅当安装、构建、传输的 runner 总耗时至少降低 10%，墙钟中位数不增加，且最慢样本增幅不超过 5% 时保留试验。失败或不可比样本不能证明收益。独立消费者构建保留[排队延迟的决策依据](2026-07-30-independent-ci-consumer-build.zh.md)。

队列 golden 覆盖队列 dock，响应式布局 golden 覆盖 composer，CJK 强调 golden 覆盖对应的 Markdown 内容。队列文字、按钮名称、禁用状态、顺序、持久化事件和响应式几何仍精确验证。完整组装与生命周期场景保留公共界面覆盖。刷新必须显式执行，随后只读回放；normalization 不扩大。

Web scaffold 在模型 workspace 外的私有根目录中分配 Session 和文档存储。显式文档根目录避免访问宿主文档、等待共享准入锁及隐式迁移旧上传。存储初始化、文件锁、维护及异步资源释放仍运行真实实现；scaffold 在资源释放完成后才删除自己拥有的根目录。隔离回归写入并读取真实文档，保护受控的宿主主目录 fixture，并在独立并发进程中运行。

## 考虑过的替代方案

**放宽阻断规则，或借用其他提交的绿灯。** 两者只能缩短表面等待，不能证明当前候选。必需检查和逐文件覆盖率保持不变。

**替换执行器，或推导完整运行时依赖图。** 动态 Cordis 组合使其成为独立架构项目。现有消费者关系和场景归属为有限范围的选择器提供依据。

**立即共享全部构建。** 生产方排队和产物传输可能比重复编译更贵。manifest 证明身份，不证明速度收益；由可比试验决定拓扑。

## 后果

更早的反馈来自准确选检、错误前置、更小的功能 golden 和可复用计算。执行器保留三态结果与依赖语义。CI 仍然只读。不引入额外 runner 等级、合并队列或自动审批层。

默认策略上线、跨 job 共享构建、更广泛的快照收缩与自动合并，都需要各自的验收证据。基线失败仍是失败，不能改称 flaky 来启用这些功能。性能报告分开呈现节省的工作和新增必需验证，保留首次失败与重跑 attempt。
