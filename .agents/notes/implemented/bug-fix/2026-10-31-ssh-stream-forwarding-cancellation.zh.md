# Agent Note: SSH 流回滚保留传输所有权

Status: implemented

[English](2026-10-31-ssh-stream-forwarding-cancellation.md) | 中文

## 问题

已完成的转发命令归还基础设施额度时，调用方仍可能取消。即使尚未分配客户端套接字，Unix 监听器也已存在。忽略取消或路径移除失败，会让仍可复用的连接持有未确认清理的转发资源。

## 决策

[SSH 连接](../../../../packages/ssh/ssh/src/index.ts) 将命令完成后的取消检查纳入预留回滚。回滚失败会使连接失效、终止其原生主进程，并等待原生进程的退出观察。分配、回滚与观察失败各自保留错误。原生清理未获确认时保留私有目录。

正常的外层销毁仍先等待消费者收尾，再停止主进程。流清理不能等待外层销毁：保留的消费者可能正在等待这次流分配。回滚失败可以直接等待原生主进程，因为连接失效已经请求终止该进程。

## 考虑过的替代方案

**未确认取消就删除套接字路径。** OpenSSH 监听器可以在路径删除后继续占用资源。

**流清理等待连接销毁。** 分配及其保留的消费者可能形成清理依赖环。

## 影响

已确认的回滚保留健康连接。无法确认的回滚拒绝新工作，并保留可见错误。此 Host 修复不改变协议字段或辅助程序摘要。[子进程准入所有权](2026-10-31-subprocess-admission-owner.zh.md) 与[辅助程序清理重试](2026-10-31-ssh-helper-cleanup-ownership.zh.md) 仍是独立的所有权决策。

## 验证

启动测试覆盖原生额度完成时取消、取消及路径移除失败，以及原生清理无法确认。[组装预期输出测试](../../../../packages/ssh/ssh/tests/stream-forwarding.expected.e2e.ts) 运行 Loader、原生 OpenSSH 载体替身及真实辅助程序，无需模型 API 即可观察套接字移除、请求拒绝和原生额度完成。
