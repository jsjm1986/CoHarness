# Agent Note: VNC 提供方拥有启动与连接清理生命周期

Status: implemented

[English](2026-11-20-vnc-provider-lifecycle.md) | 中文

## 问题

VNC 提供方可能在私有文件加载完成前就对外可见。卸载会停止已经建立的转发，但已准入的拨号、凭据握手、录制或审计追加可能仍在进行。

## 决定

Cordis 在授权存储、审计日志和已配置端点完成加载后才标记就绪。卸载关闭操作入口、清除连接令牌、取消拨号并关闭所属传输的两端。取消后返回的连接会在转发前关闭。提供方等待已准入操作和录制关闭完成，再排空审计日志。

## 考虑过的替代方案

**卸载时关闭已建立的传输。** 已准入的拨号或凭据握手仍可能在清理后完成。等待已准入操作结束，可让这些操作的传输和最终审计写入都在提供方的生命周期内完成。

## 影响

私有存储无法读取时，插件启动失败。撤下提供方前已准入的授权变更可以完成并记录审计事件。持有已撤下服务的调用方发起新操作时，收到 `REMOTE_DESKTOP_TARGET_UNAVAILABLE`。

## 验证

真实 Loader 组合覆盖存储初始化失败和初始化期间卸载。生命周期测试在卸载期间阻塞拨号、凭据解析和审计追加，验证提供方等待各自所属工作完成。
