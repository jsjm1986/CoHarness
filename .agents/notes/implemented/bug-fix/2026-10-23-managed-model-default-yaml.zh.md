# Agent Note：YAML patch 中的托管默认模型

Status: implemented

[English](2026-10-23-managed-model-default-yaml.md) | 中文

## 问题

[组织默认模型](2026-08-25-organization-default-model-route.zh.md) 与用户条目共用运行时 home patch。在 `[]`、行内序列或文档结束标记后追加块序列条目，会生成无效 YAML，可能阻止运行时启动。移除唯一的生成条目时，也必须保留尾部注释和文档标记。

## 决定

Gateway 将保留的 patch 解析为 YAML 序列，通过 YAML 文档模型添加带标记的默认模型条目。投影期间，自定义 `!!js` 标量保持为带标签的字符串。空文档使用空序列；若托管条目是唯一条目，移除时保留序列的位置。用户条目与注释在更新后仍保留，格式错误的输入会在替换文件前失败。

## 备选方案

**只特殊处理 `[]`。** 其他行内序列及显式文档标记仍会出错，文本检查还会重复实现 YAML 语法。

**用生成列表替换整个 patch。** 这会丢弃共享文件中的用户配置与注释。

## 影响

投影可能规范化 YAML 格式。同一策略的重复写入保持字节稳定；user 层模型设置仍拥有更高优先级。

## 验证

Gateway 回归覆盖空序列、行内序列、注释、文档标记、带标签表达式、移除、重复写入及无效输入保留。组装的 Loader 示例加载投影默认值，接收 Gateway 重叠刷新产生的实时策略变化，并在适配器分发前拒绝已撤销的路由。
