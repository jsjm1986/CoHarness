# Agent Note：模型记忆工具使用已提供的作用域

Status: implemented

[English](2026-10-31-memory-tool-scopes.md) | 中文

## 问题

记忆服务在功能关闭时隐藏所有 Agent 作用域，同时保留面向所有者的读取。工具若直接构造 personal 或 project 作用域，就会绕过这一区别，把已存正文返回给模型。隐藏目录和拒绝写入无法阻止显式读取或搜索。

## 决策

每个主对话记忆工具在执行入口从 `scopesFor(agent)` 解析请求或隐式作用域。未提供的作用域在访问存储前以 `memory_invalid` 拒绝。personal、workspace 和 project 调用遵循同一规则；未筛选的搜索也必须有已提供作用域。重新启用功能会恢复对保留记录的工具访问。

成员 Remote 读取保持现有访问规则，功能关闭时仍可使用。工具作用域准入不能替代服务的[写入授权检查](2026-10-23-memory-member-authority.zh.md)，包括排队和耐久标记持久化后的检查。[整理作用域决策](2026-10-28-memory-curation-scope.zh.md)独立限制辅助遍仅访问其审阅的作用域。

## 备选方案

**在存储服务拒绝关闭后的读取。** 面向所有者的成员读取需要在功能关闭时检查保留数据。模型工具自行强制执行更窄的已提供集合。

**仅隐藏工具 schema 或目录。** 模型响应仍可能包含工具调用，不受声明可见性约束。执行器必须应用当前提供的集合。

## 后果

关闭记忆撤销新的工具操作，但不删除条目或改变修订号。执行器在入口检查可用性，已进入的存储读取保留自身生命周期。读取与搜索结果在返回模型前，还须遵守[实时可用性决策](2026-10-31-memory-live-availability.zh.md)。变更操作保留额外的服务生命周期检查。设置字段、工具参数、Session 事件和存储格式均保持不变。

## 验证

针对性用例覆盖 personal、workspace 和 project 作用域下的全部四个工具、隐式搜索、所有者读取及重新启用。真实 Loader 转录使用文件设置提供者、Agent 模型调用和 JSON 存储：关闭后的调用返回精确拒绝文本，成员读取保留每个条目，重新启用后的调用返回原始数据。证据目录中的修复前工具模块复现关闭后的读取和搜索泄露，不修改共享产品源码。
