# Agent Note: 受管备份路径的索引校验

Status: implemented

[English](2026-10-31-managed-snapshot-path-index.md) | 中文

## Problem

Admin 部署页定期读取完整备份记录。逐条重复扫描清单中的所有根和目录，可能长时间占用 Gateway 主线程，延迟无关的 Runtime 注册与浏览器请求。开销同时随根数量和成员数量增长。

## Decision

`parseManagedSnapshot` 在一次解析期间为精确根路径、目录路径、文件路径和缺席根建立索引。根归属沿规范化的父路径查找，不扫描无关根。解析保留输入顺序及全部结构校验：重复成员、重叠根、缺失根或父目录、缺席根的后代、越界路径以及文件与目录类型冲突仍会报错。

[部署维护决策](../architecture/2026-09-25-gateway-deployment-maintenance.zh.md) 保持有效，负责备份完整性、字节验证和恢复互斥。

## Alternatives considered

**列表读取跳过校验。** 耐久清单在展示或用于恢复之前仍须接受校验。

**全局缓存解析记录。** 这会增加保留状态和失效管理责任，不能消除单次解析中的重复路径比较。

**增加启动期限。** 无关请求仍会被同步工作阻塞。

## Consequences

临时查询索引的内存随清单成员数量增长，解析结束后释放。父路径查找取决于路径深度，不取决于无关根的数量。耐久格式、API 响应、存储字节和恢复检查保持不变。生成数据的编译模块对照单独测量解析开销，不代表数据库、浏览器或远程网络延迟。
