# Agent Note：Node 24 上稳定的仓库文件发现

状态：已实现

[English](2026-09-13-repo-file-dirent-walker.md) | 中文

## 问题

静态与文档门禁使用 Node 的 `fs.glob` 枚举仓库文件。部分 Node 24 版本在展开 `**` 时会探测符号链接文件下的路径并抛出 `ENOTDIR`，使门禁结果依赖 runner 的 Node 补丁版本。

## 决策

`scripts/repo-files.ts` 现在通过 dirent walker 处理仓库支持的 glob 子集。通配符与 `**` 遍历不会进入符号链接目录；字面量段保留所需的 stat 行为。规范 realpath 去重、隐藏文件排除、断链失败和不支持语法拒绝仍是显式规则。该 walker 只服务 CI，不改变产品文件系统访问。

## 后果

文档和静态门禁在不同 Node 版本上枚举相同的语料；模式超出已建模子集时会明确失败。九个定向测试覆盖符号链接文件与目录、循环、断链、点文件名、规范去重和拒绝语法。

## 考虑过的替代方案

**继续使用 `fs.glob`。** 否决，因为 runner 相关的 `ENOTDIR` 故障可能阻塞无关 PR。

**跟随所有符号链接。** 否决，因为这会改变门禁语料，并可能通过循环递归。

## 验证

`scripts/repo-files.spec.ts` 的九个测试通过。发布前仍需完成完整静态与文档门禁。
