# Agent Note：召回地址描述已准入内容

Status: implemented

[English](2026-10-31-memory-recall-addresses.md) | 中文

## 问题

召回选择与消息装入的结果不同：被选中的条目可能超出剩余帧预算。把每个选择都记录为已注入地址，会使被省略条目从后续候选中消失，压缩后也不例外。选择器使用裸键时，多个已提供作用域内存在同名条目也需要确定性的解析规则。

## 决策

帧装入器返回同一保留前缀的文本与地址。只有这些地址进入持久 `memory-recall` source。被选中但因帧预算省略的条目仍可在后续回合召回。选择器重复返回的键只贡献一次地址；同名键按目录的作用域顺序解析到首个合格行。

UTF-8 输入与正文上限保留完整字符。末尾不完整的编码字符被省略，不通过结束解码补入可能超出字节预算的替换字符。完整渲染提醒仍受单条消息和会话可见预算约束，包括包装与陈旧提示。

[辅助请求决策](2026-10-24-memory-auxiliary-ownership.zh.md)继续负责精确请求日志、准入归属、取消和清理。[信号门槛决策](../feature/2026-11-19-zcode-aligned-memory-signal-gates.zh.md)保留独立的人类输入和已读取排除规则。最终注入内容的装入行为没有取代这两项决策。

## 备选方案

**对每个模型选择去重。** 选择的条目可能在到达模型请求前被省略。去重必须描述已发布内容。

**通过解析渲染正文恢复地址。** 条目内容是自由格式文本，可能包含与提醒相同的分隔符。持久元数据提供由生产者持有的明确记录。

## 后果

压缩可回收召回字节，但不会使已记录地址重新合格。历史地址元数据仍按记录作为依据；本变更不重写已提交 Session 代际，也不根据其文本推断修正。创建新 Session 会重置历史去重。选择器输出保留现有的纯键 JSON 格式，Session 事件字段保持不变。

## 验证

针对性用例覆盖部分装入后继续下一回合、重复选择、个人与工作区同名条目，以及三字节和四字节字符切口。真实 Loader、Agent、JSON 域和模型准入提供者执行三个回合，比较完整持久召回文本及地址，并确认每个模型准入都已释放。受控私有变体恢复错误归属或末作用域解析，不修改共享生产文件。
