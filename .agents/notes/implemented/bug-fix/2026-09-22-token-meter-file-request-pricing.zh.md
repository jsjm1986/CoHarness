# Agent Note: 文件请求文本决定 token 压力

Status: implemented

[English](2026-09-22-token-meter-file-request-pricing.md) | 中文

## 问题

持久文件引用包含摘要、名称和字节数。模型收到的句柄更长，会说明如何在当前执行环境中读取文件。只为引用计价会低估请求，也无法反映 Session 在其他位置恢复后的路径变化。

## 决定

[token meter](../../../../packages/llm/token-meter/README.zh.md) 在测量时通过 `ctx.llm.fileRequestText()` 解析每个文件出现位置。它在回放 fold 的启发式节点旁保留附件身份，并分别替换文件和图片的结构价格，包括嵌套工具结果。当前节点与成功调用锚点采用相同的请求时投影。

[回放 meter 决定](../architecture/2026-07-15-replay-token-meter-service.zh.md) 继续约束 envelope 匹配、提供方用量锚点与不可变测量。固定的 `heuristicTokens` 和有界持久投影保留基于引用的计量；提供方报告的用量仍是计费依据。缺少 LLM（大语言模型）服务时保留固定启发式价格，缺少可读路径时采用 LLM 服务的说明性句柄。

## 考虑过的替代方案

**在 token-meter 中重新实现句柄文本。** LLM 服务拥有实际发送的表示和执行环境路径映射。第二份格式化逻辑可能在两个包各自测试通过的情况下仍发生偏差。

**在投影中持久化已解析路径或价格。** 恢复或更换提供方后，同一个持久引用可能解析为不同路径。持久化价格会把可迁移的历史绑定到某个执行环境，并使回放依赖陈旧的访问事实。

## 影响

带文件的请求按实际发给模型的表示影响压缩压力。文件访问发生变化时，即使没有新 Session 事件，请求估算也可以改变；此前的不可变测量保持不变。持久组成投影仍采用固定启发式估算，因此可以不同于实时请求测量。

## 验证

Loader 组合使用真实附件存储、文件系统映射和 LLM 投影，将 meter 与外部模型适配器替身观察到的文件句柄消息比较。在另一存储根下恢复相同日志和字节会改变请求价格，但不会改变持久投影。所属包的测试覆盖路径不可用、图片与文件混合嵌套，以及匹配用量锚点的重新计价。
