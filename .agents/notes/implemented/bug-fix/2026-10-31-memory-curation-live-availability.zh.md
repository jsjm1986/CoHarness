# Agent Note：实时整理开关分别拥有操作生命周期

Status: implemented

[English](2026-10-31-memory-curation-live-availability.md) | 中文

## 问题

提取与整理可能等待存储、模型准备、容量或工具结果。仅在一遍开始时检查设置，会让已关闭的操作继续发送请求并把审阅标记为完成。只有一个 Session 级取消控制器，无法独立取消提取而保留整理，也无法在取消操作清理期间保留待处理回合。

## 决策

Session 通道保留其销毁控制器和合并后的回合队列。当前运行的提取或整理操作另有一个与通道关联的控制器。有效记忆开关变化时，只取消自身开关或主开关已经关闭的操作。通道等待其模型与存储清理结束后，再启动下一操作。取消提取不影响仍启用的整理；后续回合重新读取当前开关。

存储完成、模型准备完成、每个模型轮次、每个工具结果和完成游标准入，均重新检查该操作的当前开关及已提供作用域地址。不可用的工作会在记录或发送下一请求前停止，不发布完成进度。信号继续经过现有 LLM 准入与游标队列，因此迟到额度释放后不会调用适配器，被取消的排队游标也不能提交。已经准入的耐久写入保留正常结果，不回滚。

本决策扩展[实时记忆可用性规则](2026-10-31-memory-live-availability.zh.md)。精确请求记录继续遵守[辅助请求所有权](2026-10-24-memory-auxiliary-ownership.zh.md)，工具地址遵守[整理作用域限制](2026-10-28-memory-curation-scope.zh.md)，并发审阅与游标仲裁遵守[作用域合并](2026-10-31-memory-consolidation-coalescing.zh.md)。

记忆服务为命名空间提交与提供者生命周期统一拥有[来源变化通知](2026-11-01-memory-provider-availability.zh.md)，操作在取消前读取自己注入的服务。

## 备选方案

**任一开关关闭时中止整个 Session 通道。** 这也会取消另一个独立启用的操作，并丢弃安全处理待决回合所需的调度所有权。

**仅在首次模型调用前检查。** 存储或工具结果可能稍后才完成，准备好的请求也可能仍在等待容量。每次新发送与进度提交都需要当前可用性。

**提供者清理前就返回取消。** 这样替代审阅可能在旧提供者仍持有请求时消耗资源。关闭确认仍以现有通道完成为准。

## 后果

已关闭的整理不会新准入模型轮次，未完成的审阅仍可由后续启用的遍处理。所有者读取、已提交记忆条目和既有请求记录保持可用。设置键、Session 事件格式、存储记录、策略授权和资源上限均不变。项目资格与捕获签发方的检查遵循[整理授权决策](2026-11-01-memory-curation-authority.zh.md)；更大范围的项目撤销审查仍未完成。

## 验证

延迟目录和条目读取可复现撤回后发送；延迟工具读取与搜索可复现后续模型轮次。元数据、模型准备、迟到模型额度和排队游标有针对性用例。独立开关用例保留仍启用的整理。真实 SDK 进程在实际辅助调用期间提交文件设置，观察关闭运行时前已收到取消，并在释放额度前等待提供者迭代器清理结束。完整隔离旧包会使同一组 SDK 检查失败；正常整理与请求投影夹具继续提供回归覆盖。
