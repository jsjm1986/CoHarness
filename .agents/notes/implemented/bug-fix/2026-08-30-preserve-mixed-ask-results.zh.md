# Agent Note: Preserve mixed ask-user result diagnostics

Status: implemented

[English](2026-08-30-preserve-mixed-ask-results.md) | 中文

## 问题

ask-user 摘要行会解析成功工具结果中的所有文本块，并在渲染前丢弃非文本块。因此同时包含有效回答和 reasoning 或诊断块的结果会显示回答计数，却隐藏了通用展开输出本可保留的信息。

## 决策

工具视图模型只有在已结束结果恰好包含一个文本块时才使用 `singleResultText`。混合或非文本结果保留通用摘要和输出路径，由通用渲染器序列化每个内容块。这样回答计数仍是尽力解析，同时不会丢弃诊断数据。

## 考虑过的替代方案

**继续拼接所有文本块。** 不采用：这会静默丢失非文本诊断，并可能把无关文本误解析为回答文档。

**解析混合内容并增加第二套专用渲染器。** 不采用：这会重复通用内容契约，还必须为未来的每种块类型定义展示方式。

**拒绝整个工具结果。** 不采用：有效回答仍有价值；通用渲染器可以同时展示回答和诊断。

## 影响

单文本回答结果继续使用原有回答计数摘要。混合结果展开时展示完整的类 JSON 输出，不再声称已经解析出回答计数。未来新增的内容块类型也会自动通过通用路径可见。

## 测试

ask-user 行测试覆盖有效回答文本块与 reasoning 块并存的情况，并断言通用展开输出包含块类型和诊断文本。
