# Agent Note：记忆写入授权的生命周期

Status: implemented

[English](2026-10-23-memory-member-authority.md) | 中文

## 问题

记忆写入会排在其他修改之后，并在修改条目前等待耐久整理标记。只保留参与者快照、先前的提供方检查，或仅由调用者检查取消，都可能让变更在授权过期、提供方替换或操作取消后仍然获准提交。

## 决定

`MemoryWriter` 保留请求捕获的完整协作授权。成员写入在队列轮到自身后检查有效期和生命周期，并在持久化整理标记后、修改条目前再次检查。过期主体收到共享的权限拒绝；已卸载提供方对应共享的不可用拒绝。作用域发现将这些授权报告为不可写。代理写入在准入时及条目变更前检查传入的取消信号。project 写入保留准入时的执行提供方，并在标记之后进行最终权限检查；返回的执行状态必须与原状态相等。每次写入在标记之后及最终权限检查之后重新检查当前作用域是否可用。

## 备选方案

**队列推进时捕获新授权。** 此时无法保证发起请求的身份仍然处于当前上下文，新请求也不能向先前的工作授予权限。

**只保留捕获的项目模式。** 有效的作用域快照具有有限生命周期，永久保留模式会丢失该限制。

## 影响

排队不会延长主体生命周期。自定义成员写入者保留完整的请求授权，没有协作能力的独立组合则保持所有者语义。被拒绝的写入可能留下保守整理标记，但不能修改条目。

独立成员写入等待期间若引入协作能力，其无授权准入将被撤销。提供方替换不会借用替代提供方的授权。最终检查不能借用后来请求的参与者。权限检查不预留模型请求额度，也不为模型请求计费。

## 验证

确定性屏障分别在其他写入者之后和游标持久化期间验证保存与删除。恰好到达过期时刻和提供方失效都会保留原条目。有效授权仍然允许删除。

代理回归会在标记持久化或最终权限检查期间取消写入、替换或移除授权提供方、关闭作用域，以及改变参与者。真实 Gateway 更新流用例会在写入者保持空闲时撤销用户或项目资格、断开更新流，并保留无关用户的访问权。Loader 快照通过实际 Agent 整理和 JSON 存储验证保存与删除，拒绝时保留条目，并向模型反馈实际工具结果。取消快照在标记和条目持久化之间停止整理，不保留尚未发布的条目。
