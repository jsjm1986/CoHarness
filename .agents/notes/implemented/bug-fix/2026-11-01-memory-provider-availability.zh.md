# Agent Note：有效记忆来源变化取消不可用的工作

Status: implemented

[English](2026-11-01-memory-provider-availability.md) | 中文

## 问题

挂载或替换设置提供者，可能在没有命名空间提交的情况下撤回召回或整理。移除提供者也可能通过组合配置回退关闭这些功能。只监听 `settings/updated` 的消费者会遗漏变化：已经等待模型容量的请求仍保留活动信号，可能在有效开关关闭后发送。

## 决策

记忆服务在有效来源被替换后发布 `memory/switches-updated`，并在记忆命名空间提交期间同步发布。消费者重新读取自己注入的记忆服务，通过现有召回或操作控制器取消不可用的工作。来源替换与普通编辑使用相同控制路径；排队模型额度、流清理和游标写入保留现有完成所有者。

事件不携带设置快照。通知可能到达绑定到不同服务实例的消费者，消费者自己的 getter 才决定当前开关。提供者接线可重复确认未变化的值。来源变更调用返回前，所有回调均已同步执行；Cordis 并行分发在调用完全部回调后报告独立观察者错误。异步清理仍归消费者所有。

组合配置回退保持不变：移除设置提供者后使用已配置条目。只有该有效配置使操作不可用时才取消工作。服务不新增设置缓存或持久化开关状态。

## 备选方案

**只订阅命名空间提交。** 初次注册和提供者移除会在没有设置写入时替换解析来源。等待下一次提交，会让已经排队的请求继续沿用旧可用性。

**把广播设置快照视为所有消费者的状态。** 隔离服务实例可能拥有不同的有效设置。通知要求本地重新检查，而不转移另一个实例的判定。

**提供者消失时关闭全部记忆。** 可选设置明确回退到组合配置。改变该默认值也会改变独立应用及其他独立启用的功能。

## 后果

召回与整理既响应显式编辑，也响应提供者生命周期变化。重新启用只影响新操作，不恢复已中止请求。所有者读取、已准入耐久写入、模型授权、用量归属、额度及 Session/存储格式均保持不变。本决策补充[实时发布](2026-10-31-memory-live-availability.zh.md)与[独立整理取消](2026-10-31-memory-curation-live-availability.zh.md)。项目资格与捕获签发方的检查遵循[整理授权决策](2026-11-01-memory-curation-authority.zh.md)；更大范围的项目撤销审查仍未完成。

## 验证

真实 LLM 准入用例让额度跨越提供者挂载或移除，在销毁前观察取消，随后返回迟到额度但不调用适配器。真实设置提供者用例覆盖挂载、提交、回退、观察者失败及服务替换。实际 SDK 进程覆盖召回、提取与整理在编辑、文件提供者重挂载和移除时的行为，保留请求及额度直到迭代器清理结束。完整隔离旧包可复现取消遗漏，不修改共享源码。
