# Agent Note: 原生翻译在提供方 I/O 前保留其所有者检查

Status: implemented

[English](2026-11-01-native-translation-admission.md) | 中文

## 问题

原生翻译将预备 Flash 调用绑定到选定的提供方。记录输入之后，模型资源准入和凭据解析仍可能等待。原生提供方读取已解析的 Settings 值，资格检查必须使用相同的凭据引用。等待期间原生模型配置或凭据引用发生变化时，必须在提供方 I/O 前拒绝该预备调用。

## 决策

预备流在模型输入之外接收逐调用检查器。资源准入之后、每次实际提供方请求之前执行异步资格检查；所有授权等待结束后，在进入适配器或 I/O 之前同步检查所保留的所有者。重试使用同一个检查器，并传入资源取消信号。翻译器同时保留组合配置字段与提供方已解析的 Settings 快照。所有者失去资格时，原生翻译以 `TRANSLATION_UNAVAILABLE` 中止；已结束使用的调用返还额度。

## 考虑过的替代方案

**只在进入模型流前检查。** 排队准入和适配器异步准备会持续到该检查之后。

**向模型输入附加授权回调或 Session id。** 回调属于进程内授权。原生翻译必须保持为独立片段；携带其 Session id 会启用无关的原生 Session 日志扩展。

## 影响

可选检查器不改变持久模型请求、Session 格式、适配器代次选择或普通流。每个预备调用持有自己的检查器，并发 Consumer 不会意外共用授权。模型不可见的 `translation` 用途独立于 Session 附加来分类用量。它不携带用户权限；子 SDK 解析器接纳该用途，但丢弃子进程提供的归属声明。适配器仍必须为每次提供方请求调用运行时派发授权。

## 验证

受控队列、授权等待、凭据解析和重试覆盖拒绝与额度释放。原生回环测试覆盖官方模型和凭据引用变化、凭据移除、账号模型覆盖与退出登录。真实 SDK 用例比较翻译结果、持久请求与结果记录、片段隔离和额度释放。
