# Agent Note：插件配置恢复默认

Status: implemented

[English](2026-10-23-plugin-config-reset.md) | 中文

## 问题

一个 profile patch 可以包含同一插件的多条配置覆盖。只清除最后一条匹配记录会让更早的覆盖重新生效，因此恢复操作即使报告成功，也可能保留用户配置，无法恢复组合默认值。

## 决定

恢复操作清除当前 profile patch 中所有匹配且非插入记录的配置键。仅含身份元数据的行会移除；启停状态、其他字段、模块名称不匹配的记录和组合包插入项会保留。设置配置仍替换最后一条适用覆盖。

## 备选方案

**追加空配置。** 空覆盖会屏蔽组合声明的配置，可能破坏必需设置，无法恢复默认值。

**只清除最后一行。** patch 的顺序会让更早的配置在该行清除后重新生效。

## 影响

恢复操作还原所属组合的配置，更高优先级的 home 或单次启动 patch 仍保留优先权。它只修改当前 profile patch，并保留其他插件状态。

## 验证

文件系统回归把结果 patch 应用于真实条目列表。已构建 Web profile 的快照通过 PluginManager 恢复两条 MCP 覆盖，验证已加载的服务名称和注册工具，再重启 profile。
