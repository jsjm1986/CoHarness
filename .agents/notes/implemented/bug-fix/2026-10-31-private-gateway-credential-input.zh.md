# Agent Note：私有 Gateway 凭据输入

Status: implemented

[English](2026-10-31-private-gateway-credential-input.md) | 中文

## 问题

JSON 语法诊断可能包含私有凭据字节。无效 URL 错误可能把传入的 origin 保留为错误属性。origin 允许列表还使用不带方括号的 IPv6 地址，与 URL 解析器返回的带方括号主机名比较，导致预期的回环地址被拒绝。

## 决策

凭据 JSON 和 origin 解析使用静态诊断替代引擎错误，不保留原始 cause 或输入属性。通道 I/O 失败保留现有诊断上下文。origin 验证使用规范 URL 主机名与精确回环允许列表比较，包括 `[::1]`。用户信息、公网或通配主机、HTTPS、路径前缀、查询和片段仍被拒绝。应用身份保留继续由[凭据生命周期决策](2026-10-31-gateway-runtime-credential-lifetime.zh.md)持有。

## 曾考虑的替代方案

**将引擎错误保留为 cause。** 启动报告可以遍历它，再次披露同样的输入。

**通过更宽泛的主机规则放行 IPv6。** 规范主机名比较可以接受预期字面地址，而不放行公网或未指定的 IPv6 地址。

## 影响

损坏输入仍然是验证失败，但不会暴露其 JSON 摘录或 origin 文本。文件缺失错误仍可用于排查。源码测试拒绝在检查后的诊断中出现合成输入，并覆盖允许的回环形式与无效 origin 对照。无密钥运行时回放通过编译后的 Node 22 和 24验证私有诊断恢复与 origin 校验。这些夹具不读取真实凭据；解析器放行不代表已覆盖物理 IPv6 Gateway 部署。
