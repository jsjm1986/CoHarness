# Agent Note: 账号管理保留参与者当前权限

Status: implemented

[English](2026-10-28-user-administration-authority.md) | 中文

## Problem

浏览器认证可以在管理员失去权限前完成。随后的账号变更可能在目标查询、密码哈希或数据库锁等待期间保留较早的角色。账号删除还可能在数据事务拒绝管理员之前停止另一个用户的 Runtime。

## Decision

[管理员路由](../../../../gateway/src/admin-api.ts) 将服务器认证参与者传入账号创建、字段修改、密码重置和删除。请求字段不能提供这一身份。[PostgreSQL 账号变更](../../../../gateway/src/postgres/user-service.ts) 在密码哈希和事务准入之后，先锁定可用组织，再检查当前有效且未删除的账号、有效组织成员身份及管理员角色。组织、账号和成员共享锁将获准权限保留至提交。SQLite 适配器在即时事务内检查当前有效的管理员。省略可选参与者仅供受信任的引导与内部维护。

创建在插入账号和分配目录之前授权。资料字段一起提交；被拒绝的更新保留凭据和账号数据。密码重置在哈希后、替换凭据或撤销会话之前授权。既有的禁止自删、最后管理员保护、逻辑删除及保留用户名规则继续由[删除决策](../feature/2026-08-16-gateway-user-logical-deletion.zh.md)说明。

删除将参与者同时传入 [`withStopped`](../../../../gateway/src/instances.ts) 和最终账号事务。初始准入先于排队启动取消及进程终止。[破坏性操作所有者](2026-10-28-project-deletion-lifecycle.zh.md) 在数据工作结束前继续排除替代代次。数据库连接在进程监督及记账前释放，使单连接组装仍可工作。获准停机之后发生的撤权可以拒绝账号删除，同时保留已停止的账号及其文件。

[浏览器认证决策](2026-10-24-browser-authentication-lock-waits.zh.md) 说明会话验证和过期。变更准入定义这些账号写入何时获准；已完成的变更不会为后续独立请求保留管理员权限。

## Alternatives considered

**再次检查缓存的浏览器角色。** 较早的对象不能证明数据库中的当前权限。

**在哈希或事务准入之前授权。** 管理员可以在这两类等待期间失去权限。

**在 Runtime 终止期间保持权限事务。** 进程监督和记账需要自己的数据库操作；单连接池可能死锁。

## Consequences

延迟至撤权之后的有效请求在账号副作用之前返回403。获准停机后的数据拒绝不保证撤销停机。自定义服务组装传递可选参与者参数，而不依赖浏览器对象。通用管理员实例控制及其他管理能力继续保留各自的准入要求。

## Verification

经过认证的 Gateway 转录使用真实 PostgreSQL、SQLite 数据和可观察的合成 Runtime 载体验证当前及已撤权参与者。存储回归覆盖全部七种变更方法，以及排队中的创建、资料修改、删除和密码重置。这些检查不调用模型接口，也不能证明原生 Windows 进程监督。
