# Agent Note: 尚未提交的资源请求独立于远程注册退出

Status: implemented

[English](2026-11-01-resource-registration-retirement.md) | 中文

## 问题

一个 Runtime 会在多个调用方解析归属、等待容量时，串行分配远程资源身份。归属失败或尚未到达 Gateway 的取消请求，必须完成返回并释放本地排队容量，不能等待此前的 HTTP 请求。已尝试注册的请求有不同的义务：其占用需要精确的完成确认。

## 决策

归属准备保持有界，并在调用方范围内启动。已验证的条目进入可移除的就绪集合，由单个串行注册任务处理。归属失败和提交前取消会立即移除本地所有权。已尝试注册的请求被取消时，保留原有完成路径与记账不确定状态。销毁会取消并等待同一批有归属的准备及注册任务。

活跃注册表示容量预留。提供方交付许可前，会在节点事务释放连接后，重新校验已捕获的归属。立即获批的登记和批量轮询返回的活跃结果都会逐笔复核。Gateway 检查同一批次内其他结果时，先前通过的资格可能已撤销。拒绝后按精确操作身份报告尚未启动，释放未使用的占用。

## 考虑过的替代方案

**拒绝调用方但保留排队条目。** 遗留条目会以队列已满为由拒绝其他调用方。

**移除条目，但每个请求仍保留一个串联注册回调。** 取消的回调仍会堆积在缓慢的 HTTP 请求之后。可移除的就绪集合让等待任务的所有权保持有界。

## 影响

操作身份在归属解析完成后串行分配。一个有效请求可以在其他调用方仍解析归属时注册。Wire 消息、已提交策略、精确完成身份和 Session 数据保持不变。该队列不授予执行权限；Gateway 仍重新验证准入归属。

## 验证

受控 HTTP 响应覆盖立即拒绝归属、提交前取消、本地容量复用及连续远程身份。真实 PostgreSQL 检查覆盖注册等待实际节点行锁时的撤权。账号、成员身份、电脑权限或管理员角色撤回后，首次活跃预留不能启动进程；恢复权限后可以执行。可运行的 SDK 组合通过两种语言客户端验证请求结果、精确注册的操作和额度释放；完整原始源码及构建提供方可以复现失败。
