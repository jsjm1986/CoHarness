# Agent Note：独立的 PostgreSQL 控制转发

状态：已实现

[English](2026-11-22-postgres-control-tunnel.md) | 中文

## 问题

受管网关的独立 PostgreSQL 连接池可以共用同一条 SSH TCP 连接。这条连接出现延迟时，即使 PostgreSQL 已完成相应语句，就绪、租约及撤权查询也可能继续等待。

## 决策

可选回环端口让保留控制池和访问失效监听池经独立转发访问同一 PostgreSQL 数据库。该配置保留数据库、凭据和连接选项，业务池继续使用原连接地址。

## 考虑过的替代方案

**延长就绪检查期限。** 同一 SSH 连接仍承载业务与控制请求，网关也会更晚报告无法读取当前授权状态。

## 后果

每条转发都需要独立监督。就绪检查仍要求成功观测最新访问失效状态及核对写入代次。控制转发故障会使网关进入未就绪状态。

## 验证

连接池测试覆盖默认地址、独立端口以及无效转发配置。
