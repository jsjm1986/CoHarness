# Agent Note: 托管工作区必须是严格子目录

Status: implemented

[English](2026-11-04-strict-managed-workspace-descendants.md) | 中文

## Problem

一个规范化路径相对于自身的结果为空。如果把所有非父级的相对路径都视为子目录，就会接受保留的父目录自身。受托管工作区因此可能占用完整的托管根目录，项目根目录验证也会失去更严格的包含检查。Windows 磁盘及共享根目录也需要宿主平台的根目录识别；不同卷上的路径会产生绝对的相对结果，不应被视为重叠。

## Decision

Gateway 使用宿主平台路径比较，要求相对路径非空，拒绝父级遍历和绝对结果，并保留路径规范化处理。项目数据根目录配置拒绝文件系统根目录，包括 Windows 磁盘及共享根目录，同时允许独立卷上的目录。受托管项目目录必须严格位于配置的数据根目录内；受托管工作区必须严格位于其根目录内。既有[项目目录归属](../feature/2026-08-15-project-collaborative-conversations.zh.md)与[管理员目录浏览器](../feature/2026-08-17-gateway-admin-host-directory-browser.zh.md)决策仍分别管理授权规则。

## Alternatives considered

**依赖保留目录重叠检查。** 它有时会因其他原因拒绝项目根目录，却不会拒绝工作区与其自身根目录相等的情况。

**在规范化前比较原始字符串。** 尾部分隔符和等价路径组件仍可能指向同一目录。

## Consequences

选择根目录自身的配置在加载时失败，必须改为子目录。普通兄弟目录与子目录比较继续使用宿主平台路径语义。解析器回归覆盖两类项目目录、受托管工作区、规范化后的相等路径及 Windows 磁盘与共享路径语法。路径语法检查不能证明 Windows 宿主上的文件系统权限。
