# Agent Note: 引导 Runtime 身份确认期间保留初始 Workspace 选择

Status: implemented

[English](2026-10-24-bootstrap-runtime-initial-selection.md) | 中文

## Problem

项目页面可能已经收到完整的 Workspace 与 Session 列表，却仍停在未选择的 Hero。初始选择意图在连接握手前启动。池把临时个人目标解析为已鉴权项目目标时会取消该意图，因此一次性订阅永远无法执行已有的历史优先策略。

首次 Host 握手前已验证的账户上下文，还可能因通用连接重置而丢失验证。会话视口会在这种多余的撤回中取消初始导航，使启动结果取决于响应顺序。

## Decision

Session 池区分首次建立的引导身份与后续目标变化。首次声明保留既有导航 signal，绝不为已被用户取消的意图创建替代意图。独立 Host 建立连接时也确认其身份，因此后续目标变化仍执行正常取消语义。

Runtime 只将首次连接重置标记为初始连接。协作插件在首次握手中保留本页面内已经验证的上下文。首次上下文尚未验证、后续重连或未指明类型的重置，仍撤回验证并替换上下文请求。首次握手事实由事件发送方持有，启动后才安装的监听器不会误把重连当作初始化。[主体所有的布局决策](../architecture/2026-09-23-principal-owned-workbench-layouts.zh.md)继续约束实际身份丢失与账户变化。

历史仍须等待 Runtime 身份鉴权、两个权威列表基线、归档检查及普通 Session 打开完成。身份投影仍会取消尚未被接管的已保存历史读取，并拒绝改标已有引用的 Session 代次。后续目标变化、明确用户导航、账户授权撤回与销毁均保留既有取消所有权。

初始选择从首次基线等待直到历史准备完成并提交期间发布等待反馈。仅凭没有当前 Session，无法区分这段等待与已经确认的空工作区。等待期间隐藏选择提示，但保留已挂载的编辑器；已有当前空白会话时仍保留 Hero。初始选择期间，工作台导航仍可从页首操作。选择过程拥有与导航意图合并的取消 signal，因此释放只结束本次准备，不取消其他历史读取者。工作区基线读取或 Session 准备失败后移除等待反馈，并保存当时权威 Workspace／Session 输入的引用作为重试检查点：反馈发布本身不能触发另一次尝试。

[Workspace 历史优先决策](2026-08-26-workspace-history-first-entry.zh.md)继续负责候选选择。[归档选择决策](2026-10-04-archived-selection-races.zh.md)继续负责归档遮蔽与提交时拒绝；这两个决策均未被取代。

## Alternatives considered

**移除目标变化时的取消。** 否决：已确认目标发生变化时必须取消旧导航及尚未被接管的历史窗口，避免迟到数据成为新选择。

**身份或基线到达后创建全新初选意图。** 否决：它可能覆盖用户在初始化期间明确执行的清空或 Session 导航。

**身份确认前读取或选择。** 否决：账户或空间变化时，不能复用其他 Runtime 的请求、持有代次或私有数据。

**所有连接重置均保留账户验证。** 否决：重连必须重新验证权限，并释放私有布局所有权。只有首次握手可以复用同一页面中新近验证的上下文。

## Consequences

项目引导可以应用与个人引导相同的默认选择，无须额外点击 Workspace 与 Session。基线读取继续独立进行，本改动不增加请求、模型调用、缓存或定时器。Workspace 行展开与明确新建 Session 仍是独立的产品操作。人工采样浏览器状态不用于推断毫秒级改善。

## Verification

真实 Connection controller、Session 池与 Workspace runtime 回归分别控制身份与列表响应。原实现因没有当前 Session 而未通过断言，修复后通过。所属单元测试文件还验证身份到达前清空、历史打开期间清空或手动选择、账户授权撤回、个人身份确认，以及后续目标变化时的取消。事件发送方与协作插件测试区分首次握手、迟到监听器、已验证上下文、重新验证失败与重连。免密钥组装浏览器用例分别控制真实 Host 描述与 Workspace 响应，在释放最后一个列表基线前确认账户上下文，并在首个历史响应受控期间只允许一次历史请求。释放响应后，对照已有 golden 验证自动选择项目会话；后续实时事件同步仍可重新读取尾页。

受控基线与历史响应验证初始阶段只有一个加载状态，不提前显示 Workspace 选择；随后打开已有对话，不创建 Session。工作区基线失败时恢复已有的列表错误和重试按钮；重试期间显示加载，直到基线成功。组件检查保留编辑器节点及已有当前空白会话的 Hero。初始选择释放后，独立持有的历史读取仍能完成。
