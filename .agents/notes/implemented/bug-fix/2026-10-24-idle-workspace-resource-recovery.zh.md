# Agent Note: 视图返回时恢复空闲 Workspace 元数据

Status: implemented

[English](2026-10-24-idle-workspace-resource-recovery.md) | 中文

## Problem

Workspace 资源可能在无人持有期间经历传输断开与恢复。重连只读取仍被订阅或 pin 的资源，因此重新打开空闲缓存记录时，必须区分已经过时的连接失败与仍需用户明确处理的失败。

## Decision

[Workspace 资源注册表](../../../../packages/client/runtime/README.zh.md#workspace-file-resources)在订阅者或 pin 返回时，复核保留的连接不可用失败。已有连接状态检查控制读取接入，未完成读取继续共享，最后一个持有者释放时仍取消所属读取。复核保留已有元数据，并通过普通版本比较标记版本变化。

权限拒绝和普通读取失败保留各自的明确恢复策略。provider 移除时丢弃记录，目标身份仍参与每次资源地址查找。恢复不引入轮询或内容缓存。

[资源模型决策](../architecture/2026-09-05-client-resource-model.zh.md)继续负责资源身份、共享观察和 pin 所有权；本决策补充空闲恢复。

## Alternatives considered

**每次重连都刷新全部空闲记录。** 否决：即使没有视图需要，已经关闭的预览也会执行读取。

**订阅时重试所有失败记录。** 否决：无关失败和权限拒绝有各自的恢复操作，视图重新挂载不能静默重复它们。

**传输恢复后仍要求重新加载。** 否决：所属连接已经可用，已过时的连接失败不应再要求用户额外操作。

## Consequences

返回的视图使用已有元数据读取清除过时的连接失败。并发持有者共享读取，断线期间再次被持有的视图仍等待所属连接恢复。这会省去一次手动元数据重试，不用于宣称网络或渲染器耗时改善。

## Verification

受控注册表回归覆盖订阅者与 pin 返回、保留版本、共享未完成读取，以及权限拒绝和普通失败。两个恢复断言均在原实现上失败。组装浏览器先关闭 CSV 预览，在另一个文件上控制真实池连接断线并确认恢复，然后重新打开空闲 CSV，不点击重新加载，按 golden 核对正常操作。原有活跃预览的布局、选择、滚动和线级权限拒绝断言继续处于同一旅程。
