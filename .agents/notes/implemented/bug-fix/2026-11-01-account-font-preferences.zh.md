# Agent Note: 共享项目字体控件保留账号归属

Status: implemented

[English](2026-11-01-account-font-preferences.md) | 中文

## 问题

主题控件声明 account-or-host 存储，但账号字段路由和 Gateway 遗漏了六项字体字段。因此，共享项目只读 Host 会禁用控件。账号完成较早的外观迁移后，个人字体值仍可能留在旧文件中。

## 决策

账号字段路由、浏览器 JSON 读取和 Gateway 接收六项现有主题字体字段，整数范围和字符串值与控件一致。读写保留认证账号、组织资格和账号级修订号。不同电脑上下文读取同一账号行。项目 Host 写入权限保留现有所有者。

PostgreSQL migration103 增加六项可空 override 列和独立字体导入时间戳。首次账号事务从该账号自己的个人设置文件导入合法且缺失的字体值，保留已有外观、显式字体和空字符串字体列表。导入 override 会推进修订号；空导入完成后仍记录时间戳。存储失败时，导入和时间戳均不提交。源文件保留。

导入完成后，重置会删除 override。时间戳防止后续读取重新恢复旧文件值。已有行全部字体均显式配置时，完成导入不会读取不再需要的旧文件。浏览器可用状态和错误遵循选定的账号 scope；404/501 保留独立 Host 回退。

## 考虑过的替代方案

**写入共享项目 Host 设置。** 成员的个人字体选择将要求项目写入权限，并影响其他成员。

**每当列为 null 时导入。** 重置使用 null 删除 override，后续读取就会恢复旧值。导入时间戳独立于 override 记录完成状态。

**用旧文件替换整个账号主题。** 较早的账号外观和显式新字体应保留当前值。

## 影响

Gateway 与 Web 构建需要匹配的字体字段和 migration103。独立 Host 持久化与主题规范化保持现有行为。本决策补充[账号资格与迁移重试](2026-10-29-account-preference-authority.zh.md)及[字体呈现决策](../architecture/2026-10-17-configurable-font-settings.zh.md)。

## 验证

浏览器 scope 测试保留只读项目 Host，同时六项控件通过账号 JSON 设置和重置。wire 与 mutation 用例覆盖各角色范围、无效值和显式空字体。真实 PostgreSQL 事务覆盖新旧账号的旧值导入、显式值、重置保留、不可读文件重试和不同账号。认证 Gateway 进程通过浏览器 transport 在两个电脑上下文中回放，保留原个人文件，拒绝 actor 字段重定向，并拒绝已停用账号。
