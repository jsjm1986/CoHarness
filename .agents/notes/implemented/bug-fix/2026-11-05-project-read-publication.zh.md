# Agent Note：项目元数据发布使用当前读取权限

Status: implemented

[English](2026-11-05-project-read-publication.md) | 中文

## 问题

项目元数据准备与权限读取可能在不同时间完成。已准备的目录会在成员资格撤回后仍保留项目；登录角色或先前读取的所有者也可能让降级、所有权转移后的 `canManage` 继续为 true。已准备的邀请列表也会在管理权撤回后继续保留其他账号之间的邀请。

## 决策

元数据准备完成后，浏览器项目目录、详情与配置从同一个 PostgreSQL 快照取得当前权限。该读取检查账号、改密要求、组织成员资格、项目、挂载、精确电脑权限和 Steward 资格，不加载电脑元数据。发布要求电脑与准备阶段所选电脑相同。返回的所有者、主题和管理标志均来自该快照。配置能力使用同一份当前权限；保留的 Steward 空间始终不声明成员管理能力。

准备阶段的电脑标识由该请求持有，适配器在读取期间更新缓存视图也不会改变这些标识。项目邀请列表使用同一份最终项目准入。当前管理者可查看所有已准备的邀请；其他仍有资格的成员只收到本人发出或收到的邀请。读取不消耗待处理邀请。

账号范围的邀请历史与待处理数量在准备完成后要求当前浏览器会话，包括会话有效期、注销和改密资格。收发历史属于账号，项目成员资格或电脑使用权撤回后仍予以保留。其他账号之间的邀请要求当前项目管理权限；当前登录角色还会约束隐式管理员权限。最终管理权限读取只使用控制数据库事实，不加载电脑元数据。仅含本人收发历史时不要求项目读取提供方。

用量汇总保留准备前所选的计费所有者与电脑。个人和项目汇总均要求当前浏览器资格；项目读取还要求当前成员资格及精确电脑权限。只读成员仍有读取资格。个人汇总的最终核验要求账号资格；初始 Runtime 选择保留既有权限规则。被拒绝的项目读取不会替换为个人总数。无效月份输入在读取用量前被拒绝。

目录省略已撤权的条目；已撤权详情返回 HTTP 403。账号资格撤回时拒绝目录响应。自定义读取提供方缺失时返回 HTTP 501，权限查询失败时返回 HTTP 503，不携带已准备数据或数据库诊断。Runtime 授权保留独立的凭据与执行规则；浏览器改密资格不替代这些规则。

## 已考虑的替代方案

**重新加载完整项目详情来授权发布。** 电脑元数据加载增加 I/O，也增加权限可能变化的时间段。最终授权只需要控制数据库中的事实。

**从登录角色或准备阶段的所有者推导能力。** 两者都可能早于决定当前权限的所有权与成员资格变化。

## 后果

自定义协作适配器需要为浏览器项目读取及管理者可见的账号邀请历史实现 `projectReadAuthorities(userId, projectId?)`。项目与 Session 格式不变。[项目设置决策](../feature/2026-08-28-project-scoped-settings-management.zh.md)继续负责设置展示与变更准入。
