# Agent Note：待决记忆提取资格

Status: implemented

[English](2026-10-23-pending-memory-extraction.md) | 中文

## 问题

记忆整理为每个会话保留一个运行中的遍和一个待决快照。每次完成回合都替换待决快照，会让确认回复或已写入记忆的回合压掉较早的有效内容。若只把提取资格复制到后续参与者的快照，还会改变已准入工作的[执行主体](2026-10-23-curation-execution-identity.zh.md)。

## 决定

符合提取条件的待决快照仅由另一个符合条件的快照替换。其重放输入、游标目标及执行作用域保持一致。不符合条件的回合仍可替换另一个不符合条件的待决快照，以供合并评估。执行授权和实时功能开关在运行该遍时检查。

## 备选方案

**移除低信号过滤。** 确认回复会在没有有效新内容时发起模型调用。

**把提取资格携带到最新快照。** 较早的工作可能以另一参与者身份运行，并把游标推进到不符合条件的回合之后。

## 影响

队列仍最多保留一个待决快照。其提取游标可以停在后续跳过的回合之前；未来的有效内容回合可以包含那部分较晚历史。

## 验证

确定性的项目空间回归阻塞一次提取，排入另一参与者的有效内容回合，然后准入确认回复或已自行整理的回合。待决提取保留原参与者与序号。真实 Agent、GatewayExecution 和 JSON 记忆回放准入三名参与者，并将持久提取记录归属于提供有效内容的第二名参与者。
