# Agent Note: Bounded diff context and explicit terminal state

Status: implemented

[English](2026-09-22-bounded-diff-and-terminal-state.md) | 中文

## 问题

文件修改呈现器携带的变更前后文本片段包含未变更上下文。把每个旧行标成删除、每个新行标成新增，会误述小改动并夸大计数。终端卡片还需要区分已有输出的运行中命令和退出码未知的已结算命令；隐藏已收到的输出或将未知退出码视为零，都会掩盖执行状态。

## 决策

`DiffBlock` 使用 `diff.structuredPatch`，保留三行上下文并将最大编辑长度设为 256，与上游 Web 实现一致。完成的比较只渲染一次共享上下文，且只统计增删行。超过编辑预算时，将完整输入片段呈现为替换。折叠影响可见行，页脚和剪贴板则保留完整比较结果。输入字段与行终止符规则保持不变。 折叠工具行通过导出的 `diffTotals` 获取 `+A -R`，与展开页脚共用同一有界 hunk 比较。

`TerminalBlock` 在命令运行期间渲染已提供的输出，同时保留运行中指示。没有输出的运行中命令不显示输出占位；复制在结算后可用。显式 `exitCode: null` 渲染本地化的无退出码状态，不能表示成功。终止信号优先。省略退出码时保留既有呈现方式。

共享 shell 呈现解析器在 Bash 与 PowerShell 的 `renderResult` → `presentResult` 路径中，将既有 `[exit code: null]` 标记保留为 `null`。非法数字标记保持为字面输出。模型可见文本和持久标记语法不变；类型化终端视图把未知退出码事实传递到 UI。

[Diff 卡片记录](../feature/2026-07-30-web-diff-card.zh.md) 继续规定渲染位置选择、内联几何与路径分组。[终端卡片记录](../feature/2026-07-28-web-terminal-card.zh.md) 继续规定 ANSI 渲染、几何与剪贴板行为。两份记录保持有效，因为这些决策独立于行比较与执行状态。

## 考虑过的替代方案

**始终为完整的新旧片段着色。** 这避免了比较工作，却会把共享上下文表示为编辑，连相同内容也不例外。有界比较为普通编辑保留精确计数，同时避免无界的编辑距离搜索。

**使用无界比较。** 为每次替换计算精确计数，会让同步浏览器渲染承担昂贵的编辑搜索。固定预算耗尽时，替换回退保留所有输入行，代价是该情况下只能提供近似计数。

**把未知退出码视为成功。** 已完成但没有退出码的进程并未提供退出码为零的证据。在生产渲染器链中保留 `null`，可避免 UI 凭空生成成功退出状态。

## 后果

浏览器产物增加 `diff` 运行时依赖。在编辑预算内，共享行不会夸大总数；超过预算时，总数描述呈现的替换，而非精确编辑距离。运行中输出呈现只消费组件已提供的 props，不向工具快照新增流式数据。

会话预览为窄窗格和手机布局使用八行。上游 Web 预览使用九行；两个视图都从完整比较结果计算总数。浏览器 golden 保留本地预览高度，不改变比较，也不隐藏展开后的任何一行。

## 测试

组件测试覆盖相同文本、三行上下文、分离 hunk、编辑预算两侧、折叠后的复制、运行中输出更新与未知退出码状态。工具卡片测试不依赖类型断言，保留类型化的 `null`。Shell 解析器测试拒绝非法标记，两个 shell 工具均通过实际渲染器到呈现器的往返验证未知退出码。

构建后浏览器的 [diff 场景](../../../../apps/web/tests/diff-context.e2e.ts) 通过真实 composer 发送录制的提示词，并执行真实文件工具。外部字节检查覆盖被编辑文件和一个未改动的同级文件；持久结果元数据、折叠计数、精确上下文及完整展开的 130 行新增／130 行删除替换分别独立断言。只有这些断言通过后，才比较捕获的 ARIA golden。精确场景借用 ACP 属主的 live recording；超预算场景保留上游 authored 模型脚本。每次运行拥有 scaffold 的私有临时工作区，并等待完整 teardown。
