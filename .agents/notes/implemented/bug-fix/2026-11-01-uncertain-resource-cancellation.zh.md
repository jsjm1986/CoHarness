# Agent Note: 不确定记账保留执行取消

Status: implemented

[English](2026-11-01-uncertain-resource-cancellation.md) | 中文

## 问题

不确定报告得到确认后，提供方可以移除本地记账条目，但执行的结束仍未得到确认。只在该条目上保留取消机制，会让已准入的所有者无法收到之后的调用方停止、提供方销毁或记账失败通知。远程占用本身无法停止传输。

## 决策

每个已准入许可组合提供方生命周期、调用方和操作的信号。提供方销毁或记账因无法确认而拒绝继续时，会独立于条目是否保留，中止共享生命周期。不确定确认本身不会取消工作，也不会切断这些取消关联。已确认静止时，仍通过原有精确完成引用和捕获的私有传输报告。

## 考虑过的替代方案

**在静止前保留所有不确定条目。** 远程协调器已经保留不确定占用。本地元数据无需仅为维持取消机制而继续保留。

**报告不确定时取消工作。** 报告未确认清理与请求取消是不同的动作。报告不能凭空增加取消原因。

## 影响

操作记账与取消具有不同的生命周期。移除本地元数据不能释放远程占用，也不能撤销之后的精确完成。[注册退出决策](2026-11-01-resource-registration-retirement.zh.md) 继续约束尚未提交的任务。Wire 消息、配置、Session 记录和 schema 版本保持不变。

## 验证

真实 Gateway HTTP/PostgreSQL 场景在提供方销毁、调用方取消和记账确认失败前报告不确定状态。各类取消仍可被观察到，占用则保持不确定，直到精确释放。可运行 SDK 场景保持真实 HTTP 响应开启，卸载提供方，观察传输关闭，并先后报告不确定与静止。完整原始提供方的执行信号仍保持开启，因此无法通过这些场景。
