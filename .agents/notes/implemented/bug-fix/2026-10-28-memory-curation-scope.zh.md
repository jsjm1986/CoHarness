# Agent Note：记忆合并的作用域约束

Status: implemented

[English](2026-10-28-memory-curation-scope.md) | 中文

## 问题

合并审查一个记忆作用域，并提交该作用域的审查游标。若工具可以访问 Agent 的全部可用作用域，就可能泄露未审查的条目、修改无关记忆，并把其他作用域的写入计入当前游标。省略作用域时默认使用个人作用域，也会误导工作区审查。

## 决定

每轮捕获其允许的作用域：提取使用全部可用作用域，合并只使用选定作用域。每条工具使用该集合与 Agent 当前作用域的交集。无筛选搜索只搜索此集合。省略作用域时使用唯一捕获的作用域；显式指定不可用作用域，会在访问存储前拒绝。搜索、读取、保存与删除均受此约束。

这补充了[触发回合的执行身份](2026-10-23-curation-execution-identity.zh.md)与[写入授权生命周期](2026-10-23-memory-member-authority.zh.md)；参与者归属和写入授权均不能替代本轮的作用域约束。

## 备选方案

**依赖提示词或工具模式。** 模型可以返回未审查的其他作用域。执行器负责限定可用操作，并在每次调用时落实。

**合并保留 Agent 的全部作用域。** 提示词和游标只覆盖一个作用域。跨作用域读取与变更需要另行设计审查输入及游标计数。

## 影响

提取仍可关联个人与工作区记忆。合并只读写一个作用域，其成功写入计数也归属同一游标。关闭记忆会撤下可执行作用域，即使模型响应已发出。

## 验证

六个源代码回归覆盖四条工具的跨作用域调用、无筛选搜索及省略工作区作用域。真实 Loader、Agent、辅助模型运行时及 JSON 存储快照检查面向模型的拒绝结果，以及两个作用域最终的耐久条目。
