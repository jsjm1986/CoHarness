# Agent Note: 管理员 JSON 读取在发送时复核资格

Status: implemented

[English](2026-11-05-administrator-read-publication.md) | 中文

## 问题

Admin 读取准备其他账号的目录、模型策略或用量数据时，已认证管理员可能失去资格。仅在 HTTP 入口检查，会让已准备结果在撤权提交后继续可用。即使正文被拒绝，审计总数与归档附件名称等响应头仍可能暴露元数据。

## 决定

[请求持有的回应器](../../../../gateway/src/admin-response.ts)在发送 GET、HEAD 或显式选择的 POST 读取结果前，通过当前用户服务复核已认证账号。备份配置预览选择读取资格，即使其准备阶段的校验可能已经提交。组织模型发现也在目录 HTTP 请求完成后核验结果的发送资格。查询的生效状态包含组织和成员资格；删除、失去管理员角色及要求修改密码也会拒绝发送。结果不会缓存供其他回应复用。查询失败返回503及安全诊断；明确失去资格返回403。

[Admin 路由](../../../../gateway/src/admin-api.ts)及其 [Runtime 管理委托](../../../../gateway/src/runtime-management-api.ts)等待该回应器。数据专用响应头交给同一操作，因此拒绝数据时也隐藏审计总数和归档下载名称。JSON 准备沿用现有服务，并在最终查询前释放它们的借用连接。读取选出的错误回应使用相同资格检查；外层错误处理器只发送自身的安全拒绝。

变更授权仍由提交变更的服务持有。回应器不会因管理员之后发生变化，就把已提交变更改报为失败。[资源策略读取器](2026-11-05-resource-policy-read-authority.zh.md)独立保留数据库读取期间的资格；若撤权在发送前提交，HTTP 发送检查仍可拒绝该结果。活跃文档流与远程传输保留各自的撤权和清理规则。

## 考虑过但未采用

**信任 HTTP 入口捕获的管理员对象。** 它无法描述数据准备期间已提交的角色或账号变化。

**只授权 JSON 正文，提前发送元数据头。** 被拒绝的调用者仍可推断数量或下载身份。一个可等待的发送操作同时持有两者。

**所有来源准备数据期间始终保留管理员数据库事务。** 来源可能跨文件、其他节点或多个服务。在这些工作期间保留借用连接会耗尽单连接池，也不能替代来源自身的授权。

## 影响

Admin JSON 读取在发送时增加一次当前账号查询。并发撤权可能拒绝按早先权限准备的结果。任何回应都无法撤回已交给传输层的字节。账号适配器必须返回当前生效资格，并对缺失或已删除账号返回 null；缓存的候选角色无法实现该操作。既有数据格式与变更结果保持不变。
