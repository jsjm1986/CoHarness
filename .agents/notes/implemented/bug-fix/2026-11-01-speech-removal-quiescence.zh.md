# Agent Note: 语音撤回保留完成状态的归属

Status: implemented

[English](2026-11-01-speech-removal-quiescence.md) | 中文

## 问题

从路由表移除语音提供方，并不代表已接纳的识别任务结束。并发注销或注册表关闭可能因找不到注册而提前返回。订阅注销失败也可能跳过取消和等待。

## 决策

每个注册在开始清理前保留唯一的注销 Promise。注册表在可路由提供方之外单独跟踪这些 Promise。撤回立即移除路由，取消并等待已接纳录音结束，即使订阅清理抛错也执行。重复注销等待相同结果。注册表关闭在报告清理错误之前，等待所有活跃或已脱离路由的注销完成。

## 考虑过的替代方案

**等待任务结束后才从路由表移除。** 这会允许撤回期间接纳新的识别请求。

**将缺少路由条目视为清理完成。** 路由可用性不能证明先前接纳的任务是否结束。

## 影响

注销完成证明该注册的任务已结束。路由仍立即拒绝新请求，替代提供方保留独立注册，提供方拥有的准备任务仍保持自己的生命周期。服务方法、持久设置与 Session 格式不变。

## 验证

受控外部任务覆盖并发注销、注册表关闭和订阅清理异常。真实 SDK 应用比较路由撤回与任务放行前后的完成状态。源码及构建后的完整旧包可暴露提前返回。
