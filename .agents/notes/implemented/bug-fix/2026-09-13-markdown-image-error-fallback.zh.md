# Agent Note: Markdown 图片失败时保留作者内容

Status: implemented

[English](2026-09-13-markdown-image-error-fallback.md) | 中文

## 问题

允许的远程图片在 Markdown 已生成 `<img>` 后仍可能加载失败。旧渲染器会留下没有可读作者内容的破损图片框，后续图片源变化时还可能复用这个失败元素。

## 决策

`MarkdownText` 为允许的远程图片拥有一个小型有状态包装器。加载错误时，图片替换为作者的 alt 文本；alt 为空时显示原始目标。图片 key 包含解析后的源，因此源变化会获得全新的加载状态。不支持或本地目标继续使用原有的惰性 alt 回退。

## 考虑过的替代方案

**自动重试失败的图片。** 不予采纳，因为远程服务器不可用时会重复请求，读者也得不到新信息。

**显示通用错误标签。** 不予采纳，因为这会丢失能标识请求图片的 assistant 作者上下文。

## 结果

远程媒体失败后仍然可读，源变化后可以恢复，且不会重新挂载整个 Markdown 树。包装器为每个渲染中的远程图片增加一个 React 状态单元，不改变 URL 白名单、流式冻结规则或模型可见文本。
