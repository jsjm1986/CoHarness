# Agent Note：文档列表全选框并入说明行

状态：已实现

[English](2026-09-15-doc-list-header-orphan-row.md) | 中文

## 问题

`DocumentsModal` 曾渲染一个独立的 `listHeader` 横条，里面只有全选本页的复选框：一条整宽带边框的行，仅有一个未勾选框且无任何文字，夹在作用域说明行和第一个日期分组之间，看起来像渲染残缺的空行。

## 决策

全选复选框并入已有的 `.caption` 说明行，位于作用域标签与文档计数之前。该行本就是列表的表头——在概览与回收站面板中随列表一起隐藏——复选框因此保持原有可见性规则，无需单独横条。工作台菜单动作项补齐与会话行菜单相同的前置图标约定，Session 日志导出胶囊的中文标签完成翻译（`Session 日志`）。

## 备选方案

**保留横条并加文字说明。** 否决：在说明行之下再立一条表头等于为一个控件复制一层结构；admin 归档表已示范同一模式——全选框位于带标签的表头内。

## 影响

文档列表少一行冗余；选中状态与 `selectPage` 的无障碍标签不变，批量选择相关测试不受影响。

## 验证

`packages/client/ui-documents/tests/components.client.spec.tsx` 通过 `selection.selectPage` 角色查询覆盖全选复选框。部署产物实测：不再渲染 `listHeader` 元素，复选框与下方各行复选框对齐。
