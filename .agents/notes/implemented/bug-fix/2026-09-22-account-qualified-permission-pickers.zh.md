# Agent Note: 按账户资格限制权限选择器

Status: implemented

[English](2026-09-22-account-qualified-permission-pickers.md) | 中文

## Problem

进程级权限目录描述 Host 能力，不代表当前账户资格。把所有 preset 都显示为可选，会让非管理员请求 Full，或让不具备资格的账户请求 Auto；刷新失败后保留的账户数据还可能继续展示旧资格。工作台窗格不能借用其他运行时的独立本机状态。

## Decision

现有协作上下文携带明确的 Full 和 Auto 资格。刷新及连接替换时撤销验证状态，旧 HTTP 响应不能发布到新一代连接。现有运行时 UI 策略只发布派生账户资格。每个会话绑定都携带自身连接的描述，通过显式受管标记区分独立本机运行和未知状态。共享选择函数结合这些来源，不修改或复制 Host 目录。

输入框、`/permission` 弹层和新会话默认值行会禁用不可用选项并提供本地化原因，提交前再次检查。已经选择但无法使用的 Auto 保持原值，并提示选择普通模式。Auto 仅用于单次会话：默认 schema 排除它，默认值 UI 控制器也会拒绝它。具备资格的 Full 选择仍需要[完全权限确认框](../feature/2026-07-31-gui-full-access-confirmation.zh.md)；风险确认不代表授权。

弹层可以订阅自身选项源的失效通知。该来源变化时关闭弹层，在所有结束路径释放订阅，并保持无关命令弹层不变。连接独有的数据源让工作台中分别暂存的目标互相独立。

## Alternatives considered

**按照最近一次账户请求过滤共享 Host 目录。** 其他账户和会话共享该进程能力表，因此拒绝此方案。

**根据 HTTP 错误或回环地址推断本机权限。** Gateway 部署也可能使用回环地址，并临时返回 401、503 或非法数据。只有所属 Host 的显式独立运行标记允许本机行为，因此拒绝此方案。

**资格消失后自动替换 Auto。** 这会未经用户决定修改会话策略，并掩盖服务器真正执行的状态，因此拒绝此方案。

## Consequences

普通选项仍遵循原有写入策略。资格验证尚未完成时，Full 和 Auto 可能暂时不可用；陈旧菜单不能提交这些选择。最终授权由 Host 和 Gateway 负责；UI 覆盖不能证明默认值写入的服务端检查已经完成。

组件和源代码测试覆盖字段解析、刷新失败、过期响应、账户资格、目标归属、陈旧确认框、禁用选项和弹层清理。联合浏览器及构建产物验证仍属于集成收口；本注记不代表上游升级已经完成。
