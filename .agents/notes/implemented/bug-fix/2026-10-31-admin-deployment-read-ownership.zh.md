# Agent Note: Admin 部署读取的归属

Status: implemented

[English](2026-10-31-admin-deployment-read-ownership.md) | 中文

## 问题

部署轮询可能快于慢电脑的响应，并在页面关闭后保留请求。写入后的手动刷新还需要比已在读取的快照更新的数据。先翻译诊断再匹配错误码，会丢失针对当前操作的恢复提示。

## 决策

每个部署页面先读取初始入口策略，再加载集群与备份快照，随后持有一个读取操作及其取消信号。定时轮询不增加重叠或排队工作。显式刷新合并为当前读取结束后的一个后继读取；卸载时取消传输并丢弃迟到结果。

入口元数据使用共享账号读取接口，在 Runtime 转发前返回。配置写入继续检查管理员权限。Admin 的类型化错误分别保留 Gateway 错误码与本地化显示文字；操作处理按错误码判断。

## 考虑过的替代方案

**每次定时触发都发出请求。** 慢响应会累积正在执行的鉴权和数据库操作。

**每次刷新都复用正在读取的快照。** 写入前发起的读取不能证明写入后的状态。

**匹配翻译后的文字。** 语言切换及针对操作的提示无法保留稳定的错误标识。

## 影响

慢读取保留已有信息，同时限制每个文档的请求负载。写入后的显式刷新可读取已提交状态，不同步其他标签页的表单或目标。[部署参考](../../../../gateway/docs/deployment-topology/README.zh.md) 说明入口范围与配置行为。
