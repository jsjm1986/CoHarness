# Agent Note: 语音偏好跟随 Settings 提供方

Status: implemented

[English](2026-11-01-speech-settings-provider-lifetime.md) | 中文

## 问题

语音识别独立于提供方缓存首次取得的 Settings 作用域。提供方移除后仍显示旧偏好；替换提供方后，后续保存可能交给已卸载的写入器，而不是当前设置文件。

## 决策

可选 Settings 注入持有命名空间注册、观察者与缓存作用域。绑定时发布新提供方解析后的选择；撤回时清除作用域并发布组合默认值。保存要求当前绑定可用，并在持久化结束后再次检查其归属。提供方变化时拒绝保存确认，原文件已提交的数据仍保留。语音注册表卸载时先取消并等待自己的任务，再释放可选绑定。

## 考虑过的替代方案

**缓存延迟创建的作用域。** 作用域属于其提供方，不能在提供方撤回后继续使用。

**随 Settings 重启语音识别。** 录音与识别器注册具有独立生命周期，替换偏好存储不要求重启它们。

## 影响

观察者会收到偏好存储变化。默认值解析和后续保存使用当前提供方。持久化命名空间字段、服务方法、音频路由和 Session 格式均不变。

## 验证

真实文件提供方覆盖撤回、替换、写入新文件、订阅更新，以及写入过程中的绑定撤回。可运行 SDK 应用保留语音服务并修改 Settings Loader 条目，比较结果选择和保存的文件。
