# Agent Note: 记忆辅助请求记录与生命周期归属

Status: implemented

[English](2026-10-24-memory-auxiliary-ownership.md) | 中文

## 问题

提取和整理根据 Session 前缀、当前记忆目录和中间工具结果构造请求。召回另行构造选择器请求。这些输入经 LLM 服务发送，却没有各自的持久请求记录；目录被后续编辑后，便无法从当前记忆状态重建先前的模型输入。

召回仅在回合结束时取消，遗漏了 Session 销毁和插件卸载。移除插件监听器可能留下仍在运行的模型流，并允许之后注入记忆。已经进入的步骤前监听器也可能恢复执行，在卸载后启动选择器。

## 决策

每次辅助请求通过 `prepareCall()` 固定已解析的适配器和配置。召回记录 `memory/recall-request`；提取或整理的每个模型轮次记录 `memory/curation-request`，携带遍类型和从零开始的轮次。不可变请求包含已解析模型设置、消息，以及存在时的工具和工具历史。取消与授权对象仅留在运行时。追加日志失败会阻止发送。请求显式选择触发 Session 的执行资源归属，并继续通过正常 LLM 策略、准入和计量。

`memory-context` 和 `memory-curation` 均提供各自经过校验的 `maxOutputTokens` 配置。默认仍为 5,000，与主对话设置独立。部署无需编辑源码即可选择更小或更大的正安全整数；零、小数和不安全上限会在配置校验时失败。日志中的已准备请求保留所配置的上限。

召回在按 Session 调度的标记之外保留独立的完成归属。回合结束和 Session 销毁会取消当前选择器；插件卸载停止准入、取消全部未完成选择器，并等待模型流和读取清理结束，包括调度标记已经移除的工作。暂停的步骤前监听器不能在卸载后启动工作。已完成写入和游标发布继续遵循[整理变更与取消规则](2026-10-23-memory-mutation-outcomes.zh.md)。

功能设置变化也会按[实时可用性决策](2026-10-31-memory-live-availability.zh.md)取消活动召回请求，并由同一完成所有者等待其清理。

提取与整理按[整理实时操作规则](2026-10-31-memory-curation-live-availability.zh.md)分别保留设置取消能力，Session 通道继续拥有清理和排队回合。

## 影响

两个请求事件是 Session 格式版本 7 中读取时必须理解的词汇扩展。当前写入器不会把它们标为 ignorable。不认识任一事件的旧构建会拒绝日志，避免重建不完整的模型输入。这些记录不进入主模型对话，也不改变记忆域记录。提取游标仍指向被审查的已完成回合，而不是之后追加的辅助事件。

本变更持有召回工作直到其结束；它不证明包围所有者关闭时无关提供者资源之间的通用顺序。[Memory 待决获取决策](2026-10-24-memory-domain-open-disposal.zh.md)覆盖另一条提供者路径。

## 验证

负向对照复现了提取与召回请求记录缺失，以及插件或 Session 销毁后选择器未取消的问题。单元检查比较完整日志请求与发送输入，包括后续工具轮次。受控的真实 LLM 迭代器暂停清理，证明插件销毁必须等待其结束；另一个屏障证明暂停的步骤前监听器不能在卸载后准入工作。

共享的无密钥 SDK 组合通过真实 Loader、JSON 记忆域和确定性适配器运行召回、提取、整理。适配器在响应前逐项比较完整持久请求与实际输入。TypeScript 和 Python SDK 黄金输出保留全部三种请求、分别配置的 64-token 召回与 32-token 整理上限，以及完成记录：4 个模型许可获准，其中 3 个明确归属 Session 执行，4 个全部静止。随后两个 SDK 均在新的运行时恢复持久 Session，并完成另一回合。此夹具用受控许可提供者验证 LLM 准入接口；PostgreSQL 调度与真实模型 HTTP 传输由独立的 Gateway 验收证据覆盖。

夹具检查仍活跃的执行归属许可，而非最后获得的许可：对话与召回准入可以在适配器发送前交叠。辅助断言失败会拒绝等待中的主夹具流，使归属检查失败直接报告原因，不再让恢复回合一直等待。

## 考虑过的替代方案

**从主请求或当前目录重建辅助输入。** 整理有独立输入，工具轮次会加入结果，目录内容也可能在发送后变化。

**只记录路由名称，或在发送时使用可变的适配器默认值。** 这样会遗漏提供者可见设置，也无法证明日志请求选择了实际执行的适配器。

**只取消调度表中仍存在的选择器。** 回合或 Session 取消可能在模型迭代器仍清理时移除该标记。完成归属必须持有实际任务直到结束。
