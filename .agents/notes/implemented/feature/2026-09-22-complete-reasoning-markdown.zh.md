# Agent Note：Web 折叠区中的完整推理 Markdown

Status: implemented

[English](2026-09-22-complete-reasoning-markdown.md) | 中文

## 问题

推理折叠区会将流式正文截为最后 16 KiB，即使读者已经展开也一样。持久化文本完整，但可见阅读面丢失前文，并将 Markdown 当作普通文字显示。

## 决策

在现有[会话](../../../../packages/client/ui-conversation/README.zh.md)折叠区与 [Markdown 渲染器](../../../../packages/client/ui-primitives/README.zh.md)中采用 alpha.2 上游的紧凑 Markdown 呈现。展开时使用现有增量解析器渲染完整源码。已完成块保留缓存元素，正文不会被末尾片段替换。折叠按钮保持粘性定位，紧凑代码栏则保持普通文档流。

保留[本地摘要跟随](2026-08-02-web-thinking-tail-scroll.zh.md)：实时摘要通过现有节流滚动更新跟随最新非空行，结算后跳过前导排版空白。摘要省略强调标记。展开和折叠不会修改持久化文本、移动会话滚动位置或改变模型输入。

## 考虑过的替代方案

**保留有界的展开末尾片段以限制渲染工作。** 这恰好在读者要求检查时隐藏内容。增量解析可以减少重复工作，同时保留完整正文。

**用独立动画替换本地流式跟随。** 移动必须跟随到达的内容，并在生成暂停时停止。现有节流更新已经提供该行为。

## 结果

展开推理采用 Markdown 语义，因此排版空白会被解析，而非逐字显示；围栏代码保留缩进。正文与紧凑变体使用相同的安全处理和链接规则。折叠推理不挂载 Markdown 正文。长篇展开内容仍是阅读面，不会自动滚动使读者离开当前位置。

回归测试验证超过 16 KiB 后仍保留首个决策、全部 900 段及新增文本，检查语义强调和安全链接，并保留摘要跟随和结算复位。代码栏 DOM 夹具仅增加明确的样式属性。
