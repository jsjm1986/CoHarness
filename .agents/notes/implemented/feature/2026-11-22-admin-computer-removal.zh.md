# Agent Note：移除不再使用的电脑登记

Status: implemented

[English](2026-11-22-admin-computer-removal.md) | 中文

## 问题

Admin 可以在电脑部署前预留名称。撤销权限和退出接入会保留电脑身份，供本机恢复独立工作。已弃用的登记仍占用该名称，并计入组织电脑名册。

## 决策

[部署目录](../../../../gateway/docs/deployment-topology/README.zh.md#transitions-and-recovery)逐台核验电脑身份，并要求二次确认。主入口在事务中检查管理员权限、服务模式、已核验修订号、当前使用状态及持久关联。外键检查覆盖会发生级联的关系。节点行锁和缺少节点外键的账本锁保护最终核验。组织登记移除和审计事件一并提交。

## 备选方案

**在 Admin 隐藏该行。** 隐藏的登记仍占用名称，也仍计入数据库名册。移除登记可让使用名册的功能看到一致结果。

**级联删除关联记录。** 权限、项目和恢复关联对应管理员可能仍需使用的数据和工作。核验窗口列出这些关联，便于管理员通过相应功能处理。

## 影响

移除保留本机文件和已有审计事件。迁移 146 保留签发请求标识，并清除它对已移除电脑的引用。重试同一请求会返回冲突，旧接入码不能接入。再次使用原名称需要签发新的电脑身份。
