# Agent Note：DeepSeek 图片计价使用 V41 token 网格

状态：已实现

[English](2026-09-13-deepseek-v41-image-token-calculator.md) | 中文

## 问题

提供方目录已经暴露 V41 图片模型，但 CoHarness 仍对所有保留图片使用较早的 V4 视觉 token 估算器，导致当前图片请求的启发式上下文压力和请求前计价明显偏低。

## 决策

采用提供方的 V41 网格计算：把低于 544×544 像素下限的图片放大，按 14px patch、每轴 3:1 下采样投影，并在单图 1,024 token 上限内求解保持宽高比的最大网格。提供方回传的 usage 继续作为计费和展示的权威。现有请求图片字节、像素、移除、Files API 与取消策略保持不变。

共享估算器仍是 DeepSeek 请求计价使用的路由无关 helper。现有 V4 模型 id 继续使用同一提供方适配器，也采用当前估算器；这只影响启发式估算，因为完成请求会用准确 usage 替换它。

## 结果

上下文压力、压缩决策和请求图片计价现在反映当前 V41 图片成本模型。图片尺寸和确定性请求文本保持不变。计算器有界，并通过与旧实现相同的投影迭代收敛。

## 备选方案

**所有模型继续使用 V4 计算器。** 当前目录已经包含 V41，而旧上限会明显低估其图片请求。

**只使用提供方 usage。** 完成请求后的准确 usage 是权威，但请求前压力与压缩决策仍需要有界估算。

## 验证

提供方参考样例、极端宽高比、上限行为、low-detail 投影、请求图片计价及现有 DeepSeek 适配器测试通过。由于估算器不能替代响应中的 usage 字段，仍应在包含真实图片请求的部署中核验实际提供方用量。
