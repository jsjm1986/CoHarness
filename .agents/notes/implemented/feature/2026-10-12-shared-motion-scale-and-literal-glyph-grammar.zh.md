# Agent Note: 客户端统一动效标尺与字义图标语法

Status: implemented

[English](2026-10-12-shared-motion-scale-and-literal-glyph-grammar.md) | 中文

## 问题

Web 客户端各自为政的视觉方言逐渐堆积：每个功能族自选过渡时长与缓动，图标按松散隐喻挑选（项目空间用分享箭头、归档会话用通用符号），外框叠成多行头部，次级面擅自使用有边框横幅与共享词汇并不认可的系统原生下拉。审美漂移逐面累积，新贡献方继承的是不一致而非体系。

## 决策

客户端收敛到一套设计语法，含三个具名词汇表，各自集中定义、逐面应用。

- **动效标尺 token 化，而非逐面散落。** `--dsw-motion-duration-*` 与 `--dsw-motion-ease-*` 定义在 `base.css`；菜单、模态、折叠行、输入区、侧栏行、设置、消息操作、工作台与共享基元全部消费同一标尺。弹出层以方向性缩放淡入进场，卡片与停靠条挂载时上浮，交互行、胶囊、标签页与开关共享一致的 hover/active 过渡——全部经 `prefers-reduced-motion` 门控。动效永不推动布局：进场动画只在已预留的几何内做不透明度与变换。
- **图标命名通道，而非隐喻。** 字形选择按字面义：项目空间是 `Users`（对应个人空间的 `User`），保留的维护中枢空间是 `Shield`（与常驻提示卡同一字形），归档会话有独立导航字形，弱隐喻全部重映射为各控件真正打开的字面通道。新控件挑选命名其作用对象的字形；没有合适字形时扩展 `ui-primitives` 的 ic_ds_ 图标表，而不是挪用无关动作图标。
- **外框降噪进共享几何。** 会话头部压平为单条不换行；会话日志导出卡片与命令退出 Web 组合；文档管理器的提示改为无边框着色条；下拉放弃系统箭头改用共享 chevron；输入框共享 3px 强调聚焦环；次级面复用浮起胶囊与图标瓦片习语，不再自造局部容器。

## 备选方案

**每个打磨提交各记一篇笔记。** 放弃：这些提交实现的是同一个设计方向；拆开记录会把一套词汇散成八篇，并诱使后续贡献方各取片段引用。

**过渡时长继续作为各面局部常量。** 放弃：那正是本次要消除的漂移——局部时长孤立看相似，组合时发散。token 不可能逐面漂移。

**把 steward/图标重映射当作一次性 bug 修复。** 放弃：每次重映射都是图标规则的实例——把规则记录下来，才能阻止下一个隐喻图标以"只是个图标"为由混入。

## 影响

新的客户端界面通过消费 token 与 ic_ds_ 表继承动效、图标与外框几何；某个面需要定制时长或表外字形，就是应升级设计决策的信号，而非直接落地局部常量。动效标尺是全客户端时长与缓动的唯一变更点。会话日志导出卸载前创建的会话保留完整转录——退役的只是下载入口。
