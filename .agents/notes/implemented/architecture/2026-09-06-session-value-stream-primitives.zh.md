# Agent Note：Session 值与助手流基础能力

状态：已实现

[English](2026-09-06-session-value-stream-primitives.md) | 中文

## 问题

Session 迁移和重放需要无损 JSON 快照、不可变发布值，以及助手流分块的紧凑表示。如果持久化层和 LLM 包各自实现这些能力，格式校验和重放行为会逐渐分叉。

## 决策

`@deepseek-ai/dsh-util-values` 统一提供无状态的 JSON 校验、脱离原对象的快照、结构比较、深度冻结和穷尽联合类型辅助函数。`@deepseek-ai/dsh-llm/assistant-stream` 提供无损的带时间戳助手流累加器和展开器。累加器会校验并快照每个输入分块，合并相邻且兼容的增量，同时保留精确时间和分块边界以便重放。

这些能力是增量基础设施。现有 Session 格式和持久化协调器在 SessionHandle 与迁移层采用它们之前仍是权威实现。

## 考虑过的替代方案

**在每个持久化 provider 中复制校验逻辑。** 拒绝，因为 JSON 损失规则和快照所有权会在 JSONL、Gateway 以及未来 provider 之间分叉。

**只保存重建后的助手文本和工具参数。** 拒绝，因为重放和模型可见历史需要增量边界、时间戳以及非文本分块。

**原样采用上游 Session 包。** 拒绝，因为上游 v2 类型假设的持久化 API 与 CoHarness 不同；可以复用基础能力，但不能引入不兼容的生命周期语义。

## 结果

Session 迁移可以使用同一套无损 JSON 运行时定义。助手尝试事件可以保存紧凑流数据，而无需再保留一份原始分块列表。这些基础能力本身不会改变磁盘格式，也不会让 Session 创建变为异步；这些变化仍将拆成独立且可测试的步骤。

## 验证

助手流单元测试、包级类型检查、host library 构建和工作区依赖检查覆盖了本次新增内容。
