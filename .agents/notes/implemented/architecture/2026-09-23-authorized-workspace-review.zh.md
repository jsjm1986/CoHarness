# Agent Note：在所属运行节点授权历史工作区审阅

Status: implemented

[English](2026-09-23-authorized-workspace-review.md) | 中文

## 问题

轮次比较与当前工作区文件回答不同的问题。用当前文件重建比较会丢失后续编辑和删除的历史。Web 外壳直接请求相对 URL，也会丢失会话所属的个人或项目运行节点。

## 决定

上游[工作区记录器](../../../../packages/deliverables/workspace-changes/README.zh.md)负责轮次快照，通过 `workspace/changes` 通知。[present 工具](../../../../packages/deliverables/tool-present/README.zh.md)另行记录显式交付。Web 消费者使用持久事件坐标，不把助手正文解释成文件元数据。

历史摘要与 diff 通过 ApiProxy 现有鉴权传输读取。授权先于记录器查询，检查会话工作区及每条记录路径，并在异步读取后再次执行。撤权、取消、会话替换和记录器释放都阻止迟到内容返回。存储路径与 Git 对象标识保留在服务端。已删除文件仍可审阅，无需当前文件存在。

记录器要求配套的文件系统与子进程提供方。Git 及其临时索引在工作区所属目标执行，规范路径、主目录与临时目录均来自该目标。文件工具的内容副本通过受限且校验版本的 FS 窗口读取，保存在 Host 拥有的内容存储中。正常释放先删除目标快照，再关闭连接；目标不可达时报告清理失败。本机与 SSH 工作区共用上游轮次记录器、摘要语义与临时生命周期。

工作区注册使用同一运行节点文件系统解析规范路径、历史头部分组、会话挂接与实时状态。远端目录缺失或连接失败不能回退到 Host 的同名目录。注册表等待该提供方就绪后才初始化存储；目录被重定向到其他目标后，不再报告为已注册的工作区。注册表存储始终属于一个固定执行目标；连接归属与共享需要独立的 Gateway 授权。

每个被持有的会话在其确切运行节点连接上拥有自己的客户端读取器。连接替换清除摘要与比较缓存；会话释放取消读取并移除读取器。右侧栏在打开或恢复资源前检查其声明的会话。隐藏的审阅标签不主动读取文件比较。现有工作区资源服务负责当前文件预览，不另建历史审阅实现。

原生打开需要 Host 明确声明独立本机模式、基础运行节点、loopback 访问以及可用的桌面打开器。Gateway 保留授权预览，不获得服务端桌面权限。文件管理器操作通过现有 Host 方法打开所在目录，如实描述此行为，不承诺平台特定的文件选中效果。

## 考虑过的替代方案

- **按需比较当前文件：** 后续编辑或删除会静默替换历史证据。
- **照搬上游同源 HTTP 调用：** 项目请求会发往 Web 外壳的运行节点，而非会话所属节点。
- **被持有会话共用一个缓存：** 私有数据可能超过授权生命周期留存，也会混淆连接替换后相同的会话坐标。

## 相关决定

模型指引采用上游的 Markdown 链接格式和已登记的提示词顺序。渲染器保留行内代码匹配以支持已有记录，不将新回复限制为同一轮次修改过的文件。

[工作区链接记录](../feature/2026-07-31-web-workspace-file-links.zh.md)继续负责原生打开的理由和修改位置回退。[行内引用记录](../feature/2026-08-07-web-inline-file-mentions.zh.md)继续负责精确路径与唯一文件名消歧。[账号隔离侧栏记录](2026-09-23-account-scoped-auxiliary-sidebar.zh.md)负责布局及资源身份。这些决定仍保持有效，本适配层不替代其独立要求。

## 后果

读取端必须识别的事件持久保存路径与通知，不把文件内容复制到 Session 日志，也不改变格式代次。历史摘要随记录器释放而过期。当前文件预览保留独立的文件系统授权及生命周期。
