# Agent Note：插件持有的 Session 消息投影

状态：已实施

[English](2026-09-18-session-message-projections.md) | 中文

## 问题

插件持有的消息变化必须能够重放，且不能修改已提交事件。解释器卸载后，缓存消息必须不可继续读取。

## 决策

[Session](../../../../packages/core/session/README.zh.md) 在接受事件前解释插件持有的内容决策。surface manager 规划更新时不修改现有消息，在日志接受后提交解释器返回的不可变副本，并通过区别于位置替换代次的内容代次使派生缓存失效。原始事件保持不变。

注册归插件 fiber 所有。会话在创建、持久化恢复与 fork 时借用定义；移除已使用的定义会使缓存决策和已提交但尚未折叠的决策失效。未提交的候选不保留解释器。这防止解释器消失后，重放静默展示原始内容。

## 本地适配

保留本地 `seedSource: 'persistence'` 所有权协议、绝对序号事件窗口、打包 chunk 记录及不可变 Session 代次。目录生成器根据 `@messageProjection` 派生必需解释器，并拒绝同时执行 surface 位置操作的声明。本阶段没有生产事件使用该注解；图片 offload 留给后续消费者。测试提供必需的 fixture 类型，不将其加入生产目录。

## 考虑过的替代方案

修改源事件会破坏不可变日志。在 Session 中对插件事件类型进行特判会将重放与提供方耦合。解释器卸载后返回原始消息会静默丢失已提交决策。

## 影响

五项回归覆盖缺少解释器、原子拒绝、重放、恢复、fork、卸载、窗口及未提交候选。生成器用例覆盖发现与非法双重声明。真实 Loader 预设场景在 `agent/message-entered` 时应用已记录决策，验证持久输入未变，并要求首个模型请求包含投影文本。现有 TypeScript SDK 转录保持不变。此机制不改变 wire envelope 或 Session 格式版本。
