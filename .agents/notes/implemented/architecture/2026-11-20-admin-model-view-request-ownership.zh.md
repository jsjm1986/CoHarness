# Agent Note: Admin 模型视图分别管理就绪状态和数据读取

Status: implemented

[English](2026-11-20-admin-model-view-request-ownership.md) | 中文

## Problem

组织目录已经绘制后，缓慢的账号列表请求仍可能推迟两个模型详情页签的预加载。多个个人登记请求交叠时，旧报告可能覆盖新筛选条件对应的结果。

## Decision

组织目录在自身就绪并绘制后调度共享详情分块。用户选择详情页签时启动共享账号选项的读取。报告请求持有取消信号，只有当前请求能提交结果和反馈。应用不同的筛选条件时清除上一份报告。

## Alternatives considered

**为整个页面共用一个就绪条件。** 目录、计价和登记历史依赖的数据各不相同，达到可用的时间也不同。

**只取消上一条 HTTP 请求。** 已排队交付的响应或错误仍可能与新筛选交叠。取消信号同时约束每次状态更新。

## Consequences

首次访问详情页签时，账号选项和该页签自己的内容可以并行加载。账号选项到达前可以先显示页签内容，计价模型读取未完成时目录也可以预加载分块。
