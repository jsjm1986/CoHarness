# Agent Note: Progressive document overview

Status: implemented

[English](2026-11-19-progressive-document-overview.md) | 中文

## Problem

组织文档概览到达前台等待期限时只返回部分元数据。一个获授权的电脑即使能成功响应定向索引读取，也可能在每次刷新概览时超期。延长期限会让全部文档一起等待这台电脑。

## Decision

主入口的浏览器可以向现有账号接口请求渐进概览。Gateway 通过现有电脑路由有界地读取每个来源的一页。它合并就绪的前缀并发送第一页的暂定结果，分页游标随最终页发出。每次发布都会重新核验浏览器账号和文档授权。访问撤销会取消读取，浏览器在确认权限失效时清除结果。

最终页包含合并排序与每个已响应来源的消费位置。不可用电脑在下一次首查询前不参与这组分页。参与过分页的来源如果在后续读取中失败，界面会保留上一页等待重试。节点索引可以独立于 Runtime 读取。

## Alternatives considered

**延长 JSON 截止时间。** 全部文档仍需等待最慢的来源，直到更长的期限到达。

**让浏览器单独重查失败电脑。** 将独立返回的结果合入后续页会把排序及游标的责任移出目录服务。渐进流保留各次发布的组织和账号范围，并复用已经完成的读取。

## Consequences

其他电脑还在加载时，浏览器可以操作已经核验的文档。最终页到达前，第一页的排序可能改变。后续分页使用最终确认的来源位置，Gateway 除并发来源读取外只保留一页候选结果。已有 JSON 客户端继续使用前台截止时间。

## Verification

回环 Gateway 测例观察到本机暂定页后才释放远端数据，并验证两页之间的全局排序、完成前撤权、请求取消与离线后的显式刷新。浏览器组件测例验证手机可操作暂定行，以及权限变化后清除概览结果。
