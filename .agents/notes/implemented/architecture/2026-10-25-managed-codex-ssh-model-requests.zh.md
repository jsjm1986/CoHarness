# Agent Note：跨 SSH Codex 执行的父级模型控制

Status: implemented

[English](2026-10-25-managed-codex-ssh-model-requests.md) | 中文

## 问题

远端 Codex 进程无法直接使用绑定于 Harness 主机回环接口的模型监听器。向该进程复制上游凭据会绕过[外部模型请求策略](2026-10-25-external-runtime-model-control.zh.md)。转发还引入清理依赖：消费者等待模型请求收尾并移除远端监听器时，SSH 连接必须仍可使用。

## 决策

[SSH 连接](../../../../packages/ssh/ssh/src/index.ts)拥有从远端回环接口至发起 Agent 本地模型监听器的动态反向 TCP 转发。Codex 接收临时桥接令牌及远端端口；父级保留上游凭据、逐请求授权、资源准入、输入持久化和用量归属。一次性运行和持久成员均从实际 standing realm 解析该连接。远端程序解析先于模型监听器分配，持久成员恢复不启动监听器或进程。

每个转发在分配前把本地消费者的清理器保留在连接上。已经提交给 OpenSSH 的分配会在管理请求期限内完成，即使调用方已经取消，因此回滚可以获知远端端口。移除使用原始零端口转发描述。清理先等待模型监听器及请求收尾，再取消转发，并等待之后的一次 helper 往返才报告成功。该往返确认同一 SSH 传输已处理取消。控制输出必须完整且有界；退出码为零但 stderr 包含 OpenSSH 错误仍视为失败。无法确认的分配或失败的清理会使连接失效并等待本地传输退出，清理失败保留至关闭时报告。

[Preset 挂载](../../../../packages/preset/agent-preset-registry/src/mount.ts)记录拥有 standing 环境的 fiber。文件组合使用子级 Loader fiber，代码声明的组合使用 standing scope 自身。环境寻址使用记录的 fiber，不从其父级推断。缺少的 realm 服务绝不回退到 Host。

## 考虑过的替代方案

**复制父级 API key，或授权整个远端轮次。** 两者都不能为原生推理建立逐请求策略、额度及 Session 归属。

**添加另一套模型 RPC 协议。** 反向转发保留现有 Responses 传输及 helper 协议，包括模型输入持久化与原生 SSE 处理。

**调用方取消时立即中止转发控制进程。** master 可能已创建监听器，但尚未报告端口。先等待分配再回滚，可以避免调用方成功取消后仍留有无人拥有的远端监听器。

**从一个 Loader 父级推断环境所有者。** 声明式和文件 preset 具有不同的 Loader 所有关系；记录实际所有者让两者都可寻址。

## 影响

部署必须允许远端 TCP 转发，并遵守请求的回环绑定。预装的远端 Codex 程序及选定的父级 Responses 路由仍由部署负责。SSH 断开后远端执行结果仍然未知；连接既不重连也不重放工作。Claude Code 与不透明 ACP 推理保留不支持受管执行的行为。

## 验证

受控清理屏障覆盖消费者收尾期间关闭连接、分配期间取消、无效或截断的控制输出、独立的消费者与 helper 失败，以及转发所有权复用。声明式 realm 测试观测实际提供的文件系统。Loader 组合通过真实远端子进程／helper 路径运行固定版本的原生 Codex，连接测试拥有的 Responses fixture，检查独立模型额度、参与者与 Session 归属、排队撤权、额度拒绝、无密钥持久化输入，以及进程／监听器等待清理。carrier 仅替换外部 SSH 传输；隔离的原生 OpenSSH 验证另行检查转发实现。
