# Agent Note：在桌面驱动调用前强制执行部署授权

Status: implemented

[English](2026-09-23-managed-desktop-execution.md) | 中文

## 问题

操作系统桌面授权属于 Host 进程，并不属于每位 Gateway 用户。工具审批和驱动注册不能证明执行用户具备桌面资格、会话确认或资源租约。

## 决定

[computer-use 服务](../../../../packages/computer-use/computer-use/README.zh.md) 使用部署拥有的政策包裹实际驱动操作。独立本机组装保留操作者权限。受管运行时同时要求活动 Agent 与该政策；一旦观察到受管身份，提供方卸载后也不能退回本机权限。

原生提供方在调用 SDK 前执行政策。已安装驱动提供方通过 MCP 传输瀑布事件约束固定命名空间。调用独有的传输信号承载政策取消，不修改原始工具执行。无关 MCP 命名空间正常委派。已取消的操作不能发布迟到的成功结果，即使驱动直到结束才处理取消。

部署政策负责当前资格、显式会话确认、独占资源准入、撤权与等待清理。缺少该政策时拒绝受管操作。Gateway 执行提供者负责配置后的政策；适配器和政策都不把传输取消响应当作操作系统输入已排空的证明。

PostgreSQL 桌面资格分别由用户与项目拥有。迁移 032 将缺失政策视为拒绝，并通过既有访问失效 outbox 发布变化。管理端保存绑定对象及版本，并发编辑不能相互覆盖。`desktop` 执行能力核验所有已验证参与者，项目还要求可写成员身份及项目授权。管理表单丢弃旧对象的响应，冲突后要求重新读取。资格不替代会话确认或租约所有权。

迁移 033 为每个会话、桌面、节点、运行时代次及用户独立记录显式人工确认。记录资格版本，避免重新授权后恢复旧确认。私有确认端点要求已验证的交互请求身份；普通模型执行及 Auto 不能代为提交。授权检查所有已记录参与者和服务器拥有的当前节点。撤回确认发布既有访问失效通知。协调器操作绑定已认证运行时代次及实际根工作流，包括使用相同请求 ID 的重试。运行时凭据与权威执行参与者负责协调授权；过期浏览器断言不能成为后台身份。

桌面确认在实际活动根 Agent 的所有权树内共享，包含子 Agent 与 PTC 调用。运行时提供活动所有者链；PostgreSQL 根据已准入的执行继承逐条验证关系。历史分叉作为独立根恢复时不提供所有者，不能借用历史父会话的确认。每位实际执行参与者仍须匹配根会话确认，新增参与者必须自行确认；其他根会话与桌面相互隔离。

已配置的 Gateway 政策在同一根内串行执行驱动调用，并在根、子 Agent 或自有任务活动期间保留租约。每次操作前和交付输出前核验资格、确认及租约状态，并在长操作期间续租。失效会取消驱动。正常静止后释放租约；驱动失败或取消后无法确认输入是否排空时标记为停止中，不晋升其他工作流。资格撤回后，清理仍验证保留的精确持有者。协调器拒绝其他根或桌面，已配置运行时不接受调用者选择节点或工作流标识。

## 考虑过的替代方案

- **依赖工具审批：**审批不能证明管理员授予的资格或桌面所有权。
- **仅在发送前检查：**操作期间撤权可能暴露迟到结果，并让传输继续运行。
- **修改共享工具执行信号：**不可变的调用者身份与取消由工具运行时拥有，不属于单个 MCP 政策。

## 影响

受管 profile 的驱动执行前必须存在活动桌面政策。真实 stdio 测试观察到被拒绝的调用不会到达子进程，已准入请求在撤权时收到取消。原生提供方测试验证 SDK 操作前的拒绝。Web 输入区提供当前用户的显式确认框，空白会话也可使用。它通过经过会话授权的 API 和 Gateway 控制器读写；陈旧节点、保存失败和断开的传输不能确认新目标。平台 GUI 验收仍是独立义务。真实 PostgreSQL／HTTP 测试覆盖根内共享、伪造身份、撤权、排队取消及精确持有者清理；驱动政策测试观察串行化、迟到结果拒绝与等待销毁。
