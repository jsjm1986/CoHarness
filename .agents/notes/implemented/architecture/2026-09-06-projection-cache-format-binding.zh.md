# Agent Note：投影缓存绑定 Session 格式代次

状态：已实现

[English](2026-09-06-projection-cache-format-binding.md) | 中文

## 问题

投影检查点即使状态 schema 和水位都有效，也可能描述另一种 Session 日志格式。格式迁移后继续使用它，会让缓存行压过迁移后的事件折叠结果。

## 决策

每个投影缓存身份除了 `createdAt` 和 `cwd` 外还保存 `formatVersion`。读取缓存时三个 header 字段必须全部匹配；任何不匹配都会丢弃该行并从日志重新折叠。存储域版本同步递增，使已有缓存介质整体失效，而不是按新的身份约定解释。

## 考虑过的替代方案

**只绑定 Session id 和创建时间。** 拒绝，因为格式迁移可以保留这两个值，却改变事件解释方式。

**随 Session 日志一起迁移缓存行。** 拒绝，因为缓存只是折叠快捷方式而非权威来源；重放 canonical 日志更安全，并且已有 fail-soft 路径。

## 结果

格式变化可能增加一次完整投影折叠，但旧行不会再为不兼容的日志代次播种状态。缓存仍独立于 Session 迁移实现。

## 验证

投影缓存测试覆盖身份匹配和存储域版本失效路径；包级类型检查与聚焦测试已通过。
