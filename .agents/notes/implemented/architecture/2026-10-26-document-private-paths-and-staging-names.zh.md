# Agent Note: 文档私有路径与暂存名称

Status: implemented

[English](2026-10-26-document-private-paths-and-staging-names.md) | 中文

## 问题

隐藏每个 `.part` 文件名会使普通的已完成上传从文档列表中消失。对维护名称只做精确比较，还会在不区分大小写的文件系统上允许通过大小写别名访问私有上传或回收站数据。同时规范化已链接的根目录及其子路径，会把链接目标当成文档根目录，从而允许普通读取到达所配置真实目录之外。

## 决策

本地提供方保留写入方准确的 `.userdoc-<24 个十六进制字符>.part` 命名空间。其他 `.part` 名称仍是普通文档。目标解析把暂存名称冲突视为已占用，选择正常的数字后缀；公开文档标识符不能选择内部暂存文件。新的文件及目录名称在字节截断前后都移除末尾 ASCII 句点及空格。

根级维护名称同时保留大小写及 Win32 末尾句点、空格别名。公开目录校验还比较所选第一级目录与实际维护目录的设备号及 inode，拒绝文件系统的其他拼写。递归与直接子项列表应用相同的排除规则。文档根目录必须是真实目录，公开遍历拒绝链接组件。内部最终确认显式打开经过校验的私有临时文件；公开读取路径不暴露这一选项。上传启动、维护、会话锁及分块写入在文件系统操作前校验真实根目录和私有父目录。私有载荷写入拒绝链接文件，并比较打开的对象与所选源文件。清单读取拒绝链接及非普通文件，生命周期状态必须是字符串，不能只是在 JSON 值转换后看起来像字符串。

`LocalUserDocFs` 接受可选的 `controlRoot` 来保存上传与回收站状态。配置目录必须是真实目录、与公开根互不包含且位于同一文件系统；POSIX 部署要求控制目录和父目录由 Gateway 进程账号拥有且仅允许所有者访问。路径包含检查允许兄弟目录，并拒绝任一根嵌套在另一根内。可续传发布按私有根校验分片文件，按公开根校验目标。Linux 会保留两边的父目录，直到发布或回滚完成；检测到源或目标父目录变化时拒绝完成并保留私有分片。普通保存在创建暂存文件前取得父目录描述符，并持续保留到失败清理完成。生产 Gateway 组合仍使用默认的公开根目录布局。

Linux 上移入回收站会保留两边的父目录描述符，并在提交清单前比较已移动文件与所选对象。移动失败时，先通过排他硬链接恢复源，再释放隐藏副本。若其他文件已占用源位置，则两份文件都保留，并在错误中保留操作与恢复失败的原因。

Linux 恢复操作会保留私有源和公开目标的父目录，直到发布、移除隐藏链接和回滚完成。缺失的目标目录相对于保留的父目录创建。检测到父目录替换时，会移除本次创建的空目录，拒绝恢复并保留可恢复字节。

Linux 永久删除和保留期清理会在加锁、读取、移除载荷、原子替换元数据和释放锁期间保留清单目录。检测到替换时拒绝确认，根外载荷和元数据都保持不变。即使发生替换，也会通过保留路径释放锁，因此恢复原控制目录后可幂等重试永久删除。

这些检查保留[文档生命周期决定](2026-08-27-document-index-pagination-and-trash-lifecycle.zh.md) 描述的基于路径的生命周期。持久实例、独立回收站操作和目录所有权仍属于[独立的身份提案](../../proposed/architecture/2026-10-25-document-incarnations-and-trash-actions.zh.md)。

## 已考虑的替代方案

**隐藏每个 `.part` 文件名。** 该后缀是有效的用户文件名，不能证明提供方所有权。

**只比较规范化字符串。** Windows 可以为[长文件名分配短别名](https://learn.microsoft.com/windows/desktop/FileIO/naming-a-file)；私有目录对象检查不依赖另一种拼写与长名称相同。

**只依赖真实路径包含关系。** 已链接的根目录会改变包含关系所检查的目录。根目录和组件校验必须先于公开数据读取。

## 后果

普通 `.part` 上传保持可用，私有数据则不能通过已测试的别名或已经链接的文档根目录选择。Linux 不同 UID 回放证明配置私有控制根后会拒绝读取、忽略公开目录内伪造的清单，并从私有存储发布已认证的上传。引擎测试验证该上传经过重启、移入回收站、恢复和永久删除后的行为。现有用户所有的维护名称别名及暂存模式文件需要显式文件系统改名；不会根据后缀删除数据。[升级指南](../../../../docs/upgrade-guide/v0.2.1-rc.1.coharness.1/document-private-paths/guide.zh.md) 负责操作步骤。

真实 Loader 场景固定上传可见性、暂存名称加后缀、私有文件和目录拒绝、损坏上传状态拒绝、字节保留及链接根目录的读写拒绝。Linux 场景在创建普通暂存文件、移入回收站、发布恢复文件、创建缺失目录和永久删除前立即替换父目录。根外文件保持不变；上传和恢复场景保留自有数据，永久删除场景在恢复原控制目录后完成重试。macOS 原生负向对照在修复前返回私有或根外夹具字节。文件系统元数据测试模拟短名称身份；实际 Windows 别名行为和非 Linux 目录替换不属于这些证据。宿主必须保护根目录及其祖先，避免请求期间未经协调的替换。
