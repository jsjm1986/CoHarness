# Agent Note: 受管执行的已验证参与者

Status: implemented

[English](2026-09-22-verified-execution-participants.md) | 中文

## 问题

共享 Agent 可能在起始 HTTP 请求结束后、另一用户编辑队列后，或工作被委派和恢复后继续执行。浏览器角色、展示参与者或继承的异步请求上下文，都不能证明哪些人的输入促成了这次执行。如果最新的管理员可以替换先前贡献者，非特权输入就能通过编辑者、子任务或分叉获得特权。

## 决策

[Execution Authority](../../../../packages/context/execution-authority/README.zh.md) 定义输入证明、参与者捕获、委派和当前权限检查。[Gateway Execution](../../../../packages/context/gateway-execution/README.zh.md) 基于 Gateway PostgreSQL 记录实现这些操作。输入和编排消费者因而独立于请求传输，同时保留真正的 [Agent 发起人](2026-07-15-agent-initiator-scope.zh.md)。

Gateway 为当前认证调用者的精确人工输入作证。不透明引用绑定组织、运行时、Session、消息和内容，但不会授予角色。队列替换保留先前编辑者。已接受的问题答案加入经过验证的回答者；普通工具审批表达同意，不会添加执行参与者。展示元数据仍用于转录和模型，但不是授权来源。

Session 的参与者限制持续累积。发送方在异步创建子任务或投递前捕获当前已验证引用。子会话在自己读取时必需的 Session 事件中记录继承；相邻转发保留发送方限制和稳定投递身份。分叉捕获完整来源授权资料，不受所选历史前缀限制。冷态恢复向 Gateway 核对持久引用，不会复活先前请求。捕获的引用不能借用无关 Session，也不能丢弃未知历史。

执行检查每位保留参与者的当前访问权限。特权操作还要求每位参与者都有相关资格；未知历史身份会阻止 Full 和 Auto 执行。选择特权预设会同时检查选择者和现有参与者，不会制造新输入。[Auto 审查与计费](../bug-fix/2026-09-22-auto-review-execution-attribution.zh.md) 和 [profile 管理](2026-09-22-gateway-profile-management-authority.zh.md) 分别拥有其准入与归因规则。

Gateway Runtime 将应用标记为必须具有执行授权。移除提供者后，该要求仍然保留；提供者缺失会拒绝受管执行。它的 `interactive()` 身份仅在 HTTP 处理仍活动时存在；继承的请求上下文不是后台授权。授权流断开会使待处理许可失效，并取消活动工作。重连允许重新检查，不会重放副作用。独立本机 profile 保留自己的操作者权限，不组合 Gateway 提供者。

## 考虑过的替代方案

**按最新可见参与者授权。** 后续编辑或子任务响应会抹除先前限制。累积规则保留所有相关人工贡献者。

**为整个任务捕获 HTTP 主体。** 工作排队、委派或恢复期间，请求可能过期，权限也可能变化。持久来源事实和当前权限检查回答的是不同问题。

**将继承引用视为凭据。** 序列化引用可以被复制。Gateway 在允许工作前验证其运行时、Session 谱系、不可变输入事实和当前访问权限。

**把 Gateway 传输放进每个消费者。** 这会重复身份规则，并使本机编排依赖部署细节。轻量定义传递限制，由提供者负责验证。

## 影响

共享特权工作受到保留贡献者中最低权限的限制。从可见转录移除参与者或选择不同前缀都不能提升权限。未知历史仍可使用普通模式，但须具有已验证的当前写入权限。受管执行依赖可达的 Gateway 和已就绪的授权流；传输恢复不会静默恢复已取消的工作。

[动态模型工具退役](../simplification/2026-09-22-retire-dynamic-cordis-model-tools.zh.md) 移除了一条可能绕过服务授权的 Host 代码路径。剩余可信 Host 插件仍需要部署隔离；参与者检查不是操作系统沙箱。

## 测试

提供者测试拒绝过期修订、已断开流的响应、未签名输入、畸形继承和失去活动 Agent 所有权的操作。Gateway PostgreSQL 测试覆盖不可变输入事实、编辑者累积、当前资格、相邻转移、重放去重及权限变更。这些检查证明身份机制，不代表所有恢复子任务、Team 投递和已部署 Web 入口都已完成组装验收。每条真实传输和执行器仍需要自己的正常路径与拒绝证据。
