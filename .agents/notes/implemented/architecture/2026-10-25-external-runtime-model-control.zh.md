# Agent Note：外部模型请求的父级控制

Status: implemented

[English](2026-10-25-external-runtime-model-control.md) | 中文

## 问题

Codex、Claude Code 和 ACP 运行时自行发起模型请求。父级进程准入和已授权的外部轮次不能授权每次嵌套推理、预留其容量或确定其用量归属。真实 Codex 子代理能够在父级策略禁止全部模型时访问回环推理端点。

## 决策

Codex 一次性运行及持久成员可使用发起 Agent 拥有的 Responses 传输。显式 `modelProvider` 会启用它，受管父级也会要求它。`requiresParentModelControl()` 统一判断已安装或必需的模型策略、资源准入和执行权限，供 SDK 控制、Codex 模型选择和不透明后端拒绝使用。即使缺少可选的预算与模型策略服务，仅有执行权限的父级仍必须保留按执行范围实施的校验。实际发起 Agent 提供选定路由、LLM 服务、资源所有者、Session 和执行作用域。缺少路由或适配器协议不受支持时，会在进程分配前拒绝。独立组合保留原生认证与执行。

每次运行拥有经过认证的回环监听器、有界请求与响应，以及可等待的释放操作。每个已认证请求体具有独立的 `modelRequestTimeoutMs` 时限。到期返回 `504 TIMEOUT`，不创建原生模型请求事件或模型许可。上传完成后，在模型准备前清除计时；后续模型工作继续使用自己的取消机制。原生 Codex 只接收本次运行凭据和命令行提供方覆盖，WebSocket 推理与内部请求重试被禁用。父级预备的 `native-stream` 适配器操作保留端点代次，在准入后解析上游凭据，以背压解析 SSE 并报告实际 token 数。子级标头和 URL 均不能选择上游端点。 无效的子级 JSON 在解析时归类为 `INVALID_REQUEST`；意外的父级持久化或执行错误保留服务端失败分类。必需的 Session flush 失败会阻止模型派发，但不声称回滚已提交事件。SSH 执行通过实际 Agent 的 standing 连接保留反向回环转发；[对应决策](2026-10-25-managed-codex-ssh-model-requests.zh.md)定义所有者与取消行为。

每个请求在派发前追加精确的无密钥 `subagent/codex-model-request` 并持久化。`prepareDelegatedOperation()` 使用 `llm/delegated-stream`，保留父级对话重放。每个请求独立获取模型额度，并在排队等待后及异步凭据解析后通过父级实时授权及提供方注册时保留的策略。能力查询结束后会在监听器启动前复核两侧策略所有者。请求前及派发等待后均会复核保留的注册和父级资源所有者；替换或撤下后需要新的子运行时。独立父级资源所有者不能绕过注册所有者。捕获的执行作用域在父级后续活动期间保留发起 Session 和参与者。

持久 Codex 成员注册 `LlmAdapter.callKind: orchestration`。外层轮次使用 `llm/orchestration`，保留必需的策略所有者，不预留合成模型额度，也不对成员别名计量。每个原生请求通过受管成员 Agent 的委派操作、策略及资源所有者。发布前，绑定存储捕获原生认证或精确的上游提供方／模型，包括继承父级的选择；冷恢复不根据别名或父级当前设置推断新路由。通过同一提供方实例创建一次性或持续委派时，省略的设置继承已保存的上游。编排别名不提供原生模型权限。对话检查点、标题调度和位置回放会观察编排轮次；模型治理与 SDK 模型转发只观察其中的实际请求。恢复只读取 rollout。释放会取消待决的模型／进程分配，等待稍后到达的所有者，并保留独立的清理失败。

不透明外部推理仍使用 `assertExternalModelExecution()`：Claude Code、ACP 和不支持的外部传输会拒绝受管执行。其成员路由也注册为编排。LLM 服务仍检查必需模型策略，不受支持的轮次则在模型准入前到达拒绝检查；容量耗尽不会推迟拒绝，也不会消耗合成额度。注册上下文和实际 Agent 上下文均适用。加载休眠提供方仍然可用。[SDK 子运行时决策](2026-10-24-sdk-managed-model-requests.zh.md)拥有其独立的子级控制协议。

## 考虑过的替代方案

**为外部轮次预留一个额度。** 外部轮次可在不再次回调父级的情况下发起多个并发或顺序模型调用。

**只授权成员路由。** 路由标识外部 agent，原生设置决定实际模型、重试和辅助调用。持久成员需要对原生请求准入，不能在整个外部轮次外围持有一个合成对话模型额度。

**把提供方密钥复制到子级。** 这会让原生认证在父级策略之外发起推理，并使凭据来源归属不清晰。

## 影响

受管 Codex 需要已注册的 Responses 路由，采用显式 API key 或已配置协议认证。不支持提供方原生 OAuth。不支持的外部能力保持失败关闭，不算作已完成逐请求接入。缺少模型权限来源的旧持久绑定保持原样，须新建成员。必读输入事件扩展当前 Session 事件类型，不改写已提交代次，也不改变结构格式版本。

## 验证

可运行的 Loader 应用通过受控许可阻塞父级模型准入。ACP 和 Claude Code 成员不进入该等待，也不请求模型或进程容量，直接拒绝执行。私有旧产物会先进入等待，并在拒绝前释放一份多余的模型许可。提供方回归覆盖共享和隔离上下文中的模型策略、资源提供方及其必需标记，分别验证启动、成员创建和恢复推理。缺少必需模型策略仍保留专用失败。

真实 Loader 组合冷恢复成员，再通过继承的上游委派一次性原生 Codex 运行，保留成员名下的输入事件、用量及参与者归属；排队期间撤权会阻止第二次上游请求。真实包内 Codex 测试以单个模型额度恢复显式及继承路由的受管成员，完成两轮运行，分别记录原生请求及子级输入事件，且不向子级传递上游凭据。确定性屏障覆盖待决模型／进程释放和独立的清理失败。绑定存储重载保留选择，拒绝格式错误、冲突或晚于绑定的权限记录。一次性测试在一轮内发起两个原生请求，分别记录用量和额度，并在第二次排队等待期间撤销注册策略，覆盖共享与隔离的父级策略。传输测试覆盖端点代次、凭据解析、缓存用量、截断、格式错误或过大的响应以及取消。可运行 SDK 夹具在回环 HTTP 前记录精确模型输入，并通过两个 SDK 投影观测父级 Session。可运行的一次性夹具在原生 Codex 启动前验证不完整的已认证上传超时；随后的真实原生请求保持原有许可和持久输入。

真实 PostgreSQL Gateway 组合对一次性运行及持久成员，在后续管理员请求之后仍保留原始成员、项目和发起 Session；排队期间撤销模型或执行权限会阻止第二次上游 HTTP，并确认模型／进程占用全部清零。嵌入式 Gateway 夹具把工作区模块绑定到源码解析器；SDK 夹具使用所在进程完整的源码或构建运行时。两个 SDK 均投影持久成员的两轮运行，并在新宿主进程中恢复同一个子级。消费方回归覆盖检查点拒绝、未变请求头的标题修订，以及不执行原生运行时的回放和拦截器释放。

仅有执行权限的覆盖包含根上下文与隔离上下文中的一次性启动、成员准备和恢复推理。不透明后端 Loader 回放确认原生分配前的拒绝；原生 Codex Loader 示例在没有模型访问服务和预算时，确认捕获的父级范围内允许的上游派发与拒绝请求。
