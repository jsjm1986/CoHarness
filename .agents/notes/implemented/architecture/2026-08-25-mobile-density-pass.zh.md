# Agent Note：移动端导航与阅读密度

状态：已实现

[English](2026-08-25-mobile-density-pass.md) | 中文

## 问题

紧凑会话抽屉接近全屏宽度，嵌套工作区卡片和桌面 Markdown 间距偏大，导致手机能看到的对话区域过少，短回答看起来也过于膨胀。

## 决定

紧凑导航使用更窄的抽屉、更短的分组／列表节奏，以及 44px 最小行高。工作区和会话层级继续保留，只调整内边距、卡片圆角、标题字号和行间距。紧凑 Markdown 使用共享移动正文角色、更小的标题角色和更短的段落／列表间距。触控热区与视觉字号保持独立。

## 结果

抽屉遮罩后仍能露出一条对话内容，滚动前可以看到更多历史。短回答在手机上呈现为紧凑文档，而不是缩放后的桌面文档。桌面布局和数据操作保持不变。

## 验证

Workspace、Layout、Sidebar 和 Primitive 样式测试通过。320/375/390px 组装视觉审计通过，并在密度调整后复查了截图。
