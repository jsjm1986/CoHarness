# Agent Note: Document index pagination and recoverable trash

Status: implemented

[English](2026-08-27-document-index-pagination-and-trash-lifecycle.md) | 中文

## Problem

大型文档工作区每次完整扫描运行时并在浏览器筛选都会增加响应和渲染成本。删除也没有持久化的恢复窗口：文件从运行时移除后可能在用户或管理员纠正前消失，组织级目录也无法区分可恢复删除和永久清理。

## Decision

用户文档服务提供有界的目录和回收站分页，接受经过校验的筛选条件，使用稳定排序和不透明的延续游标。Host 与 Gateway 转发分页参数，绝不公开运行时路径；Web 管理器在提供方声明支持时使用游标分页，并为旧提供方保留本地分页回退。管理器持续挂载期间保留已获取的页面，筛选条件改变时创建新的游标链。

复制规划按经过校验的源文档 ID 的父目录分组，为每组读取有界分页。游标只属于一个目录，扫描预算属于整个规划。匹配使用完整文档 ID，结果保留原选择顺序。请求中的目标目录不决定源元数据的查找位置。若改用不分页的递归列表，规划工作量就会随无关文件夹增长。

删除将选中的普通文件保留在提供方回收站中。独立存储使用版本化路径清单；受管 Gateway 存储在私有 SQLite 元数据中使用独立发布 id、修订号及回收操作 id。恢复会选择可用目标，不会覆盖其他文件；清除由显式请求或保留期到期触发。每次变更都需要当前作用域权限；受管变更还携带目录索引批准的精确选择。

保留条目只证明它自身的发布实例已被移除。受管作用域可以在同一地址保留多个回收操作及替代文件；恢复与清除选择精确操作，过期活动选择不能操作替代文件。按路径寻址的独立提供方则在活动替代文件与保留路径相同时返回 `DOCUMENT_TRASH_CONFLICT`。浏览器行标识及生命周期请求保留这些区别。

独立存储的清单是一份完整恢复记录。未知版本、无效记录、重复文档 id 或隐藏文件路径以及非法路径，都会在移动或删除文档前拒绝读取和变更。仅当目录不含隐藏文档文件时，缺失清单才表示空回收站。拒绝操作会保留元数据与字节，供完整备份恢复。

恢复先选择可用名称，再通过排他硬链接发布。其他写入方若在选择后占用该名称，操作会以 `DOCUMENT_RESTORE_CONFLICT` 失败，不替换其文件，也不消耗回收站记录。链接后若发生失败，会尝试先恢复隐藏链接再删除可见副本；回滚拒绝无关的隐藏 inode，并在无法完成时保留两个原因。这种复合失败后需要恢复剩余副本。

本地保留期扫描只确定候选项。每次删除会在写入锁内重新读取清单，要求文档 id、隐藏文件相同，且当前截止时间已经到期。等待期间发生恢复、替换或续期时，会跳过该记录且不增加计数。候选项之间会释放写入锁。

PostgreSQL 目录以 `active`、`trash`、`purged` 和 `missing` 状态镜像该生命周期，记录保留时间、操作者和追加式 `restored`／`purged` 历史。已有的 `deleted` 行迁移为 `trash`，并使用默认 30 天截止时间。受保护的旧回收站导入会将匹配的纯路径回收站行标记为缺失，保留其历史及导入后的回收动作。所有权转移只适用于活跃项目文档；检查索引区分缺失文件与永久清理历史。管理员 API 提供游标列表以及单条或批量移入回收站、恢复和永久清理；Gateway broker 可用时先修改运行时字节，再提交目录状态。

运行时列表对账、身份日志投影和批量移除先按 UUID 顺序锁定已有的相关目录行，再允许更新取得企业的权限修订行。这避免多行修改持有该修订行，却等待生命周期写入方持有的文档。替换和批量移除只修改初始已锁定目录快照中的活跃行；快照等待期间提交的新登记会保留，交由下一次对账处理。等待行锁之后，永久清理仍为权威状态。

目录索引更新在实际语句中检查所需源状态，只为变更行追加历史。过期修订号不能重新激活终态历史，也不能隐藏较新的活动发布。复制登记锁定精确的目标实例，仅更新来源关系，不替换当前所有者、路径或生命周期；存在歧义的纯路径目标会被拒绝。源下载响应头将已打开的实例与后续源路径复用分离。

成员同步、移入回收站及永久清理事务在目录和历史语句完成等待后，重新检查当前企业、账号、成员身份及项目写权限。行锁等待期间提交的撤权会拒绝事务，回滚元数据、历史及操作记录。管理员生命周期操作同样在选出已锁定文档后及提交前，重新检查活跃管理员身份。所有权转移要求当前有效的管理员或项目所有者，以及具备当前项目成员身份的活跃接收方；文档等待结束后及提交前均会检查。Steward 项目权限遵循[管理员加资格规则](../feature/2026-10-10-steward-admin-layered-admission.zh.md)；已归档项目不进入成员侧元数据列表、总数及统计。独立管理员检查索引保留企业范围的审计记录。

Migration 018 为文档目录中的用户外键附加 `organization_id`（包括所有者、操作操作者和历史操作者），因此导入的 UUID 不能跨企业连接所有权或审计记录；同时增加供 SQL overview 筛选和分页使用的活跃修改时间与 trigram 索引。

Gateway 将权威身份及投递日志保存在运行时可写根之外。变更独立保留原始发起人、不可变创建者和当前目录索引所有者。受保护日志前缀与 PostgreSQL 接收游标支持中断重试；运行时元数据通知不能指定归属或生命周期事实。读取触发的观察、恢复及确认必须经过维护准入，未变化文档的已初始化读取仍可使用。独立模式的建议性目录索引回调仍没有持久凭据。

Gateway 部署清单在写入数据前保留公开、元数据及私有对象根。备份通过原始内核对象证据和摘要证明已提交文件版本。恢复重建硬链接并重新绑定新内核对象，同时保留逻辑 id、创建者和投递位置；复制旧 inode 数字不能授权恢复。缺少创建者证据的项目文档实例保持未知归属，直到显式分配。

macOS 持久绑定把从描述符取得的文件系统 UUID 与原目录 inode 配对。设备号仍是当前进程的证据，重新挂载后可能变化。第 4 版 schema 在同一元数据事务中，归一化已证实卷在记录、待完成操作及投递数据中的设备号；inode、逻辑身份、发起人和游标位置保持不变。第 2 版域标记独立绑定元数据根及数据库文件。旧证据仅在原内核对象仍一致时取得 UUID。离线恢复要求重新挂载前已独立验证的备份，以及匹配的原目录／数据库／文件 inode、保留版本和摘要。它保留后续永久删除历史及部分上传，不回滚数据库。挂载恢复不能改变已知 UUID；完整的验证恢复可以绑定另一块卷。

旧格式在启动时先验证原存储绑定，再迁移 schema。完整恢复在迁移前验证全部保留文件证据；被拒绝的复制根和不完整备份保留原元数据字节。

目录改名通过每次操作独立持有的 Koffi 库调用原生不覆盖操作。POSIX 相对于保留的上级描述符逐层打开父目录，并通过这些描述符改名；Windows 打开父目录时不共享删除权限，并使用写穿移动。排他系统调用会保留验证后新建的目标，包括空目录。命名空间同步先于身份提交。原生移动被中断后，恢复会重试同步；已完成改名的日志会保留，不会被当作尚未使用的意图取消。父目录替换会拒绝确认并保留恢复证据；回滚不会覆盖无法明确判定的副本。身份及内容清单冲突通过 HTTP 返回 `DOCUMENT_TARGET_CONFLICT`，而不是服务不可用。

身份模式的一次性保存将调用方取消传入暂存后的发布过程，并在取得根锁及准备运行时文件访问后检查它。发布前的回调被取消时，不留下公开文件并清理暂存文件。身份模式的缓冲读取共用写入使用的请求体消费器：等待中的读取被取消后，会在源取消完成后拒绝，并在取消原因之外保留独立的清理失败。

## Alternatives considered

**保留完整列表，只在浏览器分页。** 对支持分页约定的提供方否决：响应大小和元数据工作量会随工作区增长；旧提供方仍把它作为兼容回退。

**立即删除文件，只保留目录元数据。** 否决：元数据无法在误删后恢复字节。提供方在截止时间前持有回收站字节，目录继续作为审计投影。

**允许管理员只修改目录状态而不联系运行时。** 否决：界面可能在文件仍被删除时报告已恢复，或在字节仍可读时报告已清理。Gateway broker 在目录记录结果前先执行运行时操作。

**读取状态或到期时间后再无条件更新。** 等待行锁期间可能发生恢复、永久清理或保留期续期。实际更新必须检查当前状态和到期时间，较早的扫描只能确定候选行。

**只在等待文档之前授权。** 已提交的账号、成员身份、角色或资格变更可能使该决定失效。目录写入结束后的新语句提供当前准入判断，无需加入可能反转文档与权限修订行锁顺序的策略锁。这保护数据库事务；已完成的文件系统操作仍不在其回滚范围内。

**丢弃无法识别的清单记录后继续。** 后续写入会提交不完整的恢复集合，使被丢弃文件失去恢复元数据。因此校验会拒绝整份清单。

**只要 inode 相同就忽略设备号。** 复制的文件系统可能复用这些数字。持久 UUID 证明后续重新挂载；旧绑定要求独立备份证据和显式离线恢复。当前请求始终仍须核验原始路径。

**向此前空闲的恢复目标执行重命名。** 其他上传可能在查询后占用该目标。排他发布会在真正修改文件系统时执行不替换规则。

## Consequences

当前文件夹和全部作用域元数据的列表、搜索流量受请求页面大小限制。游标绑定一条查询链，不能被当作文件系统路径使用。没有索引的提供方仍可能扫描所选目录生成页面，但重复的进行中读取会合并，提示词使用的递归列表保持为独立操作。

回收站在保留期间占用存储，需要维护任务定期清理。运行时或目录服务中断可能留下待对账状态，因此用户错误保持可重试，管理员操作按行返回结果。永久清理会删除提供方字节并保留目录历史，不会再次使文档可读。

## Verification

持久化输入用例在列出、移入回收站、恢复、永久清理和保留期清理中拒绝损坏清单，并验证元数据、活动字节和隐藏字节保持完整。可运行的 Loader 示例拒绝未知元数据，恢复原始清单，再通过已加载的服务恢复原文件。

确定性的发布屏障在选定目标后创建并发上传。已加载的服务拒绝冲突，保留两个文件，并在重试时使用后缀恢复。失败用例验证隐藏文件移除或清单提交错误后的可恢复性，以及回滚失败时保留剩余副本和两个原因。

本地保留期屏障覆盖写入准入期间的替换、恢复和续期。旧构建在已加载服务的回放中删除了新进入回收站的替换文件字节。当前回放保留这些字节；普通过期用例验证每次清理只计数一次，且未来到期项保留。

本地提供方测试覆盖清单持久化、恢复冲突、幂等清理和重启恢复。Host 与 Gateway 测试覆盖有界分页、无路径元数据、内联预览响应、作用域授权、流式转发和生命周期错误映射。Client 测试覆盖游标导航、筛选重置、持续挂载的页面复用、回收站恢复和移动端控件。配置 `HGW_TEST_DATABASE_URL` 时，PostgreSQL 迁移和目录集成测试覆盖状态转换、保留字段、索引和审计历史。

受管挂载 Loader 记录启动真实 Gateway 传输和提供方，在重新挂载及旧数据验证恢复后保留文档身份和所属部分上传进度，并拒绝复制根及其他账号续传。原生卷读取与独立 macOS 卷查询一致，且在路径替换期间保留描述符。SQLite 用例覆盖已准备、已保留及已提交记录的归一化、独立快照拒绝、字节变化、新版本和中断恢复。冷域备份验证不修改不可变元数据；经过验证的恢复可以绑定另一块卷。Ubuntu x64 的隔离构建、原生测试及安装后验证在 glibc 下执行 UUID 缺失分支；musl 载荷完成编译和包检查，不代表执行过 musl 行为。Windows 平台矩阵仍独立进行。

目录屏障在最终内容清单验证后创建空目标，并在最后一次 stat 后替换源或目标父目录。macOS 及真实 Linux Node 22/24 回放均保留无关字节与选定数据。Loader 记录验证独立模式的冲突代码和成功重试；真实 HTTP 请求将失效的内容清单返回为 409 冲突。目录同步中断会保留已移动日志，拒绝尚未同步的恢复提交，并在同步成功后完成。这些结果不代表尚未执行的 Windows 平台矩阵或作用域移除生命周期已经得到验证。

真实 PostgreSQL 行锁屏障覆盖保留期续期，以及并发的删除、完整列表对账、永久清理和复制记录。原实现违反全部五项预期。管理员 HTTP handler 将已提交的生命周期和历史投影为无需模型密钥的预期输出。补充用例验证 key-share 兼容性、正常到期清理，以及重复生命周期调用不会产生重复历史。这些用例验证目录事务，不证明文件系统操作与后续目录回调之间具有原子性。

替换屏障还在对账等待时登记新文档，其 HTTP 生命周期记录保留已提交的永久清理与并发登记。经过认证的运行时 HTTP 批量移除同样与单文档生命周期事务及新登记重叠。堆扫描计划固定冲突文档顺序；未经保护的批量操作以 PostgreSQL 死锁返回 503。当前实现先取得目录行，再执行失效更新，并只更新已选 id，使两方写入均提交且保留并发登记。

真实 PostgreSQL 屏障在文档修改等待期间撤销账号、成员身份、企业、写模式、管理员角色、所有权接收方资格及 Steward 资格。被拒绝的事务保留目录状态与历史。认证 HTTP 记录覆盖管理员降级后的排队回收站操作，以及 Steward 授权、撤权、角色降级和项目归档时的成员元数据。没有项目成员行的合格管理员，以及符合资格的所有权转移仍获放行。
