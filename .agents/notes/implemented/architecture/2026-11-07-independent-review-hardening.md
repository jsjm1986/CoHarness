# Agent Note: Independent-review hardening across node, deployment, and admin surfaces

Status: implemented

English | [中文](2026-11-07-independent-review-hardening.zh.md)

## Problem

A multi-angle independent review of the active branch (Windows node/deployment, admin and Remote Desktop UI, node-lease concurrency, postgres service layer) confirmed real defects on shipping paths: Win32 error codes were read on the wrong thread, forwarded peer assertions accepted non-finite timestamps and replayable nonces, `schtasks /end` could orphan the node agent while it held the control lease, admin surfaces rendered raw machine error codes, the lease SQL functions' success payload was trusted blindly, `recoverSteward` allocated ports outside the documented advisory-lock critical section, steward dry-run `EXPLAIN` could be steered into `EXPLAIN ANALYZE` execution past both the approval gate and the read-lane deny-list, and `node_channel_lease` lacked the deployment-topology gate that `node_heartbeat` enforces.

## Decision

**Win32 errno honesty.** [directory-move-win32.ts](../../../../packages/attachment/userdoc-local/src/directory-move-win32.ts) calls `CreateFileW`/`GetFileInformationByHandle`/`MoveFileExW` synchronously: `call.async` executes on a koffi worker thread while the callback runs on the JS thread, where `GetLastError` reads stale thread-local state and every failure collapsed to `EIO`, breaking the `EEXIST`/`ENOENT` recovery branches in `store.ts`/`mutation.ts`. [windows-inspector.ts](../../../../packages/subprocess/subprocess-local/src/windows-inspector.ts) pairs every `koffi.alloc` with `koffi.free` in `finally`, matching `win32-process`'s `freeNative` ownership convention.

**Forwarded assertions.** [forwarded-principal.ts](../../../../gateway/src/forwarded-principal.ts) requires `Number.isSafeInteger` on `issuedAt`/`expiresAt` (an `Infinity` expiry previously passed `typeof` checks and never expired), and `index.ts` holds a caller-owned nonce ledger (`Map` keyed by nonce with TTL pruning, no module-level state) so a captured assertion cannot replay inside its TTL. `server.ts` comments now state that `x-dsh-target-node` is a client-settable routing marker, not arrival evidence.

**Lease payload boundary.** `acceptedLease` in [node-access-service.ts](../../../../gateway/src/postgres/node-access-service.ts) parses the `node_heartbeat`/`node_channel_lease` JSON through a `leasePayloadSchema` discriminated union instead of `as` casts, so a malformed `ok` payload throws a plain `Error` rather than fabricating `node-access/<garbage>` codes or `RangeError` from `new Date(undefined)`. Migration `126_channel_lease_topology.sql` adds the `computer uuid` parameter and the same `deployment_topology` gate `node_heartbeat` applies (a mode-disabled organization no longer authorizes channels until lease expiry), and narrows `projects_steward_per_node` to `status='active'` rows so an archived bound steward cannot poison reseeding. `issue()` maps a losing `node_agents` 23505 race to `node-access/name-conflict` instead of a raw violation.

**Windows task host.** [node-agent-task.ps1](../../../../gateway/deploy/windows/node-agent-task.ps1): `-Restart` sweeps surviving `node.exe` agent processes after `/end` because Task Scheduler terminates only the tracked `powershell.exe` — but only when the target task's actions actually host the agent (`$hostsAgent`), so restarting the sibling `HarnessNodeGateway` task cannot kill a live agent; the watchdog-vs-`-Restart` race treats a stop followed by a Running state as success; `-Install` asserts `$PSCommandPath`, absolutizes `StateRoot`/`LogFile`/`ConnectionFile`, and splits `AlsoWatch` on `[,;]` with trimming instead of treating spaces as separators; the env file reads UTF-8, strips one surrounding quote pair, and is applied before the unit's own assignments to match systemd `Environment`/`EnvironmentFile` precedence; the agent log rolls at 10 MB per launch.

**Runner liveness.** `WindowsJobOwner.signal` in [windows-job.ts](../../../../packages/subprocess/subprocess-local/src/windows-job.ts) bounds the terminate IPC with a 5-second `RUNNER_TERMINATE_TIMEOUT_MS`; a connected-but-wedged runner is killed so Job close sweeps its tree (the disconnect path already relies on `releaseOwnedJob`). A single `failAndKill` guard prevents double failure reports across the send callback, sync throw, and timeout paths.

**Admin copy discipline.** `PeerBackupSection` moves all 118 strings into [peer-backup.copy.ts](../../../../gateway/admin-ui/src/pages/peer-backup.copy.ts) (`zh` source-of-truth + `en` `Record<PeerBackupCopyKey, string>` + `{name}`/`{count}` placeholders through `translateCopy`), merges the `PeerRecoveryActions` `problem()` map into the shared `message()` so both error channels take identical localized codes, and replaces the raw-code fallback with a localized `unrecognizedOutcome`. `RemoteDesktopPage` maps the full `remote-desktop-*` code family plus auth/maintenance codes through `ERROR_KEYS`, localizes `timeLabel`, gates `changeLevel` on `busy`, and surfaces `endpointInvalid` instead of silently ignoring invalid saves. `NodeAccessSection` gains `modeDisabled`/`notFound`/`nodeDetached` mappings, moves the "more candidates" button out of the `Field` label, and both sections take `randomUUID` from `dsh-util-crypto` because `crypto.randomUUID` is absent on insecure origins.

**Steward service surface.** `recoverSteward` acquires `pg_advisory_xact_lock(hashtext('gateway-port:<node>'))` before `allocateInstancePorts`, matching every other allocation call site's documented critical section; without it a recovery racing an ordinary allocation could lose on `instances_assigned_node_id_port_key` and abort the whole mount-revival transaction. `stewardTarget` additionally binds `steward_node_id` to this gateway's node so a foreign node's steward token is not accepted. `explain()` emits `EXPLAIN (ANALYZE OFF)`: with an explicit option list the grammar requires an ExplainableStmt, so a payload-led `ANALYZE` (which used to complete the text into `EXPLAIN ANALYZE` and execute the inner statement with no approval and no deny-list) is now a planning-time syntax error; `READ_LANE_DENY` screens dry-run previews the same as executions and journals the dry-run flag on denial.

**Miscellaneous.** `instances.ts` seeds `.env` files `0600`; `login()` verifies a fixed valid `DUMMY_PASSWORD_HASH` for ineligible attempts so response time does not enumerate usernames; `config.ts` rejects an `HGW_STEWARD_PROJECT_NAME`/`HGW_COMPUTE_NODE_NAME` combination that can never normalize at load instead of at first seed; `restore-check.sh` requires an absolute dump path (its `-f` ran pre-`cd` while the restore read post-`cd`) and `backup-postgres.sh` suffixes `-$$` so same-second runs cannot overwrite one dump; `node-agent.ts` documents that `executionReady` reports configured bridge endpoints, not probed health; `windows-inspector` documents the identity-check/taskkill TOCTOU bound.

## Alternatives considered

**Koffi async + manual error capture.** Koffi offers no per-call last-error channel on the async path, so synchronous calls are the honest fix; all three syscalls are local and fast.

**Reject instead of generic-fallback unmapped codes.** Keeping a localized generic fallback preserves operator trust for the long tail of worker `error_code` values while specific, actionable codes stay individually mapped.

## Consequences

Win32 directory-move failures now reach the `EEXIST`/`ENOENT`/`EACCES` branches their callers implement; forwarded assertions carry bounded lifetimes and single-use nonces; `schtasks /end` no longer strands a heartbeating orphan; admin banners never render machine codes; the lease functions' output is contract-checked at the database boundary. `verify-client-ui-i18n` does not scan `gateway/admin-ui`; the `Record<keyof typeof zh, string>` typing is the parity gate there.
