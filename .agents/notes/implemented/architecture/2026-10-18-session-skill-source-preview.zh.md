# Agent Note: 通过 Session 注册表只读预览 Skill 源码

Status: implemented

[English](2026-10-18-session-skill-source-preview.md) | 中文

## 问题

已发送的 Skill 引用标识注册的技能，不一定是工作区下的文件。provider 与全局安装可提供同名技能，有效定义取决于 Session 的作用域。因此，打开猜测的文件路径可能展示错误定义，或绕过注册表的可见性规则。

## 决策

只读 skills API 解析 Session 的有效注册表视图，仅为用户可调用的技能返回源码。活跃 Session 使用其 Agent 作用域；冷 Session 使用已记录预设的只读作用域。未记录预设的 Session 使用 Host 视图，不可用的显式预设则不会回退到更宽的视图。注册表查询保留[分层注册表的最近层优先规则](2026-08-09-layered-skill-registry.zh.md)。

`ui-skill` 拥有可选的预览消费者。已发送的用户引用请求当前注册的源码；对话框不调用技能、不展开参数、不执行嵌入命令，也不启动模型轮次。关闭对话框、替换请求或卸载所属插件会取消读取，并阻止迟到结果发布到 UI。技能缺失或预览支持不可用时会显示可关闭的失败提示。

[Skill 工具行](../feature/2026-08-06-web-skill-tool-row.zh.md)保留准确的历史调用结果。其当前源码操作与历史展开项相互独立，仅对根 Session 作用域提供。当前源码不用于重建过去的模型输入。[用户显式调用](../feature/2026-08-08-user-explicit-skill-invocation.zh.md)仍拥有写入日志的 pre-step 注入。

## 备选方案

**通过工作区文件预览打开 `SKILL.md`。** 否决：注册表 provider 不一定是工作区文件，且更近的 scoped provider 可以遮蔽全局 provider。

**调用技能以检查源码。** 否决：调用可能展开参数、执行嵌入指令并追加模型可见输入。

**用当前源码替换已记录的工具结果。** 否决：已安装定义可能在所记录轮次之后改变。

## 后果

预览不新增 Session 事件，也不授予现有注册表之外的文件系统访问权。仅用户可调用的技能仍可预览；隐藏技能仍不可用。非根作用域的历史工具行保留已记录结果，不猜测根作用域定义。

## 验证

API 测试覆盖可见与隐藏定义、仅用户可调用的技能、作用域选择、冷 Session、不可用预设、取消与 provider 卸载。客户端测试覆盖请求替换与所属插件释放。[真实 Web 场景](../../../../apps/web/tests/skill-user-invoke.e2e.ts)打开已发送引用，并对当前源码对话框记录快照。
