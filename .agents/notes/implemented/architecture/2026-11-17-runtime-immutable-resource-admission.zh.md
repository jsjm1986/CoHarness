# Agent Note: 不可变 Runtime 资源的只读准入

Status: implemented

[English](2026-11-17-runtime-immutable-resource-admission.md) | 中文

## Problem

带修订的浏览器模块不包含执行请求，但普通代理准入仍会写 Runtime 活跃时间并重复读取治理数据。远端治理数据库让启动脚本反复承担往返成本。删除授权或相信就绪记录，会让资源在撤权后或由其他进程代次继续下发。

## Decision

严格限定的 GET/HEAD 资源请求使用 [RuntimeAssets](../../../../gateway/src/runtime-assets.ts)。一条新的 PostgreSQL 语句核验浏览器会话、组织、账号、成员身份、电脑／项目访问权、入口拓扑、精确 Runtime 分配、就绪与准备状态、已登记代次及受管节点连接。已连接的访问监控只接受该语句返回的精确授权修订；本地修订更新时拒绝本次读取。账号、位置和资格结果不跨请求保留。普通浏览器认证仍采用原有会话续期。

本地生命周期队列先检查已跟踪的监督进程，再执行新的治理读取，并保留不写活跃时间的代次引用。该引用阻止空闲回收，直到响应传输关闭。未跟踪或不兼容的代次拒绝资源，不会挂接、启动或替换进程。同版本工作台入口仍负责普通观测和恢复。[保留策略](2026-11-11-runtime-survivor-retention.zh.md)继续保留不兼容进程及其已接纳工作；资源读取不会使不安全升级变得可行。

Gateway 为精确方法、原始资源 URL、Runtime 身份和代次签发 `runtime-asset`。接收端 [GatewayRuntime](../../../../packages/context/gateway-runtime/README.zh.md)在 WebServer 资源分发之前，独立校验资源协议和签名，并保留 Connection 的 Host/Origin 检查。该断言不能准入 index、API、事件、升级连接或执行。仅带修订插件组合、已发布客户端分块／映射和哈希资源符合条件；任意修订查询及未版本化资源保留普通路由。发布自带文件仍使用[入口持有的发布资源服务](2026-11-06-center-serves-release-assets.zh.md)。

远程资源复用经过认证的有界节点传输，并在所属节点重新核验。撤权、监控断开、客户端取消、关闭以及最早登录／节点租约期限都会取消活动传输。本地转发移除浏览器凭据、响应 Cookie、身份头和逐跳头，以背压传输，并在释放引用前等待 HTTP 关闭。手动停止的代次返回409；其他不可用代次返回503，不修改生命周期。

## Alternatives considered

**保留普通执行活动准入。** 这会在不可变读取中保留活跃时间写入和重复治理往返，并使脚本下载推迟按需空闲释放。

**缓存已通过的账号或就绪代次检查。** 缓存权限可能晚于撤权失效；缓存端口可能已经属于后继进程。每请求的新数据库结果及接收进程的代次校验，无需跨请求复用即可保留这些检查。

**相信 URL 修订或仅在 Gateway 检查。** 修订选择字节，不选择用户或进程。接收 Runtime 必须在插件路由发布字节前校验断言。

**在资源读取时启动或挂接。** 隐式恢复使资源加载带有生命周期副作用，也可能替换代次。该行为由显式工作台入口负责。

## Consequences

资源读取保留授权，并将下载引用与执行活动分离。Gateway 与接收 Runtime 必须同时升级；在管理员确认安全重启前，不兼容的保留进程继续拒绝新转发。不需要数据库迁移或新增配置。本决策部分替代[活动原子准入](2026-11-01-atomic-runtime-activity-admission.zh.md)中的资源活动处理；普通 HTTP/WebSocket 准入仍由该记录定义。

聚焦 PostgreSQL 套件覆盖当前授权、代次／租约拒绝，以及撤权或 LISTEN 断开后的实时流取消。真实 Loader HTTP 测试固定资源签名检查和可撤销守卫注册。编译 Web 配置转录验证个人／项目 GET/HEAD 读取实际声明的 bundle、数据库活跃时间不变、手动停止拒绝和兼容 Gateway 恢复。这些本地检查不证明跨平台部署、公网性能或 Gateway 无中断替换。

[诊断程序](../../../../gateway/tests/runtime-assets.perf.ts)比较安装和未安装资源准入的同一编译 Gateway，每种方式与范围使用三个独立 Node 进程、十次预热、五十次256 KiB计时响应，以及独立的五十请求 SQL 计数批次。在 macOS arm64、Node25.8.1、本地 PostgreSQL18.4 下，个人范围的直接浏览器请求语句数从10降至3，项目从11降至3。个人完成耗时的中位数／P95从3.08/3.76ms变为5.53/7.04ms；项目从5.19/8.12ms变为6.15/7.81ms。个人峰值／稳态 RSS 中位数从189.59/189.56MiB变为192.92/192.94MiB，项目从189.59/189.41MiB变为190.67/190.69MiB。诊断控制 Runtime 字节和存活进程句柄，排除监督 IPC、浏览器绘制、模型延迟、广域网延迟、数据库服务端内存和并发负载。往返减少不证明公网达到两秒，本地延迟也不宣称改善。
