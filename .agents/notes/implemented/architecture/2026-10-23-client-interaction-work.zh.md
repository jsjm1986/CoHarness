# Agent Note: 让客户端更新工作量随可见变化增长

Status: implemented

[English](2026-10-23-client-interaction-work.md) | 中文

## 问题

一个 token、一次模型尝试结束、一次目录刷新或一条 Session 元数据变化，都可能使整个已加载历史或目录的展示工作失效。稳定的行投影本身不能消除重复导航扫描、视图重建、同步偏好写入或 CSS 隐藏视图中的工作。如果预览访问用户尚未展开的值，折叠结果也会产生多余工作。

## 决策

对话结算从所属 Context 中移除临时行，并重放受影响的 Context 及其前驱依赖方。无关历史节点保持不变。移除 Context 或边界不完整而需要重建时，仍可重建 Location 和替换视图。[对话装配决策](2026-08-09-client-conversation-node-assembly.zh.md) 继续定义事件顺序、Reader 依赖和 Location 成员关系。

Chat 导航更新变化节点或时间线边界涉及的轮次。轮次顺序变化时重建导航索引。只有实际重新分组需要时，流程分组才计算已加载窗口的末轮索引。完整替换、历史前插、隐藏节点转换和位置移动保持既有语义。

目录协调为传入身份和插入锚点建立索引，避免反复扫描当前数组。它保留已有行顺序、最新基线值和新身份的插入位置。没有新身份的刷新在构造插入结构前直接返回保留行。初次列表加载仍使用独立路径。[列表投影决策](2026-10-23-client-list-projection-reuse.zh.md) 继续定义源身份复用和 Runtime 描述变化时的失效规则。

每一代基础连接通过 Workspace manager 读取一次工作区基线。Workspace 与 Session 归档投影共享成功安装且遵守版本规则的归档结果。断线或释放会取消尚未完成的读取，并使迟到结果失效；下一代连接读取新基线。Workspace 帧仍会重放到响应之上，归档版本阻止旧结果覆盖新状态。

列表反馈分别读取所有者的基线阶段、活动与失败。Session 投影暴露 manager 既有的活动和错误，不持有第二份查询状态。空侧栏在读取未完成时显示骨架屏，读取失败后显示错误与显式“重试”。只有成功且为空的基线才能显示空态文案。已有内容的列表在正常状态下预留本地化提示页脚的固有尺寸，使失败到达时行位置、滚动视口和当前焦点保持不变。显式“重试”先将焦点移到树且不滚动，再使用当前空间既有的单飞刷新操作。它保留已到达的行，不创建后台重试或跨空间数据缓存。

工作区导航对每份源快照共享一次合并摘要查询，并通过一次 store action 提交协调后的顺序账户。最终持久化偏好快照完整；消费者不依赖中间的逐账户写入。在工作台模式下，React Activity 暂停被隐藏的普通目录的 effect，同时保留本地浏览状态。隐藏的内容搜索会取消请求，恢复时重新读取当前查询。[工作台决策](2026-09-08-cordis-multi-session-workbench.zh.md) 继续定义布局和 Session 所有权。

工作台账户目录读取跟随 viewport 待恢复的保存布局，以及用户打开选择器或明确重试的操作。每次打开都会读取新的已鉴权目录；恢复完成且选择器关闭时，普通 Session 页头挂载不需要目录请求。viewport 决定是否需要恢复，包括单会话展示和遗留身份。取消操作阻止已关闭或卸载选择器的迟到响应发布目录数据或恢复面板。

JSON 预览只读取既有条目数和深度范围内的值。显式展开和复制仍访问完整值。读取卡片为可见切片构造行，并将完整纯文本拼接推迟到复制时。文件树 store 比较所有声明的导航和新鲜度字段，保留未变化的列表；元数据变化和错误恢复仍会发布。显示排序跟随各目录的条目身份。

Host 只在观察到请求行窗口之后的文本时，才报告还有下一页。流结束时标记完整的最后一页，包括恰好在行数上限结束的页面。因此，预览保留最后的可见内容并禁用“下一页”。版本、取消、授权和所选页字节检查保持既有所有权。

## 考虑过的替代方案

**每次尝试结束都替换整个历史。** 这会重新匹配和构建无关的已完成轮次。选择性重放保留相同的重建内容和无关节点身份。需要移除或完整重置的情况仍保留明确的重建路径。

**卸载隐藏导航或截断大型结果。** 卸载会丢失本地浏览状态。截断会改变展开和复制可读取的内容。暂停隐藏 effect 和限制预览工作保留这些用户操作。

**只按标识符缓存。** 标识符不包含变化的元数据、源版本、时间线边界或所属 Runtime 描述。复用依赖不可变源身份，或比较完整的已声明列表字段。

**无限期复用账户目录或省略恢复读取。** 目录验证保存面板的 Runtime 归属和当前访问权限。请求跟随恢复需求及选择器的明确使用，每次打开选择器都读取当前账户数据。

**依据缺失行或展示计时器推断就绪。** 缺失行可能表示基线尚未到达，也可能源于读取失败。所有者已经报告这些状态；计时器或动画标志不能证明列表成功为空，也不能结束失败的加载。

**在预览中推断文本页是否结束。** Host 为文本预览和累计 Markdown 定义行窗口与 EOF 语义。共享流检查使这些消费者保持一致；字节上限仍表示失败，而不是截断信号。

**重写启动依赖加载器。** 已发布页面已经预加载相关应用 bundle。合成传输中的瀑布等待不能证明通过该生产入口获得冷启动改善。

## 后果

这些改动减少浏览器工作，并保留模型请求、持久 Session 记录、分页、可见排序和结果完整性。完整历史检查和显式展开仍需要与请求内容成比例的工作。结算仍重建时间线索引；这些改动并不让每项操作都变成常量时间。

列表反馈报告既有工作，并允许显式重试失败的读取；显示反馈本身不能证明请求执行或公网隧道加载时间缩短。已有内容的侧栏在正常状态下也保留紧凑提示页脚的空间，以减少列表可用高度换取失败和重试期间稳定的视口。

恰好到达行窗口边界时，提供方迭代器可能越过空分块，额外推进到一个非空分块或结束。分页循环不检查未请求的行，也不会将文件的剩余内容整体加载。

所属回归验证增量输出与完整替换一致，保留无关引用，覆盖位置移动和隐藏节点，验证刷新新鲜度与错误恢复，并证明隐藏视图清理和恢复。工作量负对照复现原有重复工作。浏览器回放通过已发布组合覆盖合成长历史、输出期间的真实输入、导航、JSON 展开和文件刷新。组件工作量计数与本机环回计时是不同证据；两者都不能证明公网隧道延迟或模型供应商响应时间。
