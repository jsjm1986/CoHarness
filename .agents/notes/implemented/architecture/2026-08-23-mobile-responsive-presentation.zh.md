# Agent Note: Web 工作台的移动响应式呈现

Status: implemented

[English](2026-08-23-mobile-responsive-presentation.md) | 中文

## 问题

Web 工作台只有一套业务模型，却包含多个手机可见领域：工作区与会话导航、空白会话创建、对话、输入区接管、工具输出、Trajectory 检查、设置和文档管理。当前 compact 布局保留了桌面信息顺序，再由各组件追加局部 CSS 例外。短屏手机因此会出现重复外壳、输入区遮挡对话内容，以及诊断控件与阅读任务争夺空间的问题。如果继续分别修补这些例外，每个新插件都必须重新发明一套移动策略。

## 决策

保留一套业务和插件系统，同时建立共享设计基础，并在信息架构确实不同的边界使用模式专属呈现。客户端对象层、Session 事件语义、Workspace 操作、slot 所有权、composer chain，以及 Tool/Trajectory 数据保持共享。`ui-layout` 拥有视口档位、compact 外壳几何和统一的浮层/滚动策略。共享原语拥有移动顶部栏、抽屉、底部 Sheet、操作溢出菜单和页面脚手架。当功能层级与桌面有实质差异时，功能包可以提供移动呈现器；只有密度差异时，继续使用共享呈现器和 CSS token。

手机工作台使用一个上下文顶部栏、全高导航抽屉、一个明确的对话滚动拥有者，以及按实际高度预留空间而不是覆盖内容的输入 dock。常用次级操作通过触控尺寸控件或一个底部 Sheet 保持可达。统计、原始 Tool Payload、Trajectory 时序、设置分区和文档操作采用渐进披露，但保留桌面端能力。Workspace 与 Session 行继续遵守现有的复用、归档、重命名、fork、搜索、待处理交互和 subagent 规则；只改变移动端分组和操作位置。`ui-primitives` 统一持有手机 Sheet 遮罩和 `Modal` 焦点循环；只有信息层级真正变化的功能 presenter 才增加手机专属返回行。

响应式约定由外壳在边界处根据视口宽度、短屏状态、安全区和指针能力计算。功能组件不创建平行的业务 store，也不直接读取 Host 服务。新的移动呈现器使用现有的四种 props share 和 slot 声明；共享状态仍按客户端架构规则归对象层或声明它的 entry store 所有。

可选 slot 会改变窗格中控件所需的空间，因此 composer 按工具栏实测宽度排布紧凑控件。以触控为主的设备在横屏外壳展开时也使用这组控件。状态控件下移到底部时保留触发器及已打开的详情。触发器处于正常布局中，指针触点与键盘导航顺序保持一致。

AppFrame 的所有宽度模式使用共享的可见视口高度，并以父容器高度为上限。横屏手机可能越过 medium 断点，但键盘仍只缩小视觉视口；仅按宽度启用键盘适配会让输入区落到键盘后面。通过 portal 挂载的模态框和图片灯箱使用同一高度，不另设视口监听器。当会话标题和可编辑内容无法同时容纳时，对话根容器可滚动隐藏标题，并保留可达的内部内容区；Workbench 窗格中的对话遵循同一规则。当工具栏、各行标题的内容高度和展开窗格的最小内容区超出可见高度时，Workbench 将工具栏与各行放入外层滚动区。悬停反馈和触控目标尺寸根据指针能力决定，与宽度独立。减少动态效果偏好保留状态反馈，同时去掉位置动画。Tooltip 在焦点或指针仍位于触发器或内容时保持显示，直到关闭或离开两者；打开另一个无嵌套关系的 Tooltip 会关闭前一个，不引入全局活动 Tooltip 注册表。

当固定工具栏挤占阅读或编辑空间时，短面板把表单控件和内容放入同一滚动区。按高度判断的容器查询要求容器具有明确高度。自动增长的回答框将自身高度限制在可用滚动区域以内，保留触摸热区和草稿内部滚动。浏览器验收检查真正的裁剪祖先以及用户可操作的滚动路径；通过脚本移动 `overflow: hidden` 祖先不能证明控件可达。

默认模态框的标题与关闭控件在可滚动正文上方独占一行，阅读长内容时保留位置提示，同时避免遮挡代码工具栏或获得焦点的字段。共享的可见高度容器无法同时容纳固定行与可用正文时，整张卡片改为滚动；仅凭布局视口无法识别键盘只留下狭窄阅读区的情况。无默认头部的呈现器保留自己的导航与滚动所有权。评审摘要按相同的可见高度值限制初始高度，并保留文本内部滚动。

对话跳转按钮占用消息链接旁的行末留白。短屏文档菜单在指针激活时保留搜索焦点。可视高度充足时，技能阅读和 Forge 评审将标题留在可滚动正文上方。共享字号使用相对单位，并启用浏览器的系统文字缩放。

Chat 的输入区达到或超过自身滚动区域高度时回到普通布局流，正文尾部与悬浮导航不再为它预留重叠高度。自动跟随末尾时将过高输入区的起始位置对齐滚动区域，并滚动外层区域以完整显示当前获焦的草稿框。手动滚动仍可触达其余控件或保留较早消息的位置，不触发这项焦点调整。短会话面板将输入区放入普通布局流时，Trajectory 列表不再额外预留输入区高度。Trajectory 详情连同摘要和操作整体滚动，避免嵌套的固定区域耗尽阅读空间。文档管理以当前文件夹作为标题，将导航和操作与搜索分行排列，并在未启用筛选的空文件夹中省略筛选和零计数。短屏在空间足够时横向排列目录操作，紧凑展示空态和上传信息，同时保留触摸尺寸。上传进度分别呈现已完成文件数量与当前文件的字节传输或最终确认阶段，保持操作名称稳定。只有对话可接收文档时才显示附加控件；选择模式仍保留目标说明。文档操作与作用域弹窗在宽度变化时保留所属组件和输入状态。视觉审查同时检查信息层级、对齐和间距，以及控件是否可达。

选择全局面板时，在同一 store action 内关闭 compact 导航抽屉，重复选择当前面板也如此。medium 控制栏保留展开状态。目标页面已渲染但仍被抽屉遮挡，不算完成手机导航；浏览器验收等待抽屉关闭后才操作目标页面。

全屏详情面板使用所属 AppFrame 的实测宽度，并移除框架原有的外侧留白；嵌入页面中的框架仍是全屏容器。输入区高度和裁切观察器在后续动画帧发布视觉测量结果，并在卸载时取消待执行更新，避免 ResizeObserver 同帧反馈循环。

侧边栏在 compact 抽屉与桌面列之间切换时保留同一 React 拥有者。即使内容通过 portal 挂载到 body，所属侧边栏卸载仍会丢失其状态；保持拥有者稳定，使打开的设置表单和输入焦点在旋转中保留。关闭的 compact 抽屉为保留的侧边栏持有带引用计数的 `inert`，使显式设置可见性的后代也无法接收指针或键盘交互。打开、变宽或卸载时只释放本次持有，保留其他浮层拥有的隔离。作用域选择浮层也通过相同机制持有被覆盖侧边栏的隔离，关闭或调整宽度时不会恢复过期的 `inert` 快照。

手机风险确认层位于所属设置面板及其遮罩上方，同时保持面板挂载。取消确认后，焦点恢复到面板中的触发选项；再关闭面板时，焦点恢复到输入区控件。模型与插件表单中的文字控件采用最小高度，使放大文字可以撑开控件而不被裁切。

## 曾考虑的替代方案

**将模态框标题粘在正文滚动区内。** 这可能遮挡同样粘住的代码工具栏和新获焦的控件。独立行预留所需空间；极端键盘高度下，整卡滚动退路以标题栏的常驻显示换取控件可达性。

**在同一份桌面 DOM 上继续增加 compact CSS。** 否决：它保留了错误的信息顺序，并把每个新功能都变成新的断点例外；现有 compact 密度、composer seat 和设置修复不能解决统一的浮层与优先级问题。

**维护独立的移动应用和业务实现。** 当前快速迭代阶段否决：重复的 Session、Workspace、插件和交互逻辑会逐渐分叉，并要求维护两套行为测试。只有在信息层级确实改变时，才允许使用独立呈现。

**建立一个拥有所有功能的巨型移动外壳。** 否决：它会绕过插件所有权，让可选能力依赖中心组件。外壳拥有模式和浮层；各包仍通过现有 slot 系统拥有自己的内容与操作。

## Consequences

- 手机外壳只有一个上下文顶部栏、一个导航抽屉和一个活动滚动拥有者；主要内容和回答操作不会被固定输入区遮挡。
- 工作区选择、空白会话创建/复用、会话导航/搜索、发送/排队/插话、模型选择、权限切换、审批、提问、Tool 详情、Trajectory 检查、设置和文档附件在手机视口仍可到达。
- 手机和桌面共享同一套 Session/Workspace 状态和操作结果；呈现改动不新增模型可见内容或持久事件。
- 新功能贡献必须有明确的移动放置方式，并复用共享原语，不得添加临时 viewport listener 或互相矛盾的断点。
- 浏览器检查覆盖 320–430px 竖屏、短屏手机、键盘可见、安全区、暗色主题、长标签、待处理接管和桌面回归。

## 风险

少量信息层级复杂的区域会增加一条移动标记路径，因此需要成对的行为和视觉检查。共享一套业务真源可以限制风险；移动路径不得复制 Session 状态、命令分发或 Host 权威。现有 compact 相关 Agent Note 继续负责各自的局部保证；只有在本决策定义更宽的呈现策略处才被部分取代。

## 实现证据

组装后的浏览器场景覆盖壳层断点、抽屉导航、表单打开时旋转、插件配置、手机确认框和文字放大。Chromium 和 WebKit 使用相同的壳层与表单场景。[浏览器测试指南](../../../../apps/web/tests/README.zh.md#mobile-acceptance)统一记录尺寸矩阵、命令、截图选项和物理设备验收限制。
