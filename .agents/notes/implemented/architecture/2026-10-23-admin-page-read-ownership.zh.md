# Agent Note：管理员页面读取所有权

状态：已实现

[English](2026-10-23-admin-page-read-ownership.md) | 中文

## 问题

同一管理员页面内的独立读取者可能重复执行相同的已鉴权数据库投影，并在浏览器中等待相同请求。组织模型页从同一份完整设置应答派生设置镜像、Provider 目录和模型目录。插件、终端及 SSH 页面既为主控件读取项目列表，也为权限选择器读取它。用量页将服务端初始月份作为应答数据接收；把它当成另一次用户选择，会重复初始概览、健康及用户读取。

## 决定

复用由已挂载页面及拥有时效要求的操作负责。[组织 facade](../../../../gateway/admin-ui/src/model-settings-api.ts) 仅在三个读取者间共享尚未完成的组织设置 Promise。每次显式 `OrganizationModelsStore.load()` 都先建立独立读取轮次，再委托既有模型 store。读取结束时按 Promise 身份释放槽位，旧读取完成不会清掉新读取。设置与凭据写入在接纳及完成时使复用失效，随后成功写入通知或冲突恢复才能请求新数据。[修订号折叠决策](../bug-fix/2026-10-04-org-model-settings-revision-fold.zh.md) 继续负责写入折叠及镜像的排队重读语义。

[OrganizationModelsEditor](../../../../gateway/admin-ui/src/components/OrganizationModelsEditor.tsx) 在 effect 中创建 facade 和 store，每次 effect setup 都创建新的 abort controller。清理会取消该所有者的读取。回调身份改变只更新通知目标，不重建所有者。每次等待读取后都会检查所有者状态，拒绝晚到应答，防止卸载后的旧 Provider 列表完成时继续发起凭据读取。单个读取者无权取消共享请求。

插件、终端及 SSH 页面将当前项目列表结果、加载／错误状态和重试操作传给权限选择器。项目读取独立于无关的用户或 SSH 读取结算。来源错误、重新加载或选中项被移除会使旧权限应答不可用；权限请求保留各自的取消和代次检查。没有自有项目列表的调用者仍使用独立选择器读取。列表不跨页面替换保留，也不代替服务端鉴权。

用量页将请求月份与服务端返回月份分开。初始空请求保留服务端按时区选择月份的权威性，显示返回月份不会发起请求。用户选择、清空选择及既有写后刷新仍是显式读取操作，结果受代次和卸载检查保护。

## 证据与验证

脱敏的 15 页导航记录包含六次在 19 毫秒内开始的组织设置 GET。最后一次耗时 3,588 毫秒，其中 3,078 毫秒记为浏览器 `blocked`；这些时序不能证明存在一条 3.6 秒的 SQL 查询。对应的每次服务端读取执行固定数量的修订号、Provider、目录及可选凭据状态查询，不会调用独立的 [Runtime Provider 投影](2026-10-23-gateway-provider-projection-reuse.zh.md)。

所属 facade 回归用受控的待完成应答承接三个读取者：未共享路径发起三次读取，共享路径一次。另一回归在前轮仍等待时启动显式刷新，移除轮次标记后只产生一次读取，而要求是两次。所有者生命周期用例覆盖 StrictMode 清理／setup、回调替换、重新挂载、失败重试、写入、修订号冲突及晚到 Provider 列表。这些是请求计数和行为检查，不是端到端延迟、内存或整机容量测量。真实已鉴权浏览器验证与 REST mock fixture 分开。

在 `gateway/admin-ui` 中用 `npm exec -- vitest run src/model-settings-api.spec.ts src/pages/ModelsPage.spec.tsx` 运行模型页定点回归。用量及权限选择器行为由所属页面和组件测试覆盖。

## 考虑过的替代方案

- **跨页面请求缓存。** 它需要另行定义用户、权限、项目和设置的失效策略。实测重复工作发生在单个页面内，保留已完成应答会增加陈旧数据风险，却没有解决另一个已测需求。
- **只有待完成设置 Promise，不标记读取轮次。** 旧请求期间的刷新会复用旧请求，削弱模型 store 的最新代次行为。页面专用子类标记该操作，不扩展共享模型 store API。
- **任何设置读取者都能取消。** 一个依赖读取者就可能取消镜像及其他读取者。取消归已挂载所有者负责；写入和刷新标记使复用失效，不中止先前消费者。
- **以浏览器本地月份初始化用量。** 它会在时区边界改变服务端定义的月份。保留初始空请求，将返回的显示值与用户意图区分。

## 影响

这三类管理员路径消除重复读取，不保留第二份鉴权或配置缓存。显式刷新、写入、重试和页面替换仍是更新数据的操作。网络、鉴权、数据库执行和浏览器渲染仍需测量，请求数下降不能证明它们各自的延迟贡献。
